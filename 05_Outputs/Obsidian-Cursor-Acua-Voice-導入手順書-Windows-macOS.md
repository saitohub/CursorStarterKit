# Obsidian・Cursor・Acua Voice 導入手順書（Windows / macOS対応）

- **作成者**: サイジム
- **作成日**: 2026年5月12日
- **対象**: Windows 10/11、macOS
- **対象ツール**: Obsidian、Cursor、**Acua Voice**（表記ゆれ: AcuaVoice / acuavoice。英語サイトでは **Aqua Voice** 表記のこともあります）

## 1. 本書の目的

本書は、Obsidian、Cursor、Acua VoiceをWindowsおよびmacOSへ導入するための手順を、初めて利用する方でも実行できるように整理したものです。各ツールの公式サイトまたは公式ドキュメントで確認できる情報をもとに、ダウンロード、インストール、初回起動、基本設定、動作確認までの流れを説明します。

本書では音声入力ツールの正式名称を **Acua Voice** とします。公式のダウンロードURL（例: `aquavoice.com`）やインストーラー名、英語ヘルプでは **Aqua Voice** 表記が使われていることがありますが、説明文・チェックリスト上の呼称は **Acua Voice** に統一します。Acua Voiceは、MacおよびWindows向けに提供されている音声入力アプリであり、公式ガイドでは「任意のテキストボックスに話しかけて入力できる」ディクテーションツールとして説明されています。

Acua Voiceの公式ガイドでは、製品について「talk into any text box」と説明されています。これは、ブラウザ、エディタ、チャット、メールなど、カーソルを置ける入力欄で音声入力を使うことを想定した説明です。

## 2. 導入前の確認事項

導入作業を始める前に、OS、権限、ネットワーク環境、アカウントの有無を確認してください。特にCursorとAcua Voiceは、利用開始時にアカウント作成やサインインが必要になる場合があります。また、Acua Voiceは音声入力ツールであるため、マイクへのアクセス許可が必要です。

| 確認項目 | Windows | macOS | 補足 |
| --- | --- | --- | --- |
| インターネット接続 | 必要 | 必要 | 各ツールのダウンロードとサインインに使用します。 |
| 管理者権限 | 推奨 | 推奨 | WindowsでSystemインストーラーを使う場合や、macOSでアプリをApplicationsへ配置する場合に必要になることがあります。 |
| 対応OS | Windows 10/11を推奨 | 最新または比較的新しいmacOSを推奨 | CursorとAcua Voiceは公式ダウンロードページでWindows / macOS向けファイルを提供しています。 |
| アカウント | 必要に応じて | 必要に応じて | CursorやAcua VoiceのAI機能・同期・利用管理にはサインインが必要になる場合があります。 |
| マイク | Acua Voiceで必要 | Acua Voiceで必要 | ノートPC内蔵マイクでも利用できますが、外部マイクの方が認識精度が安定しやすいです。 |

## 4. Obsidianの導入手順

Obsidianは、ローカルフォルダを「Vault」として管理し、Markdown形式のノートを作成・整理できるノートアプリです。公式ヘルプでは、Obsidianは主要なデスクトップおよびモバイルプラットフォームに対応していると説明されています。

### 4.1 Windowsへのインストール

Windowsでは、公式ダウンロードページからWindows用インストーラーを取得してインストールします。公式ヘルプでは、Windows欄の Universal をクリックしてインストールファイルをダウンロードし、インストールファイルを開いて画面の指示に従うと説明されています。

| 手順 | 操作内容 |
| --- | --- |
| 1 | ブラウザで Obsidian公式ダウンロードページ を開きます。 |
| 2 | Windows 欄にある Universal をクリックし、インストーラーをダウンロードします。 |
| 3 | ダウンロードしたインストーラーを開きます。通常は Downloads フォルダに保存されています。 |
| 4 | 画面の指示に従ってインストールを進めます。 |
| 5 | スタートメニューで Obsidian を検索し、起動します。 |

インストール後にWindows Defenderやウイルス対策ソフトが確認を求める場合があります。公式サイトから取得したファイルであることを確認した上で、組織のセキュリティ方針に従って実行してください。

### 4.2 macOSへのインストール

macOSでは、公式ダウンロードページからdmgファイルを取得し、アプリをApplicationsフォルダへドラッグして配置します。公式ヘルプでも、macOS欄の Universal をクリックしてインストールファイルを取得し、開いたウィンドウでObsidianをApplicationsフォルダへドラッグすると説明されています。

| 手順 | 操作内容 |
| --- | --- |
| 1 | ブラウザで Obsidian公式ダウンロードページ を開きます。 |
| 2 | macOS 欄にある Universal をクリックし、インストールファイルをダウンロードします。 |
| 3 | ダウンロードした .dmg ファイルを開きます。 |
| 4 | 表示されたウィンドウで、Obsidian を Applications フォルダへドラッグします。 |
| 5 | LaunchpadまたはApplicationsフォルダから Obsidian を起動します。 |

macOSで「開発元を確認できません」と表示される場合は、まず公式サイトから取得したファイルであることを確認してください。その上で、システム設定のセキュリティ項目から許可する必要がある場合があります。会社や学校の端末では、管理者の承認が必要になることがあります。

### 4.3 初回起動後のVault作成

Obsidianでは、ノートを保存するフォルダを Vault と呼びます。公式ヘルプでは、Vaultはローカルファイルシステム上のフォルダであり、すべてのノートを1つのVaultにまとめることも、プロジェクトごとに複数のVaultを作成することもできると説明されています。

| 選択肢 | 使う場面 | 操作概要 |
| --- | --- | --- |
| 新規Vaultを作成 | これから新しくノート管理を始める場合 | Create new vault の Create をクリックし、Vault名と保存場所を指定します。 |
| 既存フォルダを開く | すでにMarkdownファイルやメモフォルダがある場合 | Open folder as vault の Open をクリックし、対象フォルダを選択します。 |

新規Vaultを作る場合は、わかりやすい名前を付けることが重要です。たとえば、個人メモ用であれば Personal Notes、業務用であれば Work Knowledge Base、学習用であれば Learning Notes のように用途が分かる名前にすると、後から管理しやすくなります。

## 5. Cursorの導入手順

Cursorは、AI機能を備えたコードエディタです。公式ダウンロードページでは、Cursorデスクトップアプリが macOS、Windows、Linux に対応していると記載されています。

### 5.1 Windowsへのインストール

CursorのWindows版には、確認時点で Windows (x64) (System)、Windows (x64) (User)、Windows (ARM64) (System)、Windows (ARM64) (User) が表示されていました。一般的なWindows PCでは、CPUがIntelまたはAMDのx64であることが多いため、通常はx64版を選びます。

| インストーラー種別 | 推奨される利用者 | 説明 |
| --- | --- | --- |
| Windows (x64) (User) | 個人PC、管理者権限なしで自分だけ使う場合 | 現在のユーザーだけにインストールします。迷った場合はこちらを選ぶと扱いやすいです。 |
| Windows (x64) (System) | 共有PC、全ユーザーで使う場合 | PC全体にインストールします。管理者権限が必要になる場合があります。 |
| Windows (ARM64) | ARM版Windows端末 | Surface Pro Xなど、ARM版Windowsを利用している場合に選びます。 |

| 手順 | 操作内容 |
| --- | --- |
| 1 | ブラウザで Cursor公式ダウンロードページ を開きます。 |
| 2 | Windows欄から端末に合うインストーラーを選びます。一般的な個人PCでは Windows (x64) (User) を推奨します。 |
| 3 | ダウンロードしたインストーラーを開きます。 |
| 4 | 画面の指示に従ってインストールを完了します。 |
| 5 | スタートメニューから Cursor を起動します。 |

初回起動後、サインインを求められる場合があります。個人利用であれば個人のメールアドレスやGitHubアカウント、業務利用であれば組織で指定されたアカウントを使用してください。

### 5.2 macOSへのインストール

CursorのmacOS版には、確認時点で Mac (ARM64)、Mac (x64)、Mac Universal が表示されていました。Apple Silicon搭載MacかIntel Macか分からない場合は、原則として Mac Universal を選ぶと安全です。

| インストーラー種別 | 対象Mac | 説明 |
| --- | --- | --- |
| Mac (ARM64) | Apple Silicon搭載Mac | M1、M2、M3、M4などのApple Silicon向けです。 |
| Mac (x64) | Intel Mac | Intel CPU搭載Mac向けです。 |
| Mac Universal | Apple Silicon / Intel両対応 | CPU種別が分からない場合に選びやすい形式です。 |

| 手順 | 操作内容 |
| --- | --- |
| 1 | ブラウザで Cursor公式ダウンロードページ を開きます。 |
| 2 | macOS欄から Mac Universal、または端末に合う Mac (ARM64) / Mac (x64) を選択します。 |
| 3 | ダウンロードしたファイルを開きます。 |
| 4 | 表示されたウィンドウで、Cursor を Applications フォルダへドラッグします。 |
| 5 | LaunchpadまたはApplicationsフォルダから Cursor を起動します。 |

macOSで初回起動時に警告が表示された場合は、公式サイトからダウンロードしたファイルかを確認した上で、システム設定のセキュリティ設定から許可してください。

### 5.3 VS CodeからCursorへ設定を移行する

すでにVisual Studio Codeを使っている場合は、Cursorへ設定を移行すると、拡張機能、テーマ、設定、キーバインドを引き継ぎやすくなります。Cursor公式ドキュメントでは、Cursor Settingsを開き、General > Account に移動し、VS Code Import の Import ボタンをクリックすることで、VS Codeの環境をワンクリックで移行できると説明されています。

| 手順 | 操作内容 |
| --- | --- |
| 1 | Cursorを起動します。 |
| 2 | Cursor Settings を開きます。ショートカットは macOS: ⌘ + Shift + J、Windows: Ctrl + Shift + J です。 |
| 3 | General > Account に移動します。 |
| 4 | VS Code Import の Import をクリックします。 |
| 5 | インポート完了後、拡張機能、テーマ、設定、キーバインドが反映されているか確認します。 |

手動でプロファイルを移行する場合は、VS Code側でコマンドパレットを開き、Preferences: Open Profiles (UI) からプロファイルをエクスポートします。その後、Cursor側で同じくProfiles UIを開き、Import Profile から取り込みます。

## 6. Acua Voiceの導入手順

Acua Voiceは、音声をテキストに変換し、さまざまなアプリやWebサイトの入力欄で使える音声入力ツールです。公式ダウンロードページでは、Acua VoiceをWindowsおよびMac向けに提供しており、Windows向けのセットアップファイルとMac向けのdmgファイルへのリンクが確認できます。

### 6.1 Windowsへのインストール

Windowsでは、公式ダウンロードページから Download for Windows を選択し、Aqua-Voice-Windows-Setup.exe をダウンロードします。

| 手順 | 操作内容 |
| --- | --- |
| 1 | ブラウザで Acua Voice公式ダウンロードページ を開きます。 |
| 2 | Download for Windows または Windows をクリックします。 |
| 3 | Aqua-Voice-Windows-Setup.exe がダウンロードされます。 |
| 4 | ダウンロードした .exe ファイルを開きます。 |
| 5 | 画面の指示に従ってインストールします。 |
| 6 | インストール後、Acua Voiceを起動し、必要に応じてサインインします。 |
| 7 | マイクへのアクセス許可を求められた場合は、内容を確認して許可します。 |

Windowsのプライバシー設定でマイクが無効になっていると、Acua Voiceが音声を取得できません。動作しない場合は、設定 > プライバシーとセキュリティ > マイク を開き、マイクアクセスが有効か確認してください。

### 6.2 macOSへのインストール

Acua Voiceの公式ダウンロードページでは、Mac向けとして Intel Mac のdmgファイルが確認できました。Apple Silicon搭載Macでの提供形式は、公式ページ上の表示や最新版の配布状況により変わる可能性があるため、インストール時には必ず公式ダウンロードページの最新表示を確認してください。

| 手順 | 操作内容 |
| --- | --- |
| 1 | ブラウザで Acua Voice公式ダウンロードページ を開きます。 |
| 2 | Mac向けのダウンロードリンクをクリックします。確認時点では Intel Mac が表示されています。 |
| 3 | ダウンロードした .dmg ファイルを開きます。 |
| 4 | 表示されたウィンドウで、Acua Voiceを Applications フォルダへドラッグします。 |
| 5 | ApplicationsフォルダまたはLaunchpadからAcua Voiceを起動します。 |
| 6 | 必要に応じてサインインします。 |
| 7 | マイク、アクセシビリティ、入力補助などの許可を求められた場合は、内容を確認して許可します。 |

macOSでは、音声入力アプリが正しく動作するために、マイク、アクセシビリティ、場合によっては入力監視や画面収録に関する許可が必要になることがあります。Acua Voiceの画面に案内が表示された場合は、その案内に従って システム設定 > プライバシーとセキュリティ から必要な権限を付与してください。

### 6.3 Acua Voiceの基本的な使い方

Acua Voiceは、カーソルがある入力欄に対して音声入力を行う設計です。公式ガイドでは、入力先（カーソルが置かれている場所）に応じて出力が適応すると説明されています。

| 手順 | 操作内容 |
| --- | --- |
| 1 | Acua Voiceを起動します。 |
| 2 | メモ帳、Obsidian、Cursor、ブラウザの入力欄など、文字を入力したい場所をクリックします。 |
| 3 | Acua Voiceの起動キーまたは画面上の操作で音声入力を開始します。 |
| 4 | 入力したい内容を自然に話します。 |
| 5 | 音声入力を停止し、入力されたテキストを確認します。 |
| 6 | 誤変換があれば、通常のキーボード入力で修正します。 |

音声入力の精度を上げるには、周囲の雑音を減らし、マイクに近い位置で一定の速度で話すことが重要です。最初は短い文章で動作確認を行い、慣れてから長文入力に利用してください。

## 7. 導入後の動作確認

3つのツールをインストールした後は、以下の表に従って最低限の動作確認を行ってください。ここで問題がなければ、基本的な導入は完了です。

| ツール | 確認内容 | 正常な状態 |
| --- | --- | --- |
| Obsidian | アプリが起動するか | 起動後、Vault作成または既存Vault選択画面が表示されます。 |
| Obsidian | Vaultを作成できるか | 指定したフォルダにVaultが作成され、ノート作成画面が開きます。 |
| Cursor | アプリが起動するか | エディタ画面が表示されます。 |
| Cursor | VS Code移行ができるか | 拡張機能、テーマ、設定、キーバインドが反映されます。 |
| Acua Voice | マイクを認識するか | 音声入力開始時に声が認識されます。 |
| Acua Voice | 任意の入力欄に文字が入るか | Obsidian、Cursor、ブラウザなどの入力欄へテキストが入力されます。 |

## 8. よくあるトラブルと対処方法

導入時に発生しやすい問題は、OSのセキュリティ設定、権限不足、誤ったインストーラーの選択、ネットワーク制限に関連することが多いです。以下の表を確認し、該当する対処を試してください。

| 症状 | 対象ツール | 主な原因 | 対処方法 |
| --- | --- | --- | --- |
| ダウンロードできない | 全ツール | ネットワーク制限、ブラウザ設定、セキュリティソフト | 公式URLを確認し、別ブラウザや別ネットワークで試します。会社端末では管理者に確認します。 |
| インストーラーを開けない | 全ツール | OSのセキュリティ警告 | 公式サイトから取得したファイルか確認し、OSのセキュリティ設定で許可します。 |
| Cursorの種類が分からない | Cursor | x64 / ARM64、User / Systemの違い | 一般的な個人Windows PCでは Windows (x64) (User)、Macでは Mac Universal を選びます。 |
| VS Code設定が移行されない | Cursor | インポート操作未実施、プロファイル不一致 | Cursor Settingsの General > Account > VS Code Import を確認します。 |
| 音声入力できない | Acua Voice | マイク権限が無効 | OSのプライバシー設定でマイクアクセスを許可します。 |
| 入力先に文字が入らない | Acua Voice | カーソル位置が入力欄にない、アクセシビリティ権限不足 | 入力欄をクリックしてから再試行し、必要な権限が許可されているか確認します。 |
| Obsidianのノート保存場所が分からない | Obsidian | Vaultの保存場所を確認していない | Vault作成時に指定したフォルダを確認します。Vaultはローカルフォルダです。 |

## 9. 推奨する初期設定

導入直後は、すべての機能を細かく設定するよりも、まずは「正しく起動する」「保存場所が分かる」「入力できる」状態を作ることが重要です。その上で、以下の設定を行うと日常利用に移行しやすくなります。

| ツール | 推奨設定 | 理由 |
| --- | --- | --- |
| Obsidian | Vaultを分かりやすい場所に作成する | ノートのバックアップや同期設定を後から行いやすくなります。 |
| Obsidian | 最初にテスト用ノートを1つ作る | 保存と編集が正常に行えるか確認できます。 |
| Cursor | VS Code利用者は設定をインポートする | 既存の開発環境に近い状態で使い始められます。 |
| Cursor | サインイン状態を確認する | AI機能やアカウント連携を利用しやすくなります。 |
| Acua Voice | マイク入力テストを行う | 認識精度や権限設定の問題を早期に発見できます。 |
| Acua Voice | よく使うアプリで短文入力を試す | ObsidianやCursorとの組み合わせで実用性を確認できます。 |
