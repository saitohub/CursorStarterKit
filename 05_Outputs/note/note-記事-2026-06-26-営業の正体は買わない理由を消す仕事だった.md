## この記事でわかること

- 営業は「売る仕事」じゃなかった。本当の定義
- 「セールスイズ」の核心：買わない理由を消す7つのプロセス
- 「セールスイズ2」の核心：聞くな、問え。ファクトファインディングという技術
- noteやSNSで発信してる人にも刺さるポイント

※この記事は営業職じゃない人・個人で発信してる人向けです。開発者向けの話ではありません。

## 「営業＝売り込む仕事」だと思ってた

正直に言います。
「営業」って聞くと、テレアポ、飛び込み、ノルマ、根性。そういうイメージでした。

でもこの本、最初の数ページで認識がひっくり返された。

**営業とは「買わない理由を消していく仕事」**だと。

売り込むんじゃない。
お客さんが「買わない理由」を一個ずつ丁寧に取り除いていく。
その結果、「じゃあ買います」が自然に出てくる。

これ、めちゃくちゃ衝撃でした。

## セールスイズ：科学的に成果をコントロールする

著者の今井晶也さんは、営業支援会社セレブリックスの執行役員。1100社、12000商品の営業を支援してきた人。累計10万部突破のベストセラー。

この本の哲学はシンプルで強烈。

**「営業はセンスでも根性でもない。科学だ」**

成果を出す人と出さない人の差は「売り方」じゃなくて「考え方」にある。
そして考え方は、プロセスに分解できる。分解できるものは再現できる。

### 7つの営業プロセス

セレブリックスが体系化した営業の7ステップがこれ。

1. **アカウントプラン** — 勝ち筋を見つける準備
2. **アプローチ** — 最初の3秒で8割が決まる
3. **ファクトファインディング** — 表面の悩みじゃなく根本原因を掘る
4. **オーダーコントロール** — 決裁者を特定して味方にする
5. **企画設計** — 提案書は「起→転→承→結」で感情を動かす
6. **プレゼンテーション** — 一方的に話すんじゃなくて対話する
7. **クロージング** — 押すんじゃなくて、納得を後押しする

面白いのは、提案書の構成が「起承転結」じゃなくて**「起転承結」**なこと。
最初に課題（転）をぶつけて危機感を作る。普通の順番じゃない。

### お客さんが買うのは「商品」じゃない

ここが一番刺さったポイント。

お客さんが契約するのは、商品そのものじゃない。
**「問題解決への可能性」**を買ってる。

つまり営業は「商品の説明係」じゃなくて、**「課題の翻訳者」**。
お客さんの言葉にならない悩みを言語化して、解決の道筋を見せる人。

これ、noteで記事を書くときもまったく同じじゃないですか。

読者が求めてるのは「情報」じゃなくて「自分の問題が解決する可能性」。
記事のタイトルも、内容の構成も、この視点で考えると全然変わる。

### 10のルールから特に刺さった3つ

本書には営業の10ルールがあるんですが、個人の発信にも効くものを3つ抜きます。

**① 商品説明をしない**
いきなり「これいいですよ」って言わない。相手の課題を先に聞く。
noteの記事でいうと、冒頭で「こんないい方法があります！」って始めるんじゃなくて、「こんな経験ありませんか？」から入る。

**② 失注（失敗）から学ぶ**
成功体験より、失敗のほうが学びが多い。
読まれなかった記事、反応がなかった投稿。そこに次のヒントがある。

**③ 行動量が確率を上げる**
「量より質」じゃない。量をこなすから質が上がる。
まず出す。反応を見る。直す。この繰り返し。

## セールスイズ2：「聞くな、問え」

2026年5月に出た続編。360ページの大作。
テーマは**ファクトファインディング**。

今井さんが20年の営業人生でたどり着いた結論がこれ。

**「売れる営業は、何を話すかじゃなくて、何を問うかで決まる」**

### ヒアリングとファクトファインディングの決定的な違い

ここが本書で一番面白いところ。

| | ヒアリング | ファクトファインディング |
|---|---|---|
| やること | 相手の話を聞く | こちらから問いを投げる |
| 見つかるもの | 顕在的な課題（相手が自覚してるもの） | 潜在的な課題（相手がまだ気づいてないもの） |
| スタンス | 受け身 | 能動的 |
| 効果 | 相手が言語化できてる範囲で止まる | 相手の認識を根底から変える |

普通の営業は「お困りのことはありますか？」と聞く。
でもそれだと、相手が自覚してる問題しか出てこない。

ファクトファインディングは違う。
**相手がまだ気づいてない課題を、問いかけで一緒に発見する。**

「興味ありません」が「提案ありがとう」に変わる瞬間が、ここで生まれる。

### 3ステップと7つのファクト

具体的な進め方がめちゃくちゃ実践的。

**ステップ1：事業理解（相手のビジネスを知る）**
- コンセプト、ターゲット、商品、背景を把握する
- 「このサービスが生まれた背景は？」「大切にしてる観点は？」

**ステップ2：問題発見（現状 − 理想 ＝ 問題）**
- 今どうなってるか → どうなりたいか → そのギャップが「問題」
- ここで相手の共感を得る

**ステップ3：課題設定（原因 ＋ 示唆 ＝ 課題）**
- なぜその問題が起きてるのか（原因の深掘り）
- このまま放置するとどうなるか（示唆＝気づきを与える）
- じゃあ何に取り組むべきか（課題の定義）

この3ステップで引き出す「7つのファクト」がこう。

1. ビジネスモデル
2. 現状
3. 理想
4. 問題
5. 原因
6. 示唆
7. 課題

順番に聞いていくと、相手が自然に「あ、確かにそれ課題だわ」と気づく設計になってる。

## 著者・今井晶也さんのエピソードが面白い

今井さん、実は元役者志望。
営業の世界に入ったとき、最初の受注まで**半年かかった**そうです。

半年ですよ。毎日営業して、半年ゼロ。
普通なら心が折れる。

でも上司が信じ続けてくれた。
そして一度売れたら、1〜2ヶ月で次々と受注が出るようになった。

今井さんはこう言ってます。

**「どんな状況でも『トップセールスを演じろ』」**

お客さんの前では、世界で一番のトップセールスでいる。
演じるんです。最初は嘘でもいい。そのうち本物になる。

元役者志望の今井さんだからこそ説得力がある言葉。

そしてもう一つ。

**「営業ほどクリエイティブな仕事はない」**

「売り込む」と捉えると苦しい。
でも「自分ならではの発想を展開できる創造型の仕事」と捉えれば楽しくなる。

これ、noteの発信にもそのまま当てはまりますよね。
「書かなきゃ」じゃなくて「自分の発想を形にする創造の時間」。
同じ作業でも、捉え方で全然変わる。

## noteやSNSで発信してる人に持ち帰ってほしいこと

この2冊を読んで、営業の話なのに自分の発信に直接効く気づきがいくつもあった。

**1. 読者の「読まない理由」を消す発想で書く**
記事を読んでもらえないとき、「もっといい内容を書かなきゃ」と思いがち。
でも本当に必要なのは、「読まない理由」を一個ずつ消すこと。
タイトルが自分ごとに見えない？ 冒頭が長すぎる？ 誰向けかわからない？

**2. 説明するな、問いかけろ**
「こうすればいいですよ」より「こんな経験ありませんか？」のほうが刺さる。
ファクトファインディングの考え方は、記事の書き出しにそのまま使える。

**3. お客さん（読者）が買うのは「問題解決の可能性」**
記事の価値は情報量じゃない。
「これを読んだら、自分の問題が少し前に進むかも」と思えるかどうか。

**4. 量をこなすから質が上がる**
「完璧な1本」より「80点の3本」。
出してみないと、何が刺さるかわからない。

## まとめ：営業の正体は「相手の未来を一緒に見る仕事」だった

セールスイズが教えてくれたのは、営業の「型」。
セールスイズ2が教えてくれたのは、その型の中で最も強力な武器＝「問いの技術」。

どっちも共通してるメッセージはこれだと思う。

**売ることを考えた瞬間、主語が自分になる。
でも本来、営業はお客さんが変わるために行動する仕事。**

これ、発信も同じ。
「読まれたい」「稼ぎたい」が先に来ると、主語が自分になって読者が離れる。

「この人が次の一歩を踏めるように」。
その視点で書けば、記事も自然と届くようになる。

さて、今日の記事を読んで「確かにそうだな」と思ったあなた。
まずやることは1つ。

**今ある下書きを1本、「読者の買わない理由を消す」視点で書き直してみてください。**

冒頭3行を変えるだけでも、反応は変わります。
