### はじめに

夜に学んで、朝には消えている。

40代以降の多忙な会社員にとって、これが一番の問題だと思っています。時間がない中でインプットしても、翌朝には「なんか読んだ気はするけど…」になる。**開発者向けではありません**。コードを書く記事でもありません。

このnoteは、夜30分しか時間がない忙しい会社員が「声で出して、翌日の自分に引き継ぐ」ための設計ノートです。

---

私もそうでした。

本やセミナーで聞いたことをそのまま書き写して、覚えようとはしていた。でも続かずに忘れ去られていく。見返すこともしない。

今思うと、**自分ごとに変換できていなかった**から、他人ごとのように見えてしまって、気持ちが湧かなかったんだと思う。

今まで手で書いたり、キーボードで書いていたとき、なんかカッコつけて**賢いフリをしたメモ**になっていた。思っていることをそのまま残さず、難しい言い回しに固めたり、本っぽい言葉に寄せたりして、あとから行動しようとしたら意味が分からなくなるタイプ。

音声入力を始めたら、たどたどしくてもよくなった。「わかんない」「この言葉が出てこない」と言いながら、「うわぁ、ちょっと悔しいなぁ」という感情が出てきたりする。でもそのあと、「調べればできるじゃん」「次はこうしよう」というひらめきがいっぱい出てきた。

なぜかというと、**本音で喋っているから**。感情が吐き出せてすっきりする。分からなくても、納得いかなくても、吐き出してるから頭の中はすっきりする。感情的な摩擦がないので、**次の行動に行きやすい**というのが自分の体験。

## ■ 有料パート（鍵の向こう側にコピペ）

### 1. 1週間で詰まりやすい3つ（要約しない理由つき）

**1. 生の声を、いきなりAIで要約して保存してしまう**

これが一番もったいない。要約すると、感情・言葉が詰まった箇所・言い淀みが全部消える。するとまた「賢いフリのメモ」に戻る。生の声は**必ず残す**。別枠で、それを読んだAIに質問を出させて答えていく、が正しい順番。

**2. なんでもAIエージェント／エディタ任せにして指示だししすぎる**

自分が追いつかない速度でAIがどんどん進んでしまい、コントロール不能になりやすい。知識をつけながら、**自分がコントロールできる範囲内で小さくやる**。

**3. 音声入力のエラーでイラついて止まる**

エラーは起きる。でも習慣化できていれば、そのイライラごと声に出せばいい。パソコンやスマホのエラーで止まっているなら、スクショを**無料枠のAI（Gemini・ChatGPTなど）**に貼って聞くだけで解決することが多い。

### 2. 私の運用：iPhoneメモ → Mac → Obsidian →（余力で）AI

**スマホ（iPhone）**：メモ帳を開いて、カーソルを合わせて、マイクボタンで音声入力。iPhoneのメモ帳はMacと連携しているので、スマホ側に入れればMacのメモ帳にも自動で反映される。

最初はショートカットで「即音声」みたいに仕込もうとしたが、めんどくさくなって今は普通にメモ帳を開いてやっている。**他のショートカットを増やしすぎるのは自分には時間の無駄**だった。できる人は早くやればいいが、まず**「喋ってメモに残す」本丸を先に固める**方が早い。

**パソコン（Mac）**：家に帰ってパソコンを開いたら、メモ帳からObsidianに貼り付ける。エネルギーがあるときはCursorに投げて壁打ち。めんどくさいときはObsidianに貼って終わり。時間があるときに深掘りする。

**AIの使い分けルール**：課金しているAIに無駄に編集や雑談をしすぎると、制限に早く達する。だから**基本は無料AI**から入り、最後の最後だけ課金AI（スタメン）を使う。無制限に近い枠でも、調子に乗ると消費が跳ねるので注意。

**3ステップ（まとめ）**

1. スマホのメモ帳に声で話して貼り付ける
2. AIと壁打ちしたいなら、メモをもとに**自分で質問を考えるより、AI側に質問させる**（コーチングっぽく深掘り）
3. 1週間〜1ヶ月たまったら振り返る（自分はリズム未固定だが、決めた方がいいとは思う）

### 5. 爆速執筆プロンプト（v1 → v2 → v3）

> 習ったテンプレをそのままではなく、**自分用に変えたプロンプト**として収録。禁止事項は自分版に調整してよい。

#### v1（最初に動かしたプロンプト）

```
以下は私のメモ（生の声のまま）です。
まず要約して、次にやることを3つに絞ってください。
```

**何が足りなかったか**：要約が先に来ると、言い淀み・感情・迷いが削られて「賢いメモ」側に寄る。自分語りとしての厚みが失われやすい。

#### v2

```
以下は私のメモ（生の声のまま）です。
要約はまだ不要です。まず、私が見落としている前提や抜けを指摘してください。
そのうえで、深掘りのための質問を5つ出してください（質問は短く）。
```

**直した点**：要約を禁止し、質問を増やした。ただし質問の作り方にまだ自分の頭が入る。

#### v3（主力）

```
以下は私のメモ（生の声のまま）です。

ルール：
- 要約しない。言い換えで"整った文章"にしすぎない。
- 私の感情の言葉（悔しい、怖い、モヤる等）があったら尊重する。
- あなたの仕事は「正解を出す」より「私が気づく質問」をすること。

やってほしいこと：
1) 私のメモから、論点を最大3つに分ける（分け方だけ示す）
2) 各論点について、私に返す質問を2つずつ（計6つまで）
3) 最後に「今日の一手」を1つだけ提案（小さく実行できるもの）

出力は日本語で。長すぎないこと。
```

**いつ使うか**：帰宅後3分でも10秒でも、声で吐き出した直後。習慣化が先。「もっと深掘りしたい」ときにコピペして渡す。  
**使わない／注意**：エージェントに丸投げで編集・構成を量産させる用途（コントロール不能・課金の無駄撃ちになりやすい）。

#### 5-1. ジャーナル型テンプレ（自分用プロンプト化版）

生の声のあと、次のカテゴリをタグや見出しで整理する想定：

- **ビジネス・仕事で気になったこと**（市場の動き、お客さんの反応、競合、自分の動き。小さな観察でよい）
- **今日エネルギーが上がった瞬間／下がった瞬間**（何が動かしたか／何が消耗させたか。蓄積するとコンテンツの種になる）

ビジネス・仕事の視点：

「今日のマーケット観察日記」
街の空気感、お客さんのふとした表情、ライバルの小さな違和感。そんな「名もなき変化」をキャッチした瞬間の記録。

エネルギーの波：

「心のエネルギー・ログ」
何が自分の感情を震わせ、何が自分をすり減らしたのか。一日の感情の『動き』を記録し、未来のコンテンツの種としてストックする。

2. 日報・自己研鑽向け（ロジカル＆具体的）
振り返りの精度を上げ、具体的な改善につなげやすくするリライトです。

ビジネス・仕事の視点：

「フィールド・リサーチと自己分析」
市場の微細な動向、顧客のリアクション、競合の施策。これらに対する自分の「打ち手」をセットで書き留める。

エネルギーの波：

「ハイ＆ロー・トラッキング」
高パフォーマンスを引き出した『トリガー』と、気力を奪った『ノイズ』の特定。自分の「勝ちパターン」を言語化するための記録。

3. 短文・SNS向け（キャッチー＆シンプル）
パッと見て「何をすべきか」が伝わる、リズム重視のリライトです。

ビジネス・仕事の視点：

「半径5メートルの市場調査」
日常の違和感や、顧客の『本音』が漏れた瞬間を逃さずストック。

エネルギーの波：

「感情のガソリン残量計」
何で満たされ、何で漏れたか。その波を知ることが、持続可能なビジネスの第一歩。

【活用アドバイス】
これをAqua Voiceで記録する際は、以下のように自分に問いかけるとスムーズです。

「今日、世の中で『おや？』と思ったことは何？」

「今日、一番『よっしゃ！』と思った瞬間と、逆に『ずーん』とした瞬間は何？」

こうして記録したものが、先ほど提案した「AIを資産に変える」という文脈での「独自の一次情報」として、note記事の価値をグッと高めてくれます。
