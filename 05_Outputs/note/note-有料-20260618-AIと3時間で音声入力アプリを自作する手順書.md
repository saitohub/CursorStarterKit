# AIと3時間で音声入力アプリを自作する手順書

私がやったことは、AIと話しながらターミナルにコピペしただけです。

コードは書いていない。「次に何をすればいいですか？」と聞いて、言われた通りにやった。

わからないことが出たら「これどういう意味？」「このエラーが出た」と伝えた。そうするとAIが「こうしてください」と言ってくるので、その通りに動いた。わからない用語が出てきたときは、その都度聞いたり、強引に進めたりした。それだけ。

この手順書は、その会話の過程をそのまま記録したものです。**私が実際にAIに聞いたこと・詰まったこと・AIが出してくれたコード**がそのまま入っています。

---

## 作業の全体像

ターミナルというのは、MacでCmd+Space→「ターミナル」と入力すると出てくる黒い画面のことです。

この作業は全て、**ターミナルを開きながらClaude Codeと話し、言われたコードをターミナルに入力していく繰り返し**になります。それだけです。

**一つだけ注意：** コードをコピペするとき、先頭や末尾に余分なスペースが入るとエラーになります。コードブロックの中身を正確にコピーすることが大切です。私も最初これでハマりました。

---

このnoteで作れるもの：
- Fnキーダブルタップで録音開始・終了
- OpenAI Whisperで自動文字起こし
- カーソルがある場所に自動貼り付け
- 月7時間11分使った場合の試算で約415円（使用時間によって変わります）

- **Mac**（MacBook / iMac どちらでも可）

> Claude Codeがなくても、この手順書のコードをそのままコピペすれば作れます。ただ、詰まったときにAIに聞きながら進めるほうが断然楽です。

## ステップ5：main.pyを作る

**AIが設計して、コードを全部書いてくれた。** 私は「Fnキーダブルタップで使いたい」「自動で貼り付けてほしい」「エラーのときは音声ファイルを残してほしい」と要望を言っただけ。

以下がAIが作ったコードの完成版。ターミナルで実行：

```
cat > ~/voice-input/main.py << 'PYEOF'
import io
import os
import sys
import datetime
import threading
import time
from pathlib import Path
from dotenv import load_dotenv
import numpy as np
import sounddevice as sd
import scipy.io.wavfile as wavfile
from openai import OpenAI
import pyperclip
import pyautogui
from pynput import keyboard

pyautogui.FAILSAFE = False

load_dotenv()

OPENAI_API_KEY = os.getenv("OPENAI_API_KEY", "")
HOTKEY = os.getenv("HOTKEY", "<cmd>+<shift>+<space>")
SAMPLE_RATE = 16000
LOG_FILE = Path("log.txt")
RECORDINGS_DIR = Path("recordings")

openai_client = OpenAI(api_key=OPENAI_API_KEY)


def check_config():
    if not OPENAI_API_KEY or not OPENAI_API_KEY.startswith("sk-"):
        print("エラー: .env に OPENAI_API_KEY が設定されていません。")
        sys.exit(1)


def append_log(text: str):
    timestamp = datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    with open(LOG_FILE, "a", encoding="utf-8") as f:
        f.write(f"[{timestamp}] {text}\n")


def save_error_recording(audio_data, sample_rate: int):
    RECORDINGS_DIR.mkdir(exist_ok=True)
    timestamp = datetime.datetime.now().strftime("%Y-%m-%d_%H-%M-%S")
    filepath = RECORDINGS_DIR / f"{timestamp}.wav"
    wavfile.write(str(filepath), sample_rate, audio_data.astype(np.float32))
    print(f"音声を保存しました: {filepath}")
    return filepath


class AudioRecorder:
    def __init__(self, sample_rate: int = SAMPLE_RATE):
        self.sample_rate = sample_rate
        self._frames = []
        self._lock = threading.Lock()

    def _callback(self, indata, frames, time, status):
        if status:
            print(f"[AudioRecorder] stream status: {status}", file=sys.stderr)
        with self._lock:
            self._frames.append(indata.copy())

    def start(self):
        if hasattr(self, "_stream") and self._stream.active:
            raise RuntimeError("Already recording")
        self._frames = []
        self._stream = sd.InputStream(
            samplerate=self.sample_rate,
            channels=1,
            dtype="float32",
            callback=self._callback,
        )
        self._stream.start()

    def stop(self):
        self._stream.stop()
        self._stream.close()
        with self._lock:
            if not self._frames:
                return None
            return np.concatenate(self._frames, axis=0)


def transcribe(audio_data: np.ndarray, sample_rate: int = SAMPLE_RATE) -> str:
    buffer = io.BytesIO()
    wavfile.write(buffer, sample_rate, audio_data.astype(np.float32))
    buffer.seek(0)
    buffer.name = "recording.wav"

    response = openai_client.audio.transcriptions.create(
        model="whisper-1",
        file=buffer,
        language="ja",
    )
    return response.text.strip()


def paste_text(text: str):
    pyperclip.copy(text)
    time.sleep(0.15)
    pyautogui.hotkey("command", "v")
    time.sleep(0.1)
    pyperclip.copy("")


def run():
    recorder = AudioRecorder(sample_rate=SAMPLE_RATE)
    is_recording = threading.Event()

    FN_KEYCODE = 179
    DOUBLE_TAP_INTERVAL = 0.4
    COOLDOWN_AFTER_PASTE = 2.0
    _last_fn_time = [0.0]
    _last_paste_time = [0.0]

    def on_toggle_with_cooldown():
        if time.time() - _last_paste_time[0] < COOLDOWN_AFTER_PASTE and not is_recording.is_set():
            return
        if not is_recording.is_set():
            is_recording.set()
            recorder.start()
        else:
            audio_data = recorder.stop()
            is_recording.clear()

            if audio_data is None or len(audio_data) < SAMPLE_RATE * 0.3:
                return

            def process():
                try:
                    text = transcribe(audio_data)
                    append_log(text)
                    paste_text(text)
                    _last_paste_time[0] = time.time()
                except Exception as e:
                    print(f"エラー: {e}")
                    save_error_recording(audio_data, SAMPLE_RATE)

            threading.Thread(target=process, daemon=True).start()

    def on_press(key):
        code = getattr(key, "vk", None)
        if code == FN_KEYCODE:
            now = time.time()
            if now - _last_fn_time[0] < DOUBLE_TAP_INTERVAL:
                _last_fn_time[0] = 0.0
                on_toggle_with_cooldown()
            else:
                _last_fn_time[0] = now

    listener = keyboard.Listener(on_press=on_press)
    listener.start()

    print("起動しました。Fnキーダブルタップで録音開始/終了")
    try:
        listener.join()
    except KeyboardInterrupt:
        pass
    finally:
        listener.stop()


if __name__ == "__main__":
    check_config()
    run()
PYEOF
```

## ステップ7：アクセシビリティ権限を設定する

**私がAIに言ったこと：**「キーが反応しない」

AIに聞いたらログに `This process is not trusted!` と出ていると言われた。Pythonがキーボードを監視する権限がないということ。

1. **システム設定** → **プライバシーとセキュリティ** → **アクセシビリティ**
2. 「+」ボタンをクリック
3. `Cmd+Shift+G` で `/usr/bin/` と入力 → `python3` を選択して追加
4. 追加された「Python 3」のスイッチをオンにする

権限を設定したら、ターミナルで `Ctrl+C` → `python3 main.py` で再起動。

## ステップ8：Mac起動時に自動で立ち上げる

**私がAIに聞いたこと：**「使うたびにターミナルを開かないといけないの？」

AIが「launchdという仕組みでMac起動時に自動起動できます」と教えてくれた。

毎回ターミナルを開かなくてもいいように設定します。

ターミナルで以下を実行：

```
cat > ~/Library/LaunchAgents/com.voice-input.plist << 'EOF'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
  "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key>
  <string>com.voice-input</string>
  <key>ProgramArguments</key>
  <array>
    <string>/usr/bin/python3</string>
    <string>/Users/あなたのユーザー名/voice-input/main.py</string>
  </array>
  <key>WorkingDirectory</key>
  <string>/Users/あなたのユーザー名/voice-input</string>
  <key>RunAtLoad</key>
  <true/>
  <key>KeepAlive</key>
  <true/>
  <key>StandardOutPath</key>
  <string>/Users/あなたのユーザー名/voice-input/stdout.log</string>
  <key>StandardErrorPath</key>
  <string>/Users/あなたのユーザー名/voice-input/stderr.log</string>
</dict>
</plist>
EOF
```

**「あなたのユーザー名」を自分のユーザー名に書き換えてください。**  
ユーザー名がわからない場合は、ターミナルで `whoami` を実行すると表示されます。  
（私はここをAIが自動で設定してくれたので、自分では確認しませんでした。）

書き換えたら以下で有効化：

```
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.voice-input.plist
```

## 実際に詰まったこと全記録

きれいな手順書には書かれていない、実際にハマった箇所を全部書く。

---

### 詰まり①：pip3のコマンドが「そんなファイルない」と言われる

コピペしたコマンドの**先頭に全角スペースが入っていた**。

```
　/usr/local/bin/pip3 install ...   ← 先頭の「　」が全角スペース
```

エラーメッセージは `zsh: no such file or directory` 。コマンド自体は合っているのに動かないときは、先頭や末尾に見えない文字が入っていないか疑う。Claude Codeからコピーするときは特に注意。

---

### 詰まり②：pip3のインストールがエラーになる

```
error: externally-managed-environment
```

このエラーが出たら、コマンドの末尾に `--break-system-packages` を追加して実行する。

```
pip3 install --break-system-packages openai pynput ...
```

「システムのPythonを壊すかも」という警告だが、今回のライブラリでは問題ない。

---

### 詰まり③：OpenAI APIキーは持っているのに「quota exceeded」エラー

ChatGPT Proを契約していても、**OpenAI APIの費用は別請求**。

同じメールアドレスでもアカウントは別扱い。`platform.openai.com` でクレジットを別途購入する必要がある。最低$5から。月7時間使っても$2.59なので$5が約2ヶ月持つ。

---

### 詰まり④：Fnキーが反応しない（「This process is not trusted」）

アクセシビリティ権限がないとキーボードの入力を検知できない。

ターミナルでスクリプトを起動しても何も起きないとき、ターミナルのログに以下が出ているはず：

```
This process is not trusted! Input event monitoring will not be possible
```

対処：**システム設定 → プライバシーとセキュリティ → アクセシビリティ** で「Python 3」をオンにする。

手順はステップ7に書いてある。設定後はスクリプトを再起動すること（Ctrl+C → python3 main.py）。

---

### 詰まり⑤：何を喋っても「ご視聴ありがとうございました」しか出ない

Whisperは録音が短すぎる・ほぼ無音のとき、**でたらめな文章を自信満々に返す**。

これはAIの「ハルシネーション」という現象で、空白の音声に対してそれっぽい文章を生成してしまう。

対処：Fnダブルタップで録音を開始したら、**2〜3秒以上しっかり喋ってから**止める。「録音してるかな？」と迷いながら小声で喋るのが一番ダメ。

---

### 詰まり⑥：Dockのアイコンがたまに揺れる

アプリが内部でクラッシュして、自動的に再起動を繰り返しているサイン。

このnoteのコード（ステップ5）をそのまま使っていれば発生しない。古いバージョンや途中で変更を加えた場合に起きることがある。コードを最初からやり直すのが早い。

---

### 詰まり⑦：貼り付けたあと、同じ文がもう一回貼り付けられる

Fnダブルタップで文字起こしが成功する → Enter送信 → もう一度Fnダブルタップしてしまう → 前回の録音がほぼ無音 → Whisperが同じ文章を返す → また貼り付けられる。

このnoteのコードには「貼り付け後2秒間はFnダブルタップを無視する」クールダウンが入っているので、この手順書通りに作れば発生しない。

---

### 詰まり⑧：貼り付けが終わってEnterを押したあと、次のFnダブルタップで前の文がまた出てくる

macOSの標準「音声入力（Dictation）」機能もFnダブルタップで起動する。

自作アプリとmacOS音声入力が同時に動いてしまい、macOS側が前の文を貼り付けていた。

対処：**システム設定 → キーボード → 音声入力 → オフ**

これだけで解決した。Fn双方タップを使う場合は必ず最初にオフにしておく。

---

### 詰まり⑨：Fnダブルタップのリズムがむずかしい

「素早く2回」の感覚は人によってバラつく。

- 速すぎる → 1回しか認識されない
- 遅すぎる → 2回目が別の1回目と認識される

コツは「パン、パン」と手拍子するくらいのリズム。0.4秒以内に2回タップすればOK。慣れれば意識しなくなる。
