# 一体、何が「コピペ不要」になったのか？

> Cursor Proをやめたら、ジャーナル→noteの清書コピペだけが消えた話（多忙な会社員の検証メモ）

---

一体、何が

**コピペ不要**

になったのか？

というと、、

+------------------------+

【先に結論だけ知りたい方へ】

- **上の画面**：無料のCursorは、ジャーナルを**自分の言葉で静かに書く場所**のまま使う
- **下の画面**：ターミナルで `claude`（Claude Code）に頼むと、**ファイルの作成・保存まで**AIがやってくれる
- **ルール**：`.cursor/rules` の中身を、一度だけ **CLAUDE.md** にコピペすればよい

「人生が完全自動化」ではありません。  
私が体験したのは、**清書のコピペ地獄だけが消えた**、という話です。

詳しい話は、このまま読んでください。

ジャーナルを書いて、

**事実ベースのメモ**です。

エンジニア系の記事で

​

「Cursor Pro（月20ドル）をやめて、

無料Cursorのまま

**Claude Code**（ターミナルで動くAI）に寄せる」

​

……正直、

最初は私も

「え、黒い画面？」

でした。

​

**Claude Codeって、

開発者向けでしょ？**

​

でも2026年5月22日、

私はVaultのなかで

Node.jsとnpmを入れて、

`claude` コマンドまで

到達した日でした。

​

（ログインと課金の整理は、

そのあと続き。

完璧に終わった話ではない。

ここは事実として書きます）

​

その夜、

ふと気づいたんです。

​

**消えたのは、AIの賢さじゃない。**

**消えたのは、私の「コピペの手」だった。**

## 体験：Cursor Proの「右チャット」は、結局ワンナイトだった

毎日の流れ、

だいたいこうでした。

​

1. Obsidian（Vault）かCursorで、

   **ジャーナル**（日記・思考ログ）を書く

2. 右側のChatやComposerに、

   「このジャーナルをnoteの構成にして」と頼む

3. AIがいい感じの文章を返す

4. **自分でコピーして、別ファイルに貼る**

5. ファイル名を整えて、保存

6. noteに貼り付けて公開……

​

わかりますよね。

​

AIは助けてくれる。

でも、

**「作業」は自分の手に残る。**

​

私は何度も書いてきました。

ChatGPTの **ワンナイトAI**——

その場限りで終わる対話——

を卒業したい、と。

​

なのに、

Cursorの右チャットだけ、

**セッションが終わると、

「清書の手順」は毎回リセット**

されていた。

​

週次振り返り（5月23日）でも、

同じ盲点が出ました。

​

note（Outputs）に書けば、

ジャーナルには要らない——

そう錯覚していた。

​

成果物は残る。

**過程と、清書の手間**は残りにくい。

## 転換：画面が「上下」に分かれた日

無料Cursor ＋ Claude Code に寄せると、

私の画面の使い方は、

こう変わりました。

​

```
+---------------------------------------------------------+
| [ journal.md ]  ← 【静】自分で書く。Tab補完に邪魔されない  |
|                                                         |
|  ・今日の振り返り...                                     |
|                                                         |
+---------------------------------------------------------+
| [ ターミナル ]  ← 【動】AIがファイルまで触る              |
|                                                         |
| $ claude                                                |
| 「journal.mdを元に、note用の下書きを作って保存して」       |
| → article.md を作成・保存した、と返ってくる              |
+---------------------------------------------------------+
```

​

会話の相手が

**下に引っ越した**、

というイメージです。

​

何より大きかったのは、

**「提案して終わり」じゃなく、

保存まで終わる**

こと。

​

コピペの往復が、

一気に薄くなった。

​

これは、

「記事が自動でバズる」

みたいな話じゃないです。

​

**地味な作業が、地味に減った。**

——そこだけ、はっきり体感があります。

## コストの話：20ドルは「消えた」わけじゃない

ここ、

誤解されやすいので

事実だけ書きます。

​

Cursor Proの月20ドルをやめても、

**コストがゼロになるわけではない**。

​

Claude Codeを動かす選択肢は、

だいたい次の2つです。

​

**① Claude Pro（月額20ドル程度）【私はこちらを検討】**

- すでにWeb版Claudeに課金している人は、追加がない場合もある
- 日記の清書・週1本のnote程度なら、定額の安心感が大きい

**② APIの従量課金**

- たまに使うなら安く見える
- ただしClaude Codeは自律で何度も読み書きするので、  
  **放置＋長文丸投げ** でトークンが溶ける、という注意は本当にある（テック系でも話題）

​

私にとっては、

**予算の「置き場」をCursorからClaudeへずらした」**

くらいの感覚です。

​

安くなった、と言い切ると嘘になる。

​

**同じ20ドル帯で、

手作業が減る方向に寄った**

——ここまでが、今の正直なところです。

## ルールの引っ越し：1分で終わる（自動移行はない）

Cursorで育てたルール、

**「トーンはです・ます」**

**「事実と根拠」**

**「煽らない」**

​

これ、

Claude Code側に移す手順は単純です。

​

1. プロジェクトのルートに **CLAUDE.md** を新規作成
2. `.cursor/rules` や `.cursorrules` の中身を、そのまま貼る
3. ターミナルで `claude` を起動

​

自動移行はない。

でも、

**1回コピペで終わる。**

​

私の体感では、

Cursorのルールは

たまに「忘れた」感じがあった。

​

CLAUDE.md への忠実度は、

今のところ高い。

​

だから、

**健一さん向けの文体**

（話し言葉・次の一行・開発者向けではない）

も、

清書のときに崩れにくい。

## 向いている人・向いていない人

**向いている人**

- Tab補完に邪魔されず、**自分の言葉で**ジャーナルを書きたい
- 清書・ファイル整理・保存の **作業** はAIに渡したい
- ルール（ペルソナ・禁止事項）を、一度書いて守らせたい

**向いていない人（この記事では追わない）**

- Cursorを業務で毎日フル活用している人
- コード習得が主目的の人
- 「月収◯万」の再現性だけ欲しい人

## 次の一行（あなたへ）

今夜30分でできることは、これだけです。

​

1. `.cursor/rules` のなかから、いちばん大事なルールを1ファイル選ぶ

   **「今日のジャーナルを、note用の下書き1本にして保存して」** と1回だけ試す

**「どこで手が止まったか」**

をジャーナルに3行書けば、

来週の自分に引き継がれます。
