# 2ヶ月分の日記に「怒り」がゼロだった話

こんにちは。サイジムです。

今日は「感情に蓋をしてた自分に気づいた話」を書きます。発信とか副業で、なんか動けない・続かないって人に届くといいなと思って書いてます。精神論じゃなくて、最後に1分でできるワークも置いとくので、そこだけ持って帰ってもらえればOKです。

きっかけは、自分の日記でした。

僕、AIを使って日記をつけて2ヶ月になります。感情が動いた瞬間に絵文字をつけてたんですよ。「😍嬉しい」「😭しんどい」「💡ひらめき」みたいに。で、怒ったときは「😡」をつける、って決めてました。

ある日ふと、「😡」だけ検索してみたんです。

……一個もなかった。

2ヶ月間、僕は何にも怒ってなかったことになってた。いやいや、おかしいでしょw 毎日noteを書いても反応ゼロだし、人のプロフィール見て勝手に凹んでるし、ムカつくことなんて山ほどあったはずなんですよ。

なのにゼロ。これ、怒ってなかったんじゃない。**怒りに蓋をして、マークを付けることすらできてなかった**んです。そもそも自分が「怒る」っていう感情を、自分に許してなかった。気づいたとき、地味にゾッとしました。

ちょうどそのタイミングで、学んでる講座で「ムカついたことを書き出すワーク」っていうのをやったんです。普段は絶対使わない「くそ」「ぼけ」みたいな言葉も込みで、10分ひたすら吐き出す。

やってみたら、出るわ出るわw 自分の中にこんなに溜まってたのか、ってくらい。

で、書いてて一個わかったことがあって。

**怒りに蓋をするって、本音に蓋をすることなんですよ。**

「これがムカつく」の裏には、たいてい「本当はこうしたい」「本当はこれが大事」っていう自分の本音が隠れてる。怒りを感じないようにしてると、ラクなようでいて、**自分が何を大事にしてるのかも一緒に見えなくなる**。だから「やりたいことが分からない」「なんか動けない」になっていく。

もちろん、怒りを人にぶつけてまわれって話じゃないです。それはただの八つ当たりなんで。そうじゃなくて、**まず自分の中で、感じることだけは自分に許してあげる。** それだけで全然違いました。

実際、書き出した怒りの紙を眺めてると、最後はぜんぶ「で、お前は本当はどうしたいの?」に行き着くんですよ。怒りって、本音への入口だったんです。

なので、最後に。いきなり1時間やると疲れるんで、**1分でできる版**を置いときます。

**【1分・怒りの蓋を開けるワーク】**
1. 今日「ちょっとイラッとした瞬間」を1つ思い出す
2. スマホのメモに、その相手・モノへの文句を3語だけ殴り書き（きれいにしない）
3. 最後に「で、自分は本当はどうしたかった?」と1行だけ足す

これだけ。きれいに書かなくていいし、誰にも見せなくていい。

あなたが最近、蓋をしてしまった怒りは、なんですか?

それ、たぶんあなたの本音の入口です。まず1分、感じることから始めてみてください。
