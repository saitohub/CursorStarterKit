# 10分バックアップは動いていた。動いていなかったのは、スマホの“保存場所”だけ

> 誰向け：Cursor／Obsidian を iCloud でつなぎ、スマホでも書きたい多忙な会社員さん  
> 約束：同期の故障じゃなく「段違いのフォルダ」かもしれない、と気づける

---

## 体験：スマホで書いたのに、Cursor に無かった

Mac の Obsidian にメモを入れた。Cursor にも出てきた。ここまでは「つながった」と思った。

ところがスマホの Obsidian で追記したメモが、Mac の Obsidian にも Cursor にも出てこない。  
「iCloud、壊れた？」「スマホで繋いだら見れなくなった？」——その気持ち、まったくわかる。

10分ごとの GitHub バックアップも、以前は動いていたのに、今日の分が上がってこない。  
不安が二重になる。同期とバックアップ、どっちも疑う。

---

## 気づき：届いていた。場所が違っただけ

Mac 側を調べると、話はこうだった。

- **iCloud には届いていた**（ファイルの更新日時が動いていた）
- でも場所が **`CursorStarterKit` の外**——保管庫「サイジムの秘密基地」の**直下**
- Mac の Obsidian は **`CursorStarterKit` を入口**にしている
- Cursor も **`CursorStarterKit` だけ**をワークスペースにしている

つまり、

```
サイジムの秘密基地/          ← スマホの保管庫の“外枠”
├── 無題のファイル.md        ← スマホで作ったメモ（ここにあった）
└── CursorStarterKit/        ← Mac・Cursor が見ている“本番”
    ├── 01_Notes/
    └── 04_Journals/
```

**配送は成功している。番地が一段違っていた。**

「10分バックアップが止まった」ように見えた日も、実は **Git の対象フォルダの中に変更がなかった**だけ。  
外側にファイルができても、バックアップのループは「中身に差分なし」で止まる。正常な動きに近い。

---

## もう一つの体験：Delete Vault の英文

保管庫を直そうとして、スマホで **Delete Vault** まで行った。

画面にこう出た。

> Deleting this vault will delete all files in it. This action is irreversible.

これは「リストから外す」ではなく、**フォルダごと消す**警告。  
親の保管庫を消すと、中の **`CursorStarterKit` ごと消える**可能性がある。

**キャンセルした。** 正解だった。

iPhone の Obsidian には、Mac にあった「フォルダを保管庫として開く」が出てこなかった。  
Delete で無理に直そうとすると、最悪、本番ごと消す。

---

## 教訓：スマホだけルールが一段ある

Mac で保管庫を **`CursorStarterKit` に揃えた**のは大正解。

でも iPhone は、保管庫名が「サイジムの秘密基地」のままでもよい。  
**書くときのルールが一段だけ増える。**

| やること | 結果 |
|----------|------|
| 秘密基地の**直下**で新規メモ | iCloud には届く。**Cursor には出ない** |
| **`CursorStarterKit` に入ってから** `01_Notes` や `04_Journals` で書く | Mac Obsidian・Cursor・スマホで**同じファイル** |
| 保存後 **1〜2分待つ** | iCloud の遅れを吸収できる |

「リンクされる」というより、**同じ引出しを開いている**イメージの方が近い。

---

## チェックリスト（詰まったとき30秒）

1. スマホのファイル一覧で、いま **`CursorStarterKit` の中**にいるか  
2. Mac / Cursor で、同じパス（例：`04_Journals/2026-05-20.md`）を開いているか  
3. 親の直下に `無題のファイル.md` が増えていないか（増えていたら中へ移すか削除）  
4. Delete Vault の英文が出たら、**まずキャンセル**  
5. GitHub の履歴は「変更があったか」もセットで見る（変更なしならコミットも増えない）

---

## 着地

同期不良だと思って焦る前に、**保存場所の一段**を見る。  
10分バックアップは、**中に差分が入ったとき**に動く。

**次の一行：** スマホでメモを開く前に、ファイル一覧で **`CursorStarterKit` に入ったか**だけ確認する。

---

## 事実メモ（この話の根拠）

- Mac の保管庫：`CursorStarterKit` に統一済み  
- iPhone：保管庫は「サイジムの秘密基地」、執筆は `CursorStarterKit` 内で運用（B）  
- 親直下に作成された例：`無題のファイル.md`（iCloud 上で Mac に到着、Cursor ワークスペース外）  
- `2026-05-20.md` は `CursorStarterKit/04_Journals` 内で Mac・スマホ双方から参照可能だった
