## 1. はじめに：なぜ「声」なのか

**紙・手帳・メモの裏に書いていた頃、何が起きていたか**（体験談）
何が起きていたかを聞いたり、本を読んだり、セミナーを受けていたことをそのまま書き起こして、それを覚えようとしてやってみたりはするけど、続かずに忘れ去られていく。見返すこともしない、みたいな感じというより、自分ごとに変換できていなかったから、他人ごとのように見えてしまって、気持ちがわかなかった。
- 思いつきを書く → 「なぜ／何／次に何をするか」の整理まで言いかけ → **結局やっていない**、など具体で。
- 

**それが「資産」にならなかった理由**（自分なりの言い方で。断定しすぎない）
それが資産にならなかったのは、ただ単に自分がすぐに行動を何回も繰り返さないといけなかったからです。また、資産にしたくても何か、あの時メモしたよなっていうのを生活の中で思い出した時にも、そのメモがどこに行ったか探すのに苦労して、エネルギーを見失って結局疲れてしまう。
- 

**声の執筆を入れたあと、何が変わったか**（1文の要約＋後章への橋渡し）一番変わったのは、今まで紙とかキーボードで書いていたときは、なんかカッコつけて省略して**賢いフリをしたメモ**（思っていることをそのまま残さず、難しい言い回しに固めたり、本っぽい言葉に寄せたりして、あとから行動しようとしたら意味が分からなくなるタイプ）になっていたのが、今ではたどたどしくても、自分が今思ったこと、わかんないならわかんない、この言葉が出てこないならこの言葉が出てこないなどを言いながら、「うわぁ、ちょっと悔しいなぁ」っていう感情が出たりします。

でも、調べればすぐ簡単にできるかっていうのが出てきたり、次の行動をこうしようっていうひらめきがいっぱい出てきました。

「やったらやればいいだけじゃん」みたいな感じが出てきました。それは何でかっていうのを、実体験では多分本音で喋っているから、で、賢ったりしてないから、感情が吐き出せてすっきりしてるんだと思います。多分行動に今まで起こせなかったのは、自分で納得がいってないとか、分かりにくかったっていうのもあるんですけど、声を出したら分かんないんだけど納得もいってないんだけど吐き出してるから頭の中はすっきりしてるんですよね。

だから感情的な摩擦がないので、次の行動に行きやすかったっていうのが一応自分の体験です。

## 5. 「声」から「資産」へ：ワークフロー（無料／有料の境界はここで決める）

**カーソルがある場所**＝どのアプリを主戦場にしているか（Obsidian / Cursor / その他）

- 私はスマホならアイフォンのメモ帳に音声入力をして、Macと連携させてます。iPhoneのメモ帳はMacのメモ帳とリンクしているので、スマホ側に入れば**Mac側のメモ帳にも反映**される運用。
- 最初はショートカットで「即音声」みたいに仕込もうとしたが、今はめんどくささに負けて、**普通にメモ帳を開いてカーソルを合わせ、マイクボタンで音声入力**している。**他のショートカットを増やしすぎるのは、自分には時間の無駄**だった。できる人は早くやればいいが、自分は「手でできるところは手でやる」という割り切りで、**本丸の「喋ってメモに残す」**を先に固めた方がよかった、という反省。
- 最近はObsidianやAIはCursorも使う。**Cursorへのコピペ運用やVault連携の細部は、また別の記事で**書くかもしれない（このnoteの主役からは外してよい）。

**Cursorを使う／使わない（自分の分岐）**

- **時間・気分・トークン／お金**の兼ね合い。エネルギーがあるときだけCursor、めんどくさいときはObsidianに貼って終わり、もあり。
- **最大に失敗しやすいのは、課金しているAIに無駄に編集や雑多な相談をしすぎて、制限に早く達すること**。だから基本は**よく使う無料AI**から入り、**最後の最後**に課金しているAI（スタメン）を使う、という順番にしている。無制限に近い課金枠でも、調子に乗ると消費が跳ねる時があるので注意。

**音声のあと、必ずやっている3ステップ**（例：貼る → 整形 → 保存／タグ）基本的な使い方は、スマホだったらメモ帳に貼り付けでどんどん貼り付けていって、家に帰ったりしてパソコンを開いてObsidianに貼り付けます。Obsidianに貼り付けて、エネルギーがあったら自分はCursorっていうAIを使ってるので、そこに投げて壁打ちをしてもいいし、めんどくさい時はそのメモだけObsidianっていうのに、メモ帳からObsidianに貼り付けて終わりです。

なんか時間がある時は、それを貼り付けて深掘りしたりしています。

1. まず適当なメモの場所に音声で話して貼り付ける。
2. AIと壁打ちをしたかったら、このメモをもとに**自分で質問を捻るより、AI側に質問させる**（コーチングっぽく深掘り）。ポイントは**生の声を残したまま渡す**こと。
3. 1週間とか1ヶ月とかになったら、そのメモを振り返る（自分は日付固定ではなく適当だが、**リズムを決めた方がいい**とは思う）。

**Aqua VoiceのHistory（自分の見方）**

- アプリを立ち上げて左メニュー真ん辺あたり。**過去の文字起こしを見る**ときと、**くるくるやエラーが出たときに見に行く**とき。
- 文字起こしは無いが「◯分前に記録」みたいに**音声だけ残っている**ことがある。その場合は**下矢印のダウンロード**で音声を落として、適当なAIに入れて文字起こし、を何回かやった。

**職場・家族の近くで声が出しづらい人へ（自分なら）**

- スマホを持って**外に出る**。**電話のフリ**をして音声入力（通勤で家から駅の間は最初恥ずかしかったが、電話してる感覚でやった）。散歩ついでも可。周りは、道で電話している人の内容を覗き見していないのと同じで、**そこまで気にしていない**という割り切り。

**音声データの保存・削除**

- 目的が決まっているなら、目的に沿わないものは**取捨選択**した方がゴミが減る。目的を決めずに溜めると、また「なんで書いたか分からないメモ」が増える。整理はAIにも手伝ってもらいつつ、**目的に沿わないものは捨てる**意識を持つ。

## 6. 爆速執筆プロンプト（v1 → 失敗 → v2 → いま）

> **有料で出す想定**：習ったテンプレを「そのまま」ではなく、**自分用に変えたプロンプト**として収録する。人によって地雷は違うので、プロンプト内の禁止事項は自分版で調整する。

### 6-0. 有料に入れる「ジャーナル型テンプレ」（骨子・下書き）

次のような観察カテゴリを、**生の声のあと**にタグや見出しで整理する想定（本文は自分用に整備してから有料に入れる）。

- ビジネス・仕事で気になったこと（市場、お客さんの反応、競合、自分の動き。小さな観察でよい）
- 今日エネルギーが上がった瞬間／下がった瞬間（動いた理由／消耗の理由。蓄積すると種になる）

### 6-1. v1（最初に動かしたプロンプト）

```text
以下は私のメモ（生の声のまま）です。
まず要約して、次にやることを3つに絞ってください。
```

**何が足りなかったか**

- **要約が先**に来ると、言い淀み・感情・迷いが削られて「賢いメモ」側に寄る。**自分語りとしての厚み**が失われやすい（自分の失敗パターン1と同型）。

### 6-2. v2

```text
以下は私のメモ（生の声のまま）です。
要約はまだ不要です。まず、私が見落としている前提や抜けを指摘してください。
そのうえで、深掘りのための質問を5つ出してください（質問は短く）。
```

**直した点**

- **要約を禁止**し、質問を増やした。ただし「質問の作り方」はまだ自分の頭が一部入る。

### 6-3. v3（主力）

```text
以下は私のメモ（生の声のまま）です。

ルール：
- 要約しない。言い換えで“整った文章”にしすぎない。
- 私の感情の言葉（悔しい、怖い、モヤる等）があったら尊重する。
- あなたの仕事は「正解を出す」より「私が気づく質問」をすること。

やってほしいこと：
1) 私のメモから、論点を最大3つに分ける（分け方だけ示す）
2) 各論点について、私に返す質問を2つずつ（計6つまで）
3) 最後に「今日の一手」を1つだけ提案（小さく実行できるもの）

出力は日本語で。長すぎないこと。
```

**いつ使うか／使わないか**

- **使う**：帰宅後3分でも、10秒でも1行でもよいから**声で吐き出した直後**。習慣化が先。吐き出したあと「もっと深掘りしたい」ときに、**コピペして**このv3に渡す。
- **使わない／注意**：エージェントに丸投げで編集や構成を量産させる用途（コントロール不能・課金の無駄撃ちになりやすい）。

**補足（AIの使い分け・自分のルール）**

- 基本は**よく使う無料AI**。課金している「スタメン」は**最後の最後**。無制限に近くても、調子に乗ると消費が跳ねる。
