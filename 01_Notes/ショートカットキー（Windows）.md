# ショートカットキー（Windows）

覚えると作業速度が倍になる。最初は⭐️5つだけでいい。

---

## Cursor

### ⭐️⭐️⭐️⭐️⭐️

- AIチャットを開く / 閉じる
	- Ctrl + L

- コマンドを呼び出す（/weekly-journal 等）
	- チャット欄で `/` を入力 → コマンド名を選択

- ファイル名で検索して開く
	- Ctrl + P

- メッセージを送信する
	- Enter

- 改行する（送信せずに）
	- Shift + Enter

### ⭐️⭐️⭐️⭐️

- ファイルをチャットに添付する（@参照）
	- チャット欄で `@` を入力 → ファイル名を選択

- 音声入力を起動する
	- Win + H

- 新しいチャットを始める
	- Ctrl + R（チャット欄にカーソルがある状態で）

### ⭐️⭐️⭐️

- サイドバーを開く / 閉じる
	- Ctrl + B

- 設定を開く
	- Ctrl + ,

---

## Obsidian

### ⭐️⭐️⭐️⭐️⭐️

- 新しいノートを作る
	- Ctrl + N

- テンプレートを挿入する
	- Ctrl + T

- コマンドパレットを開く
	- Ctrl + P

- Markdownのアシスト
	- /

### ⭐️⭐️⭐️⭐️

- ファイル名で検索して開く
	- Ctrl + O

- 単語で検索する
	- Ctrl + F

### ⭐️⭐️⭐️

- 設定を開く
	- Ctrl + ,

- 前の画面に戻る
	- Ctrl + [

- 先の画面に進む
	- Ctrl + ]

- 再起動する
	- Ctrl + Shift + R
