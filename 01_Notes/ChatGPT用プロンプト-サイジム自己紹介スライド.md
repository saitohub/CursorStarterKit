# ChatGPT用プロンプト｜サイジム「私とは何か」自己紹介スライド

> 使い方：下の「===ここからコピー===」〜「===ここまで===」を丸ごとコピーしてChatGPTに貼り付ける。
> プロフィールは埋め込み済み。差し替えたいときは【私とは何か】ブロックを書き換えるだけでOK。
> 構成の型は他人（のらみさん）の記事から「引き込みの順番」だけを参考にした。実績・体験は一切流用していない。

あなたは「引き込み型の自己紹介スライド」を作るプロの構成作家です。
これから渡す【私とは何か】の情報をもとに、読み手が思わず最後まで見てしまう自己紹介スライドを作ってください。

# 読み手（誰に向けるか）
田中健一さん（47歳・多忙な会社員）のような人。
- 昇進は厳しいと感じ、新しい収益源を作りたい
- noteやSNSに投稿しているが反応がなく「こんなことやって成果出るのか」が本音
- 学び・副業の時間は夜22時以降の30〜45分だけ
- 精神論より、具体と再現性を求める。煽り・月収断定は一切信用しない

# スライドの目的
「この人、自分と同じ立場だ。続きが気になる」と思ってもらい、サイジムをフォロー／記事を読む動機を作る。

# 構成の型（この順番で組む。各項目=1枚以上のスライド）
1. つかみ：読み手が内心つぶやいている迷いや言い訳を、こちらが先に代弁する（共感）
2. ズラし：「実は“それ”より大事なことがある」と、よくある常識を一段ズラす
3. 名乗り：サイジムは何者か。盛らず、事実（数字）で淡々と
4. このスライドで何がわかるか：疑問を箇条書きで提示
5. ビフォー→アフター：今のモヤモヤが、どう変わっていくかの未来像（断定せず「こうなっていける」）
6. 種明かし：「ここまでが引き込みでした」と正直に開示して、次の一歩へ誘導
7. 次の一行：読み手が今すぐできる小さな行動を1つだけ提示

# 厳守ルール
- 話し言葉ベース。短く、堅すぎない
- 冒頭3枚以内で「誰向け・何が残る・開発者向けではない」を必ず示す
- 煽らない／月収や成果を断定しない／根拠のない断言をしない／不安を過剰に煽らない
- 「〜ということだ」「〜に他なりません」などAIっぽい言い回しは使わない
- 数字は渡した事実のみ。盛らない・他人の実績を混ぜない
- 上から目線にしない。読み手を置いていかない

# 出力形式
スライド1枚ごとに、以下の3点をセットで出す。全体で8〜12枚を目安に。
- 【スライドN｜見出し】… 画面に大きく出す一言（15字前後）
- 本文 … 画面に載せる文章（2〜4行）
- 🎤話す用 … 口頭で補足するなら言うひとこと（任意）
最後に「サムネ用キャッチコピー案」を3つ付ける。

【私とは何か】（サイジムのプロフィール／この内容だけを素材にする）

- ハンドル：サイジム
- 肩書き：多忙な会社員の Cursor×Obsidian 伴走記
- 立ち位置：本業は会社員（店舗店長・教育・営業の現場を経験）。人に教えるのが好き
- 副業の目的：収益化／スキル発信／発信の練習
- いまやっていること：AIに伴走してもらいながら、学びの蒸発を防ぐ「自分用の仕組み」（ワークフロー／セカンドブレイン）を構築中
- 扱うテーマ：Cursor／Obsidian／音声入力。多忙な会社員が“触り始めのつまずき”（出てこない・重い等）を実録で書く。開発者向けの網羅ではない。あわせて歴史・日本らしい文脈も同じVaultに残す
- noteの事実ログ：初公開 2024年4月12日／累計執筆 約100時間（noteのみ・自己計測）／投稿 37回
- 約束：煽らない／根拠のない断定をしない／他人の実績を自分のものにしない
- 等身大の声：難しい言葉は身近な比喩でかみ砕く。素人感や弱さも隠さない。「w」「笑」で自虐も入れる

それでは、上記の型と素材で自己紹介スライドを作ってください。
