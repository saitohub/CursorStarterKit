# ショートカットキー（Mac）

覚えると作業速度が倍になる。最初は⭐️5つだけでいい。

---

## Cursor

### ⭐️⭐️⭐️⭐️⭐️

- AIチャットを開く / 閉じる
	- Cmd + L

- コマンドを呼び出す（/journal-fix、/weekly-journal 等）
	- チャット欄で `/` を入力 → コマンド名を選択（`!` 付きは一覧の上の方に出る）

- ファイル名で検索して開く
	- Cmd + P

- メッセージを送信する
	- Enter

- 改行する（送信せずに）
	- Shift + Enter

### ⭐️⭐️⭐️⭐️

- ファイルをチャットに添付する（@参照）
	- チャット欄で `@` を入力 → ファイル名を選択

- 音声入力を起動する
	- Fn を2回押す

- 新しいチャットを始める
	- Cmd + R（チャット欄にカーソルがある状態で）

### ⭐️⭐️⭐️

- サイドバーを開く / 閉じる
	- Cmd + B

- 設定を開く
	- Cmd + ,

---

## Obsidian

### ⭐️⭐️⭐️⭐️⭐️

- 新しいノートを作る
	- Cmd + N

- テンプレートを挿入する
	- Cmd + T

- コマンドパレットを開く
	- Cmd + P

- Markdownのアシスト
	- /

### ⭐️⭐️⭐️⭐️

- ファイル名で検索して開く
	- Cmd + O

- 単語で検索する
	- Option + F

### ⭐️⭐️⭐️

- 設定を開く
	- Cmd + ,

- 前の画面に戻る
	- Cmd + [

- 先の画面に進む
	- Cmd + ]

- 再起動する
	- Cmd + Shift + R
