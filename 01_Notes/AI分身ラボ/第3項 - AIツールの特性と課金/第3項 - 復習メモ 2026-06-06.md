# 第3項 復習メモ

## Claude Codeのモデル

| モデル | 特徴 |
|--------|------|
| Opus 4.8 | 最高性能・重い |
| **Sonnet 4.6** | **デフォルト** |
| Haiku 4.5 | 軽量・速い |

- Claude CodeはAnthropicのClaudeのみ（CursorのようにGPT・Geminiは選べない）
- `/fast` でOpus Fastモードに切替。もう一度打つと戻る
- `/status` で現在のモデルを確認できる

## セッション中に解決したCursorエラー

```
Error installing Cursor extension: ERR_STREAM_PREMATURE_CLOSE
```

**原因：** `cursor` コマンドがPATHに未登録  
**解決手順：**
1. Cursor を開く
2. `Cmd+Shift+P` → `Shell Command: Install 'cursor' command in PATH`
3. ターミナルを再起動
4. `cursor --version` で確認
