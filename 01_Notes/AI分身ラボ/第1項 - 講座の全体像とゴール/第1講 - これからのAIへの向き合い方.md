# これからのAIへの向き合い方

> 講座のカリキュラム説明ではなく、**私が腹落ちした「向き合い方」** のメモ。  
> 背景・前提は [[Claim - 外に出す前に内側と手順を整える]]、[[Claim - 曖昧に動くと迷子になる]]、[[Logic - AI時代は名言を一日で消費しない]] など、これまで Vault に書いてきたものから拾っている。  
> 講義の全文は [[第1講 - 文字起こし - 講座の全体像とゴール]]（構造の参考。他人の数字・実績は自分のものとしては使わない）。  
> **2026-05-20**：文章だけでは伝わりにくかった部分を、音声で言語化して追記した。  
> **用語**：**一次情報**＝自分の体験・生データ（ネットの一般論とは別）。講義では「一時」と聞こえる箇所があるが、表記は **一次** に統一する。

## 私がここに立っている理由（背景）

ChatGPTは使う。翌日には「昨日なんの話してたっけ？」になる——この感覚は、ジャーナルや Vault に何度も書いてきた。

- **チャット疲れ**：毎回ゼロから背景を説明する  
- **学びの蒸発**：セミナーや動画の感想だけ残って、自分の言葉にならない  
-※追記　スペックのセリフで感動したでは、見返した時に思い出せないし、残していない。
　　　　どんな背景で、どう感じたのか、誰がいったセリフまでないとメモを残す必要がない。
　　　　できれば、自分の体験から似たようなことを探すとより良い。エピソード記憶
- **後回し**：Cursor や Obsidian は名前だけ知っていて、手が動かない  
- 　　　2026年６月22日　およそ２ヶ月。最初はマニュアルを見て導入した。それを逐一説明するのは、AIがある今は
- 　　　必要がない。今なら、CursorとObsidianをダウンロードをしよう。わからなければAIにきこう！に慣れてという。
- 　　　私も教わった時、質問してもそう言われたから、最初は不親切だと思っていたが、これが日常になるんだと思い、
- 　　　どんどんAIを使えばいいと思った。質問しても、上手い答えを返してこないの、きちんと伝える練習にもなる。
- **できた感**：ツールや機能は増えたのに、利益・時間・頭の余白は変わらない  

店長時代、背中を見せて動かす側と、一人で全部抱える側の両方を知っている。AIも同じで、**代わりに全部やってくれる神**として置くと期待値がずれる。

私が寄せているのは、**伴走者**、ときどき**自分の先輩**のような存在、あるいは **専属のエージェント** という捉え方。こう置くと、何をやるにしても **打席に立つ回数** が増え、**行動の量** も増えるんじゃないか、と思う。
確かに、つまづいた時にすぐ聞けるというのは行動の加速にはなる。しかし市場では、スクールに入ってもAIっぽい答えが返ってくるという批評をみた。これはマインドの部分もあると思うが、そう思っている人はいるのだろう。

なぜかというと、怖い・やったことない・過去に失敗した、といった感情が出てきたときに、そこを一緒にいてくれる存在がいると、**その摩擦が一段ほどける**から。だから「何を使うか」より先に、**どう向き合うか**。向き合うってのは、具体的にAIを使ってうまくいかなかったときやエラーを出した時に、次そうならないようなマネジメントをすることが大切、次やらないように、ルールファイルに記載するとか、今はそれでも忘れ去られる時もある。クロードコードなら中の内部n

具体的には、自分が思った気づき・体験・「こうしたい」「やりたい」を、エージェントに **どんどん渡して報告していく**。それで **壁打ち** する——これが、私にとってのこれからのAIとの向き合い方の芯。

動いているあいだも、紙や Vault に置いてチラ見して忘れを防ぐ（[[Claim - 曖昧に動くと迷子になる]]）。

## 向き合い方の芯（5つ）

講義を聞いて、文章化したあと、音声で言い直して腹落ちした「これからの前提」。

### 1. AIは「賢くなる道具」より「言語化と反復の相棒」

「賢くなる道具」そのものは、もうみんな使う。いろんなことが出てくるから、**そこにお金を払う必要はない**、という感覚に近い。

差が出るのは、日々の **一次情報**——体験、気づき、こうしたい、やりたい——を **ひたすら言語化** して、AIと壁打ちしながら **反復** していく側。

「使うほど賢くなるか？」と聞かれたら、AIを使っている人同士では **一般的な差は出にくい**（[[Logic - 壁打ちで消えるのはAIより自分の言語化]]）。困るのはAIの記憶より、

- **自分の言葉にしきれていない**  
- **短く繰り返していない**  

——この側。

自分は思っているのに、**思うように言語化できていない**ものを、壁打ちで **出し切る**。出し切って **行動まで落とした** ときに、それを **短く、何度も繰り返す**。脳のシナプスを強くして、身についている状態にする。これはAIを使えば、前よりかなり **加速** できる。

**バトンの回し方（私の体感）**

| 誰   | やること                                |
| --- | ----------------------------------- |
| 人間  | **拡散** — モヤモヤ、体験、失敗、偏愛。音声AIに喋っていく   |
| AI  | **収束** — 構造・整理を一瞬でやってくれる            |
| 人間  | **温度** — 収束したものを見て、自分の温度感で形にし、言語化する |

このバトンを回せば回すほど、ありきたりなAI文から一段離れる（[[Logic - 拡散と収束は人間とAIでバトンタッチする]]）。

これを繰り返して、壁打ちして、保存していくと、**自分が出したい言語化** を、エージェント側が **専属として覚えていく**——そういう感覚。

### 2. 残すのは「ノウハウ」より「一次情報」

一般化されたノウハウは、AIが秒で出す時代で、価値がかなり落ちている。一方で、

- 自分の失敗・気づき  
- お客さんの反応  
- **口コミの瞬間**（なぜこれが口コミで広まったのか、という出来事）  

——こういう **一次情報** は、同じプロンプトを渡しても再現しにくい。**自分の体験談は、プロンプトだけでは出てこない。**

私が Cursor に頼んでいるのは魔法ではなく、**1年間（365日）の学びの取りこぼしをなくす**こと（[[Logic - Cursorで残す取りこぼしの定義]]）。たとえば、

- 話を聞いた・本を読んだ・見聞きしたのに「すげえこと言ってんな」と思ったのに **ファイル化されない**  
- メモはその場では取るが **後で見返さない**（「メモどこいった？」のまま）から、どんどん抜け落ちる  
- **感情が動いた** のに、結局メモしても見返さず忘れている  

**取りこぼしの型**とは、こうしたパターンのこと。知識がじわじわ抜けていく状態——メモを取るだけ、見返さない、ファイルに残らない——を、夜30分のうちに **1つでも** 塞ぐ。

### 3. チャット止まりから、複利の設計へ

毎日セーブデータを消して、チュートリアルからやり直すゲーム——**チャットだけ**使うと、ここに近い。

**複利**とは、今日の学びが明日の土台になり、その土台の上にまた積み上がること。単利は毎日ゼロからやり直すイメージ。チャット止まりは後者に近い。

蓄積がある人とない人の差は、お金では買えない。**時間**と**文脈**の差。時間そのものはお金で買える場面もある。でも **文脈**——自分の体験の蓄積、積み上げてきたもの——は、お金では手に入らない。

ただし「もう遅い」ではない。やらない人はずっとやらない。今気づいたなら、**今日から1日分のデータが増える**——それで十分。365日続ければ、365日分貯まる。

### 4. ツールに依存しない資産（マークダウン＋ローカル）

ワードや Notion にファイルを閉じると、引っ越しが重い。データそのものが重くて **動かしにくい**。

テキスト（マークダウン）で **ローカル** に置けば、

- どのAIにもコピペで渡せる  
- なぜならマークダウンは**規格が変わっていない**（長く使われている形式）  

どんなAIツールが出てきても **移動できる資産** を築ける。枝葉の新ツールは、土台のあとで拾えばいい。

### 5. 外に出す前に、内側と手順を考える

成果や発信だけを先に追うと、設計が抜ける。

「こういうことを伝えたい」「こう発信しよう」という **目的だけ** を追っていると、**読む側のこと**、**相手が望んでいる結果** を考えていない状態になりやすい。そういう状態が続くと、行動が止まったり、気合でやろうとしてもエネルギーが続かない——これは気合い不足ではなく、**順番の欠落**（[[Claim - 外に出す前に内側と手順を整える]]）。

**私のイメージ（6拍子）**

| # | 段 | やること |
|---|-----|----------|
| ① | 吐き出す | 「失敗したら怖い」「これがないからできない」など、感情・モヤモヤ・事実を全部出す。ジャーナルに **音声** で残し、AIで文字起こしする |
| ② | 整理する | 自分なりに整理整頓する。AIと壁打ちしながら進めてよい |
| ③ | 知識にする | **光ったもの**、**「これだ！」と思ったもの** を、自分の知識として蓄積する |
| ④ | For You | 発信の前に、**この人のために伝えたい** と思える **誰か1人** を思い浮かべる。その人の悩み・問題を **仮説** として立てる |
| ⑤ | 30秒で説明 | その人に伝えたいことを、口で30秒説明できるか |
| ⑥ | 外に出す | 発信する・仕事に使う |

AIは②の整理・壁打ちの往復に入る。**⑥の前に①〜⑤が通っているか**を見る。紙とAIの往復もセット（[[Logic - 紙とAIの往復で定着させる]]）。

## AIを使い倒すことにより、「できたか」より「変わったか」

思いつきで終わらせないために、私が見ている問い（チェック用）。

- 副業でも本業でも、**利益**は増えたか（自分の定義で）  
- **業務時間**は減ったか  
- **頭のリソース**に余白はできたか  
- AIに頼るようになって、**新しい学びがどんどん進む**ようになったか  
- **以前できなかったこと**ができるようになったか  
- AIと関わることで、**自分ではできなかったこと**ができるようになっているか  
- **仕事のやり方そのもの**が変わったか  

ここに変化がなければ、新しいツールを入れても人生は大して変わらない。数字やビフォーアフターで見ないと、**正しそうな情報を集める癖**だけが強くなり、行動が曖昧で、目的も不明確のまま動けなくなる——という自覚。

## 日常で回す最小ループ（マインドセットの実装）

マインドセットは「頭の中にセットする」こと。でも頭の中だけだと忘れる。私は、目につく場所やクリアファイルに **「こういうマインドで動きます」** と書いた紙を1枚入れ、毎日チラ見する。置いて、見るだけ。

多忙な会社員向けに、私が続けているのはこれだけ。思想で終わらせない。

1. **毎日30秒〜5分** — 気づきを **音声化** し、音声AIで **文字起こし** → `04_Journals`  
2. **週1回** — ウィークリージャーナルでまとめる（`/weekly-journal`）  
3. **手直ししたら** — 自分が言ったものと、AIが修正したものの **差** を分析する（何が違ったのか）  
4. **良い事例を見つけたら** — 構造を自分の知識として蓄積（他人の全文コピーではなく構造）  
5. **原稿化・ストーリー化できたら** — `03_Knowledge` の **Story / Logic / Claim**（体験・理屈・主張）に、AIに整理してもらいながら置く  

Story・Logic・Claim の違いや中身の分け方は、最初はAIにも十分伝わっていないかもしれない。だからまずファイルを作って保存し、壁打ちしながら **中身を分けていく**——そんなイメージで進めている。

仕事や生活をしているだけで、こういうファイルが増える。増えるほど、翌日・その翌日のAIが、**自分に合った専属**に近づいていく。貯めたファイルを読み込んだエージェントが、伴走者・先輩のように壁打ちしてくれる——そういう状態が、いまの私の **AIへの向き合い方のゴール**。

名言や励ましをその場で消費しない（[[Logic - AI時代は名言を一日で消費しない]]）。感動したら、ジャーナルか紙一行 → 必要なら壁打ち → それから出力。

## パートナーとしてのAI

便利なツールというより、**頭の中のバックアップの相棒**。

- 忘れたことを思い出させる  
- 自分では気づかない **考え方の癖** を見せる（ジャーナルを読み返して「うわ、これ考えてた」）  

24時間ずっと話し続けるのは無理。**夜30分**くらいなら続けられるのでは、という感覚。それでも苦しければ、**1分を30回**のように小さくして、習慣化する。ここまで言って「難しいな」と思ったことは、**自分なりにハードルを下げる**。

**AIに使われるか、AIと手を組むか** — 私は **手を組む方が早い** と思っている。  
AIと組んで育てていく。賢くなるのはAIだけではなく、**自分の言葉**と、**自分がやりたいことの道しるべ**も一緒に育つ。

目的は、**その日のうちに壁打ちしたことが、明日の自分をセーブしてくれる**こと。続きが書ける。これを毎日続けると、時間の差として **大きな差** がつくような気がしている（私の体感。断言はしない）。

## 2026-06-12 復習で気づいたこと（音読と目的と反復）

「取りこぼしをなくす」の具体例が、今日の体験で見えた。

SPECというドラマを見ていて、感情が動いたセリフを**音読**したら、翌日になっても臨場感を伴って覚えていた。
**失ってしまったものに思いをはせても仕方ないです。私達刑事が守るべきは他人の幸せです**
瀬文の元上司の子供が難病になっていることを見て、瀬文が落胆している。それを見て当真が
いったセリフ。自分もプロポーズされたが、ニノマエに腕を切られ、幸せを失ったのを想いに馳せて喋ったセリフ。

  

**スペック****5****話　当真のセリフ**

| | 状態 |
|---|---|
| Before | 見て「いいな」と思うだけ → 翌日消えている |
| 変化点 | **目的を添えて音読**（「これを覚えていたい」「自分の中に取り込みたい」） |
| After | 翌日も臨場感を伴って残っていた |
| ただし | うろ覚えになる。**2日以内に2〜3回**見返す・音読するサイクルが必要 |

**気づき：**
- メモを取るだけでは「取りこぼし」の型と同じ（感情と紐づかない・見返さない）
- **目的 → 音読（体を使う）→ 反復（2日以内に2〜3回）** のセットで初めて残る
- 感情が動いた瞬間を、声と体を使って定着させる——これが「メモを取るだけで終わる」から抜ける実体験

→ [[Logic - 感情は体・言葉・意識の3つで動く]] に繋がる。
