## この回の要点（音声メモベース）

### 前提

- この理解がないと、AI を動かしても **意味が薄れやすい**（講義の言い方）

### AIモデル

- ChatGPT / Claude / Gemini 等。**頭はいいが記憶はない**
- 翌日には忘れたように感じる → 正確には **チャットごとの文脈**
- チャットが長いと **精度低下**（コンテキスト複雑化・消費増）

### API

- **表**: 月額（例：20ドル級）で使い放題に近いが、リセットされ、記憶なし、できることが制限されがち
- **裏（API）**: 使った分課金。自分のツールから直接 AI を呼べる
- **Cursor は裏口（API）側** で動いている、という説明

### Markdown（重複するが3本目でも強調）

- `.md` ＝ AI が読みやすい純テキスト
- Word / PDF / Notion 独自形式は AI に余計
- ルール（口調など）も Markdown で書ける、という文脈
