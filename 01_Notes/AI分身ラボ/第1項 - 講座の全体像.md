# 第1項 - 講座の全体像

## この講座のゴール

この講座の目的は、あなたの思考・文体・判断基準をAIに移植し、
「自分の分身として動く制作環境」を作ることです。

最終的に、以下を目指します。

- 日々のジャーナルが知識資産に変わる
- 知識資産がコンテンツ（note、メルマガ等）に変わる
- 迷ったときにAIが「あなたの基準」で提案できる

## 全体の流れ（5ステップ）

1. 入力を整える（ジャーナル習慣を作る）
2. 抽出する（体験をStory / Logic / Claim / Evidenceに分解）
3. 蓄積する（03_Knowledgeに資産化）
4. 出力する（05_Outputsにコンテンツ化）
5. 改善する（週次・月次で振り返り、基準を更新）

## 各フォルダの役割

- `04_Journals`: 素材置き場。感情と事実を生で残す
- `03_Knowledge`: 再利用できる知識資産
- `05_Outputs`: 読者に届ける完成コンテンツ
- `06_Reflections`: 週次・月次の学習ログ

## まず最初の実行タスク（今日）

### Task 1
`04_Journals` に今日のジャーナルを1本書く（5分でOK）

### Task 2
そのジャーナルから気づきを1つ選び、1行で要約する

### Task 3
要約した1行をもとに、`Logic` か `Story` を1本作る

## つまずきやすいポイント

- 完璧に書こうとして止まる  
  → まずは粗く書いて、後で整える
- 情報を集めすぎて出力しない  
  → 「1入力につき1出力」をルール化
- 目的を見失う  
  → 「次に動ける1手」を毎回最後に決める

## この講座の進め方（おすすめ）

- 平日: 入力と小さな出力を回す
- 週末: `/weekly-journal` で整理する
- 月末: `/monthly-journal` で方向を調整する
