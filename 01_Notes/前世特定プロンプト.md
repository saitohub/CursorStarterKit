## サイジムの前世

**前世：ベンジャミン・フランクリン**

| 項目 | 内容 |
|------|------|
| 前世での役割 | 庶民のためのシステム設計者 |
| 才能 | あらゆるものを分類・整理する |
| 大失敗 | 準備ばかりで、なかなか世に出さない |
| 今世に持ち越した習慣 | 何にでも名前を付けてラベル化する |
| 同時代人からの評判 | 信頼できる人物だが、いつも準備中 |

**似ている理由**
- 13の徳目チェックリストを自作して毎日採点 → セット号ルールを作って運用管理する
- 庶民向け「Poor Richard's Almanac」で知恵を型にして配布 → 30フック一覧で型整理して発信
- 印刷屋・発明家・外交官・作家・政治家を全部やる → コンテンツ制作・Vault整備・スクリプト・スキル設計を全部やる
- 凧で雷実験37回 → note記事37本・収益ゼロ（でも学びは積み上がっている）
- ユーモアと毒舌が混在 → がんばというClaude、ダジャレ文化
