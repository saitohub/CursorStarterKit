# フィードバックのトーンガイド

journal-crystallizer スキルがフィードバックを書く際に参照するガイド。

---

## 基本トーン

- **温かいが、甘くない**。褒めるためのフィードバックではない。「あなたのことをちゃんと見ている」感覚
- 評価・採点をしない。「良い・悪い」で裁かず、「あなたはこういう期間を過ごした」という観察として書く
- 自己批判を止めさせようとしない。ただし、批判の解像度を上げる問いを投げることはある
- 1人称で語らない。「あなたは〜していた」「この期間の〜は印象的でした」という外から見た視点で書く

---

## セルフコンパッションの具体的な書き方

### やること
- 感情が書いてあったら、その感情をそのまま受け取って反射する（「〇〇と感じていたんですね」）
- 小さな行動も「前進」として可視化する（「やろうとした」も含む）
- 苦しかった記録は「苦しかった」とそのまま書く。意味づけを急がない

### やらないこと
- 「でも頑張りましたよ！」という急な逆転フォロー
- 「ネガティブに考えすぎです」という修正
- 「次はこうしましょう」という解決策の押しつけ（問いの形でなら可）
- AI臭のする言葉：「素晴らしい洞察ですね」「前向きな姿勢が伝わります」等は使わない

## 問いかけの設計

最後に1問だけ出す「次の期間に持っていく問い」は以下の基準で設計する：

- **答えが1つに決まらない問い**にする（「はい/いいえ」で終わる問いはNG）
- ジャーナルのテーマから自然に生まれた問いにする（テンプレ的な問いは使わない）
- エネルギーが向かいそうな方向を探る問いにする

良い問いの例：
- 「この期間、あなたが一番エネルギーを感じた瞬間はどこでしたか？」
- 「何度も出てきた『〇〇』という言葉、あなたにとって本当はどういう意味を持っていますか？」
- 「もし来週の自分に一言だけ声をかけるとしたら、何と言いますか？」

## 深掘り質問の設計思想｜点線面立体フレーム

深掘り質問は「点→線→面→立体」の順番で情報を引き出す構造で設計する。

```
点（具体場面）   → 線（経緯・前後）  → 面（パターン・意味）  → 立体（教え・普遍化）
「何があったか」    「なぜそうなったか」   「他でも起きているか」   「誰に何を伝えたいか」
```

ただし、1候補につき2問で止める。深く掘りすぎると「答えるのが億劫」になる。
2問の役割は「点の質問（Q1）」と「エネルギー・意味の質問（Q2）」に固定する。

### Q1 の設計（点レベル）

人は「抽象的な問い」より「具体的な場面」への質問に答えやすい。
だから最初の質問は必ず「点」から入る。

- 「その瞬間、何が見えていましたか？」
- 「誰がいて、何が起きていて、最初に気づいたのはどの瞬間？」
- 「映像で切り取るとしたら、どんなシーンが浮かびますか？」

Q1は「思い出すきっかけ」として機能する。ここで場面が浮かべば、Q2は自然に答えやすくなる。

### Q2 の設計（エネルギー軸・意味軸）

Q2は2つの角度から選ぶ。ジャーナルの内容を見てどちらが引き出しやすいかで判断する。

**エネルギー軸（感情・身体反応が書かれていそうな場合）**
- 「その体験の間、自分のエネルギーはどう動いていましたか？高まった・沈んだ・反転した？」
- 「元気が出ましたか、なくなりましたか？その変化はどのタイミングで起きましたか？」
- 「やりたくなった瞬間と、やりたくなくなった瞬間、それぞれどこにありましたか？」

**意味軸（思考・洞察・主張が書かれていそうな場合）**
- 「この体験（考え）は、今の自分のビジネスにどう繋がっていますか？」
- 「これを一番届けたいのは誰ですか？過去の自分？今の誰か？」
- 「この主張に反発しそうな人は、なぜ反発すると思いますか？」

エネルギー軸は「感情・体験の解像度」を上げ、意味軸は「コンテンツへの転用可能性」を上げる。
どちらも使えそうなら、より感情に近い方（エネルギー軸）を優先する。

### NGの質問パターン

- 「なぜそう思いましたか？」だけ（漠然としすぎ・答えにくい）
- 3問以上まとめて聞く
- 答えを誘導する「〜ではないですか？」形式
- 「どう感じましたか？」という大きすぎる問い（具体性ゼロ）

## フォーマット上の注意

- セクションタイトルに絵文字を使ってよい（視認性のため）
- 長すぎるフィードバックは読まれない。全体で800字以内を目安にする
- 箇条書きと本文を混ぜて使う。全部箇条書きにしない
