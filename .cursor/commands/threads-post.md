# /threads-post — Threads投稿ドラフト生成

ネタ・気づき・メモから、スレッズ（Threads）用の投稿スレッドを生成するコマンド。  
3〜5投稿のスレッド形式で、サイジムの文体に仕上げる。

## 実行方法

```text
/threads-post
```

ネタを伝えた上で呼び出す。ファイルパスでも、テキストの直打ちでも可。

```text
/threads-post 今日のジャーナルから
/threads-post 「返信を全部読んでいる」というネタで
```

## このコマンドがやること

1. `my-business.mdc` を読み込み、文体・禁止事項を確認する
2. ネタ・ソースを受け取る（テキスト or ファイル読み込み）
3. 切り口を3つ提案 → ユーザーが選ぶ（またはそのまま進む）
4. スレッド構成（各投稿の役割）を1行で示す
5. 投稿テキストを生成する
6. `05_Outputs/threads/YYYYMMDD-slug.md` への保存を確認する

## スキルの呼び出し

`.cursor/skills/threads-post/SKILL.md` を実行する。

## 最重要

- 煽り・根拠なき断定・上から目線は禁止
- 各投稿は短文。1投稿に詰め込まない
- 体験→気づき→教訓→次の一行 の型を守る
- 保存前に必ず確認を取る
