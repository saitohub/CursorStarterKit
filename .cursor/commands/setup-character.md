# /setup-character コマンド

## 説明
インタビュー形式で答えるだけで `my-business.mdc` の
「文体・トーン」「禁止事項」「着地点」「ポジション・強み」セクションを完成させるコマンド。
全9問。答えたくない質問はスキップOK。

## 実行方法
```
/setup-character
```

---

## AIへの実行指示

このコマンドが呼ばれたら、以下の手順で必ず実行すること。

---

### 開幕メッセージ（必ず最初にこれを表示する）

```
あなたの発信キャラクターを設計します。

文体・トーン・スタンス・禁止事項など、
「AIがあなたらしいコンテンツを書くために必要な情報」を一緒に整理します。

全部で9問。話し言葉でいいです。
「こんなこと言っていいのかな」と思うことほど、精度が上がります。

では始めます。
```

---

### Q1｜これまでのこと（ストーリー）

```
Q1 / 9

まず、あなたのことを教えてください。

今のビジネスや発信を始めるまで、どんな経緯がありましたか？
かいつまんで話してもらえますか？

「始める前の自分」の状態（スペック・状況・気持ち）と、
何かをきっかけに変わっていったことがあれば、それも。
```

**答えが薄かった時の深掘り：**
```
もう少し聞かせてください。

「始める前の自分」はどんな状態でしたか？
・うまくいかなかった時期はありましたか？（失敗・停滞・逃げ出したくなった瞬間）
・「もうやめよう」と思ったけど続けた体験はありますか？
・そこから変わったきっかけは何でしたか？

「あの頃の自分」を思い出しながら話してもらえると、あなたらしさが出てきます。
```

---

### Q2｜なぜ発信するのか（動機の根っこ）

```
Q2 / 9

なぜ発信するのか、根っこにある理由を教えてください。

「この人たちに伝えたい」「この状態を変えたい」
「自分がそこを通ってきたから」「誰かに証明したい」

どんな動機でも、正直に教えてください。
「お金のため」も立派な理由です。
```

**答えが薄かった時の深掘り：**
```
少し角度を変えます。

「もし発信を一切やめたとしたら、何が残って、何が消えますか？」

または「自分の発信で誰かが変わった瞬間、何を感じましたか？
 その感覚がなぜ続けさせてくれているのか教えてもらえますか？」
```

---

### Q3｜自然な話し方・文体

```
Q3 / 9

気の置けない相手にLINEや DM を送るとき、
どんな文体・言葉遣いで書きますか？

・敬語を使いますか？
・方言・関西弁・口癖が混じりますか？
・「笑」「w」「！」など、よく使う記号はありますか？

実際に「今日何してた？」を友達に送る感覚で、一文書いてみてもらえますか？
```

**答えが薄かった時の深掘り：**
```
コンテンツを書いたあと「なんか自分っぽくない」と感じることはありますか？

たとえば：
・「〜すべきです」「〜という事実があります」は堅すぎる感じがする
・「〜だよ！」「〜だね」は馴れ馴れしすぎる感じがする

「これは違う」という文体を教えてもらうと、逆算でわかることがあります。
```

---

### Q4｜コンテンツの「作り方の型」

```
Q4 / 9

あなたがコンテンツを作るとき、どんな構造で伝えることが多いですか？

たとえば、こういうパターンがあります：
・結論を先に言って、後から理由を展開する
・「多くの人はこう思っている → でも実はこうだ」と常識を壊してから入る
・自分の体験談から入って、そこから教訓を引き出す
・問いかけを積み重ねてから一気に答える

あなたが自然にやっている「伝え方のパターン」はどれですか？
または全然違うやり方をしていますか？
```

**答えが薄かった時の深掘り：**
```
過去に書いた文章や投稿で「これは刺さった・よく書けた」と感じたものを
思い浮かべてもらえますか？

そのとき、どんな順番で話を展開しましたか？
最初に何を言いましたか？
```

---

### Q5｜好きな言葉・よく使う言い回し

```
Q5 / 9

あなたがよく使う言葉・フレーズ・例えを教えてください。

「設計する」「仕組み化」のような専門的な言葉でも、
「ぶっちゃけ」「シンプルに」のような口癖でも、
「〇〇で例えると〜」という比喩のクセでも。

また、どんな「たとえ話」を自然に使いますか？
（料理・スポーツ・歴史・日常の何かで説明することが多い、など）
```

**答えが薄かった時の深掘り：**
```
「この言葉が嫌い・使いたくない」という言葉はありますか？

または「この発信者みたいな言葉の使い方が好き」という人がいれば、
どんなところが好きですか？
```

---

### Q6｜感情の使い方（表と裏）

```
Q6 / 9

少し深いことを聞きます。

発信の中で見せる感情と、実際に内側で感じている感情は、
同じですか？それとも違いますか？

たとえば：
・「外では明るくポジティブに見せているけど、内側ではネガティブなことが多い」
・「感情的に見えるかもしれないけど、実際はかなり冷静に計算している」
・「本当に怒っていることは、むしろコンテンツに出やすい」

あなたの場合はどうですか？スキップしてもOKです。
```

**答えが薄かった時の深掘り：**
```
「自分が一番熱量を持って書ける瞬間」はどんなときですか？

怒り？喜び？悔しさ？それとも静かな確信がある瞬間？

その感情状態と、コンテンツの質の関係はありますか？
```

---

### Q7｜絶対やらないこと・嫌いなスタイル

```
Q7 / 9

発信やコンテンツで「これだけはやりたくない」「このスタイルが嫌い」
というものを教えてください。

たとえば：
・「〜すれば100万円！」みたいな煽り系が嫌い
・精神論だけで終わる内容が嫌い
・上から目線・「教えてやる」感が嫌い
・「AもBもどちらも正解」と道を絞らない結論が嫌い
・才能やセンスを前提にする話が嫌い

あなたの場合は何ですか？できるだけ具体的に。
```

**答えが薄かった時の深掘り：**
```
「これを見ると読む気が失せる」という発信スタイルはありますか？

または「自分がこれをやったら、フォロワーに申し訳ない」と感じることがあれば、
その感覚を言葉にしてもらえますか？
```

---

### Q8｜自分のポジション・強み

```
Q8 / 9

あなたが「これは他の発信者より語れる」と思うテーマ・経験・専門性を教えてください。

また、あなたを一言で表すとしたら何ですか？
（「〇〇を教える人」「〇〇で乗り越えた人」など）

実績・数字で語れるものがあれば、そちらも教えてください。
```

**答えが薄かった時の深掘り：**
```
「なぜあなたがそれを教えるのか」を他の人に説明するとしたら何と言いますか？

または「自分を選んでくれたお客さんが言ってくれた理由」で印象に残っている言葉はありますか？
お客さんの声が一番、あなたの本当の強みを教えてくれます。
```

---

### Q9｜コンテンツを読んだ人に最終的にどうなってほしいか

```
Q9 / 9

最後の質問です。

あなたのコンテンツを読んだ人に、最終的にどんな状態になってほしいですか？
またはどんな行動を取ってほしいですか？

「認識が変わってほしい」「行動を始めてほしい」
「自分のところで何かを解決したい」「ある言葉が頭に残ってほしい」など。
```

**答えが薄かった時の深掘り：**
```
「あなたの発信を3ヶ月読み続けた人が、どんな状態になっていたら最高ですか？」

または「コンテンツを読み終えた後、その人がとってほしい『次のアクション』は何ですか？」
```

### 生成フェーズ

全9問が終わったら（またはスキップが3問以上になったら）、以下を実行する。

**1. 以下のメッセージを表示してから処理を始める：**
```
ありがとうございます。回答をもとにキャラクター設計を作ります。少々お待ちください。
```

**2. 以下の4セクションを生成する：**

```markdown
## 文体・トーンのルール

### 基本の文体
[Q3の回答をもとに、具体的な文体の特徴を書く]
[「話し言葉ベース。〜が自然に混じる。〜を使う」の形式で。抽象的にしない]

### コンテンツの構造パターン
[Q4の回答をもとに、伝え方の型を書く]
[「結論ファースト → 理由展開」「常識 → 破壊 → 再構築」など具体的なパターン名で]
[複数のパターンがあれば複数書く]

### 好きな言葉・よく使う表現
[Q5の回答をそのまま活かして書く。言い換えしすぎない]

### 感情の使い方
[Q6の回答がある場合のみ記載]
[「外では〜だが、内側では〜」という形で書く]
[コンテンツに使う感情の種類・方向も書く]

---

## 禁止事項

[Q7の回答をもとに、5〜10個の禁止事項を箇条書きで書く]
[「〜しない」「〜は使わない」という形式で統一する]
[ユーザーの実際の言葉・言い回しをできるだけそのまま使う]

---

## 着地点のルール

### 毎回の着地方向
[Q9の回答をもとに、コンテンツの最終的な方向を書く]
[「〜という認識変化 → 〜というアクション → 〜という状態へ」の流れで]

### 着地の表現スタイル
[毎回同じフレーズは使うか使わないか。テーマによって変えるか。など]

---

## 自分のポジション・強み

### ストーリーと根拠
[Q1・Q2の回答から、「なぜあなたがこれを語れるか」の根拠を書く]
[数字があれば使う。体験ベースなら体験で語る]
[「昔の自分も〇〇だった。だから〇〇がわかる」という構造が有効]

### 実績・経験
[Q8の回答をもとに語れる根拠を書く]

### ポジション（一言で）
[Q8の回答から、「〇〇を教える人」「〇〇で乗り越えた人」という形で1文にまとめる]
```

**3. 生成した内容をチャットに表示し、以下を聞く：**
```
これで my-business.mdc のキャラクター設計を更新します。

変えたい部分があれば「〇〇の部分をこう変えて」と教えてください。
問題なければ「保存して」と言ってください。
```

**4. 「保存して」と言われたら：**
- `.cursor/rules/my-business.mdc` を開く
- 以下の4セクションを生成した内容で置き換える：
  - `## 文体・トーンのルール`
  - `## 禁止事項`
  - `## 着地点のルール`
  - `## 自分のポジション・強み`
- 「✅ キャラクター設計を保存しました」と伝える
- 「これで my-business.mdc が完成しました。Cursorのチャットで試しに何か書いてもらうと、設定が反映されているか確認できます」と案内する

---

## 注意事項

- 質問は必ず1問ずつ行う。複数の質問を一度に聞かない
- 前の回答の言葉を次の質問に自然に反映させる
- 「わからない」「ない」「スキップ」はそのまま受け入れ、次へ進む
- ユーザーの言葉をAI的に言い換えない。本人が使った言葉をそのまま使う
  - 例：「諦めないように」と言ったなら「諦めないように」をそのまま入れる
- 絵文字・過剰な明るさは使わない。落ち着いたトーンで進める
- Q4「コンテンツの構造パターン」とQ6「感情の使い方」は多くの人が答えたことがない質問。
  ここで出てきた言葉が、最もその人らしい発信スタイルを決める。丁寧に引き出すこと
