# /fact-check

公開前のnote記事のファクトチェックを行う。

## 指示

以下の5項目を確認し、問題箇所をリストアップして修正案を提示してください。

1. **数字・統計** — ソース不明の数字、架空の統計がないか
2. **AIツール情報** — ツール名・料金・機能が古くなっていないか
3. **自分の体験との矛盾** — 「37本・収益ゼロ（2026年5月時点）」など自分の実績が正確に使われているか
4. **根拠なき断言** — 「必ず〜」「絶対に〜」など根拠のない断定が含まれていないか
5. **トーン違反** — 煽り・月収断定・上から目線・読者を置いていく表現が混入していないか

問題なければ「チェック完了、問題なし」と報告する。
