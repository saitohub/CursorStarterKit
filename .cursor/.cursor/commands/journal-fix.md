# /journal-fix コマンド

## 説明
今日のジャーナル（または指定したジャーナル）の誤字脱字・スペース・改行を整えて上書き保存する。
内容は変えない。形だけ整える。

## 実行方法
```
/journal-fix
```
または
```
/journal-fix 2026-03-22
```
（日付を指定した場合はその日のファイルを対象にする）

---

## AIへの実行指示

### Step 1｜対象ファイルの特定

日付が指定された場合：`04_Journals/[指定日付].md` を対象にする。

日付が指定されていない場合：今日の日付（JST）で `04_Journals/YYYY-MM-DD.md` を特定する。

ファイルが存在しない場合：「対象のジャーナルファイルが見つかりませんでした」と伝えて終了。

### Step 2｜整形の実行

以下のルールで整形する。**内容・意味・感情表現は一切変えない。**

#### やること

**音声入力スペースの除去**
- 不自然な1文字スペースの連続を除去する
  - 例：`何 て 言う ん でしょ う` → `何て言うんでしょう`
  - 例：`僕 は 昨日` → `僕は昨日`
- ただし意図的なスペース（箇条書きのインデント等）は残す

**明らかな誤字脱字の修正**
- 変換ミスによる明らかな誤字を修正する
  - 例：`確かニ` → `確かに`
  - 例：`学習する必用がある` → `学習する必要がある`
- 「明らかな誤字」かどうか判断できない場合は変えない

**句読点の補完（最小限）**
- 文末に句点がなく、明らかに文が終わっている箇所にのみ句点を追加する
- 読点は追加しない（話者のリズムを壊すため）

**連続する空白行の正規化**
- 3行以上連続する空白行を2行に圧縮する

#### やらないこと

- 文章の言い換え・書き換え
- 語尾の変更（「だ」→「です」等）
- 内容の追加・削除
- 感情表現の整え・美化
- 口語・方言・崩れた文体の修正（それが本人のスタイル）
- 句読点の大幅な追加・変更

### Step 3｜差分の確認と上書き

整形後のテキストを元のファイルに上書き保存する。

保存後に以下を報告する：

```
✅ ジャーナルを整形しました（YYYY-MM-DD）

修正した内容：
・音声スペース：X箇所
・誤字修正：X箇所
・その他：X箇所
```

変更箇所が0の場合：「整形の必要はありませんでした」と伝えて終了。

## 注意事項

- frontmatter（`---` で囲まれた部分）は変更しない
- `## Journal` 等のセクション見出しは変更しない
- 判断に迷う箇所は変えない。過剰整形より未整形の方がいい
