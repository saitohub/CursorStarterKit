#### 理論・ノウハウ

**ビジネスメールが面白く読まれる型**のひとつ。いきなり商品説明せず、**読者の予測を2回外してから**、笑い・具体・失敗で信頼を作り、最後だけ **「物語＝メッセージが価値」** に畳んでオファーへつなぐ。

**一言テーゼ（再利用用）**

> 人の心を動かすのはスペックではない。**「なぜそれを伝えたいか」が乗った物語**。

**物語7 : 教訓2 : オファー1** くらいの文字量比が目安。説教が先に来ると臭いが、**自分の体験のあと**なら「なるほど」になる。

#### 前提・背景

- 読者は「実績がない」「資格がない」と言いがち。**否定のあと**に「大事なのはなぜ伝えたいか」へ転換すると受け口ができる。
- 人はモノを買っているようで、**想い・メッセージ**にお金を払っている（クラファン等の短い事例で補強するパターン）。
- [[Claim - 数値は正しさを運びストーリーは刺さりを運ぶ]] と同筋。数値・スキル説明だけを頑張らなくていい。

#### 仕組み・構造

**全体マップ（14ステップ）**

```
① 謎の一行（数字＋「一体何が復活？」）
② 枠CTA（期間限定・締切・上にも置く）
③ 自己紹介＋答えの提示（商品じゃないモノ／体験）
④ 時系列エピソード（場所・金額・こだわりの具体）
⑤ 落差の笑い（英雄にならない失敗）
⑥ 眠らせた理由 → 再起動（小さな手間の積み上げ）
⑦ 再体験の五感（軽い・速い・怖い等）
⑧ 身体ギャグ or 正直な転倒（誇張＋^^;）
⑨ 感情の一文（青春／宝物）
⑩ 抽象化（物語・メッセージが価値）
⑪ 他人の短い事例（モノ＜想い。他人の数字・実績は自分のものにしない）
⑫ 読者の「言い訳」を引用してから転換
⑬ 結論の太字＋問い（語ってますか？）→ オファー正当化
⑭ P.S.（キャラ・別依頼で関係維持）
```

**二重フック（ずるいが効く順序）**

| 段階 | 読者の頭の中 | 実際 |
|------|--------------|------|
| 1 | 復活＝ライブ・商品？ | 枠CTAで補強 |
| 2 | 物語の主役＝ビジネス？ | 答えは**意外な体験モノ**（自転車等） |
| 3 | 教訓の主役＝趣味の話？ | 着地は**メッセージ・発信・出版** |

**感情曲線（映画型）**

```
高揚（夢中だった時期）
  ↓
落下（やめた・飾っただけ）
  ↓
再起（部品交換・仕事の合間）
  ↓
快感（再体験・対比）
  ↓
恐怖＋笑い（やりすぎ・転んだ）
  ↓
静かな余韻（「〇〇だったな」）
  ↓
論理接続（だから物語が価値）
```

**比喩の橋渡し（1本道で転用）**

| 物語側 | 発信・商品側 |
|--------|----------------|
| 記念の高い買い物 | 実績・資格がなくてもいい |
| 少しずつパーツ交換 | スキル説明より「なぜ伝えたいか」 |
| 古い・最新じゃない | AI整文だけでは足りない |
| 宝物＝物語が乗っている | 一冊・一記事に人生・価値観が乗る |
| 安いモノでも支援 | 人は想いにお金を払う |

**読者を離脱させない5エンジン**

1. **パターン・インタラプト**（予測の外しを2回）
2. **具体の異常さ**（地名・金額・パーツリスト→脳内再現）
3. **笑いの型**（英雄拒否→親近感→記憶）
4. **感情曲線**（論理が物語のあとに来る）
5. **比喩の一本道**（体験の感情を読者の発信に移植）

**心理トリック（表に出ない部分）**

- オープンループ（冒頭の謎を中盤まで解かない）
- 自己開示の階段（高価→失敗→転倒。完璧な専門家像を避ける）
- 対比の連打（旧 vs 新、スペック vs メッセージ）
- 読者の悩みの先回り引用（「実績がない」等）→ 転換
- CTA二段（上：締切／下：関係・P.S.）
- P.S.でトーンを戻す（本編感動寄り→人間味・別依頼）

**文体の細部**

- 1行1息の改行（スマホで「次は？」）
- オノマトペ・記号（声が聞こえる）
- `^^^^` 等でスキャン読者にも主張が残る
- 締めの口癖でシリーズ感

**ポンポン型（概念フック→研究→3ヶ月体験）との違い**

| 軸 | 謎解き物語ブリッジ型 | 概念フック型 |
|----|----------------------|--------------|
| 入口 | 謎＋予測のズレ | 意外な概念・研究 |
| 証明 | 自伝・身体・笑い | メタ分析・短期変化 |
| トーン | エッセイ・バラエティ寄り | 論破＋共感ビジネス |
| オファー | 物語のあとに自然接続 | やや早めにセミナー名・LP |
| 読後感 | 人が好き・話が面白い | 構造が分かった |

どちらも PASONA 系の変形。**Need** を「実績不足」から **「メッセージが語れていない」** に置き換えるのがこの型の特徴。

#### 具体例

**再利用テンプレ（中身は必ず `03_Knowledge/` の自分素材）**

```
1. 謎の一行（数字＋「一体何？」）
2. 枠CTA（急ぎの人向け・上にも可）
3. 答えは意外な体験（商品名ではない）
4. 時系列（場所・金額・こだわり）
5. 笑える失敗（英雄にしない）
6. 眠らせた理由 → 最近の再起動
7. 再体験の五感
8. ギャグ or 正直なハプニング
9. 感情の一文
10. テーゼ一行（物語・メッセージ）
11. 他人事例1つ（構造のみ・ストーリー流用禁止）
12. 読者の言い訳を引用 → 転換
13. 結論＋問い → オファー
14. P.S.（キャラ・別依頼）
```

**健一さん向けの置き換え例（題材の方向だけ）**

- 「23年ぶりに復活」→「何年ぶりに Vault を開いた」「飾られていた一行メモ」
- パーツ交換 → テンプレ・ルール・伴走AIへの依頼文を少しずつ足す
- オレママ比較 → チャットだけ vs 残る置き場
- 着地：[[Logic - Cursorで残す取りこぼしの定義]]・学びの蒸発・次の一行

**美咲さんライン**

- 同型の **物語→置き場** は使えるが、オファーは **不安の3行・胸の置き場**。AI・Kindleを主役にしない（my-business 別レーン）。

#### よくある誤解・反論

- **「笑いがあるから軽い」** → 笑いはラポール装置。本題の論理は物語の**あと**に置く。
- **「他人のメルマガをそのまま書ける」** → 構造のみ。痔・MTB・キャラ名等の他人エピソードは **Swipe扱い・自分の実績にしない**。
- **「AIで書けば同じ」** → 型の型通りで整えるだけでは **メッセージが乗っていない** 本文になる。自分の一次体験（Story）が先。

#### コンテンツでの使い方

- **ステップメール・登録直後**：謎→物語→「なぜ伝えたいか」→ 無料note／有料への橋
- **note無料記事**：冒頭3行は健一さん向け約束。本文は体験→気づき→教訓のあと、型の⑩〜⑬
- **執筆前チェック**：④に具体があるか、⑤⑧で上から目線になっていないか、⑪が他人の数字になっていないか
