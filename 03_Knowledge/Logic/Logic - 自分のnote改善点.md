# Logic - 自分のnote改善点

> 元ネタ（他人事例の構造分析）→ [[Swipe - ノラミ氏noteの構造分析]]
> ※ノラミ氏の数字・実績は他人のもの。サイジム自身のものとして出力しない（swipe-guard準拠）。

ノラミ氏noteの型分析から導いた、サイジム自身のnoteへの改善点。健一さん向け・収益ゼロ（2026年5月時点・37本100時間）の現状を踏まえる。

## 改善点（優先順）

### 🔴 最優先：記事の「出口（導線）」を作る
- 収益ゼロの最大要因はおそらくここ。ノラミ氏は全記事が次の行動に繋がるが、サイジムの「次の一行」は読者の自己行動を促すだけで、自分の何か（LINE/無料プレゼント/商品）に繋がっていない。
- 文章を磨くより、出口を1つ作る方が売上に直結する。今週やれる施策。

### 🟡 タイトルを「否定・逆説・問いかけ」に振る
- 健一さんの痛み「整理しようとするほど迷子になる」と逆張りタイトルは好相性。
- 例：「設計図は、書かなくていい」／「"ちゃんと整理しよう"が、あなたを止めている」／「100時間書いて収益ゼロの私が、やっと気づいたこと」

### 🟡 サイジムの数字こそ最大の武器
- ノラミ氏の売上数字は真似できない（こちらは収益ゼロ）。だが逆に「37本・100時間・収益ゼロ」という生々しい数字こそ健一さんに刺さる。
- 「同じ場所で足踏みしてた人の言葉」として最強の共感装置。隠さず冒頭に置く。

### 🟢 書き出しを「共感→一撃」の2行型に固定
- 既存ルール「書き出しで何がわかる記事か言う」の前に、1行で健一さんの行動を言い当てると掴みが段違いになる。

---

## 結論（今週やること1つ選ぶなら）
タイトル・書き出しは微調整でOK。本質的に足りないのは「記事の出口」。次のマイルストーン（初収益1円）に直結するのは導線設計。
