# Logic - クレジットカード・パスワード・個人情報はメモリに保存しない

## 核心

クレジットカード番号、パスワード、個人情報など、機密情報を `.claude/projects/.../memory/` に保存してはいけない。セキュリティリスク。

## 問題

- メモリシステムに「親のニコスカード情報（ナンバーレスだが裏面に16桁番号あり）」が保存されていた
- メモリファイルは git 管理外で、ローカルに平文で保存される
- PC が盗まれたら、カード情報が露出する可能性がある
- クレジットカード番号は PCI DSS（Payment Card Industry Data Security Standard）違反

## ルール

**保存してはいけない情報：**
- クレジットカード番号（全桁・一部問わず）
- デビットカード番号
- パスワード・API キー・トークン
- 個人識別番号（マイナンバーなど）
- 銀行口座番号
- 医療記録・健康情報
- その他、個人が特定される情報

## Why

- メモリシステムは暗号化されていない（平文保存）
- ローカルファイルなので、PC が盗まれると一発で露出
- セキュリティ規格違反（PCI DSS など）
- ユーザーの信頼を損なう

## How to apply

**保存前のチェック：**
1. これは機密情報か？（カード番号、パスワード、個人情報か）
2. ローカルファイルに平文保存して安全か？
3. 「NO」なら、保存しない

**代替案：**
- 本当に必要なら、1Password などの暗号化ボルトに保存
- または、git-crypt で暗号化
- 一時的なメモなら、即座に削除

**今後：**
機密情報がメモリシステムに入らないよう、ユーザーと私の両方が気をつける。
