# Logic - ファイル保存前に CLAUDE.md と .cursor/rules を必ず確認

## 核心

知識があるのに「実行時に参照しない癖」があると、ルール違反が起きる。ファイル保存・ナレッジ記録・重要な判断をする前に、CLAUDE.md と `.cursor/rules/` を必ず確認する。

## 問題

- 2026-06-19、ナレッジを保存するとき、システムの `/memory/` フォルダに勝手に置いてしまった
- CLAUDE.md のセット号ルール（`03_Knowledge/Logic/` に置くべき）を知ってたのに確認しなかった
- `.cursor/rules/` の存在も知ってたのに参照しなかった
- 「知ってる」と「実行時に確認する」を混同した

## ルール

**ファイル保存時のチェックリスト：**

1. CLAUDE.md のセット号ルール（`03_Knowledge/`、`05_Outputs/note/` など）を確認
2. `.cursor/rules/` の関連ファイルを参照（`my-business.mdc`、`swipe-guard.mdc` など）
3. 既存のファイル配置を見て判断基準にする（同じフォルダの他ファイルはどこに置かれてるか）
4. 保存先が確定してから実行

## Why

- ユーザーは既に環境を整えてくれてる（CLAUDE.md、`.cursor/rules/`、フォルダ構成）
- ユーザーは「暗黙的に指示」してる（CLAUDE.md に書いてある = 指示）
- 明示的な指示がなくても、ルールを確認する責任がある
- 「知ってる」で安心しないこと

## How to apply

ファイル保存、ナレッジ記録、その他の重要な判断をする前に、以下の流れを必ず実行する：

1. 「CLAUDE.md に関連するルールがないか」確認
2. 「`.cursor/rules/` に参考になるファイルがないか」確認
3. 「同じ種類のファイルは、どこに、どう名付けられてるか」調べる
4. その上で判断・実行

実行時の省略は許さない。「確認するコスト」は「ルール違反のコスト」より小さい。
