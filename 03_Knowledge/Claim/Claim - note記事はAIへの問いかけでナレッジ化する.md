# Claim - note記事はAIへの問いかけでナレッジ化する

note 記事を毎日投稿しても、ジャーナルに書いても、AIに「この記事からナレッジ候補はあるか」と問いかけて抽出しなければ学びの蒸発は続く。

## なぜそうなるか（盲点の構造）

- 娯楽・インプット → ジャーナルに書く
- Cursor 作業・note 投稿 → Outputs に保存して「残った気」になる

この分離が無意識に起きていた（2026-05-23 に発見）。**記事投稿 ≠ ナレッジ化。** 出力したことと、自分の知識資産に変換したことは別。

## 実践ルール

1. 週次振り返り後、または月次振り返り時に「今週（今月）の note 記事からナレッジ候補はあるか」と Claude に問いかける
2. Cursor 作業ログは 3 行でジャーナルに残す（何をした／何が残った／次の一行）
3. 投稿した記事を AI に読ませて Story・Logic・Claim・Evidence のどれに当たるか分類させ、候補があれば即作成する

## この盲点が生まれた理由

「Cursor でやった＝記事になった＝残った」という錯覚があった。成果物（記事）は見えるが、その記事が自分の知識資産になったかどうかは別の問いが必要。

→ 定期的に Claude への「抽出問いかけ」をルーティンに組み込む。
