# サムネイル設計ガイド（外部ツール用 参考プロンプト集）

> **ルート別の使い分け**:
> - **nanobanana-deji（Gemini API）ルート** → `.claude/skills/nanobanana-deji/references/slide-style.md` を参照
> - **Claude Code 直接生成（PIL）ルート** → `.claude/skills/note-word/references/figure-patterns.md` を参照
> - **本ガイド** → 外部ツール（Midjourney / DALL·E 等）でサムネを作るときの参考プロンプト集

本スキル本体（PIL/Gemini ルート）は画像を**自動生成します**。
本ガイドは「自分で外部ツールを使いたい人」向けの補助資料です。

---

## 基本ルール

- サイズは **1280 × 670px（16:9）** 固定
- 「ゴシック体フォント使用」をプロンプトに必ず書く
- 情報は詰め込まない（1焦点）
- 固有名詞（Claude, ChatGPT 等）は英語のままでOK
- パステル / フラット / プロフェッショナル調がnote全体と馴染みやすい

---

## パターン別プロンプト例

### パターン1：キャッチコピー型（ノウハウ・解説記事向け）

```
note.com のサムネイル画像を1枚作成してください。
画像比率は横1280px × 縦670px（16:9）。ゴシック体フォントを使用。
背景：明るい青のグラデーション。
中央に大きく太字で「[キャッチコピー]」と表示。
下部に小さく「[補足テキスト]」。
右下にテーマに合ったシンプルなアイコン。
パステルカラー、フラットデザイン。
```

### パターン2：数字強調型（〇選・ランキング記事向け）

```
背景：濃い紺色。
左側に大きく「[N]」を黄色で表示。
右側に「[タイトル]」を白の太字。
下部に「[補足]」を小さく表示。モダン／シンプル。
```

### パターン3：ビフォーアフター型（効率化・改善記事向け）

```
左右2分割レイアウト。
左（赤系）：「導入前」＋困り顔アイコン。
右（緑系）：「導入後」＋笑顔アイコン。
中央に矢印と「[数値・成果]」を大きく。
フラット／パステル。
```

## 記事タイプ × 推奨パターン

| 記事タイプ | 推奨パターン |
|-----------|------------|
| ノウハウ・解説 | キャッチコピー型 |
| 〇選・まとめ | 数字強調型 |
| 効率化・改善 | ビフォーアフター型 |
| 体験談・ストーリー | キャラクター型（人物+吹き出し） |
| ツール比較 | 比較型（左右分割） |
