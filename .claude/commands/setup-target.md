# /setup-target コマンド

## 説明
インタビュー形式で答えるだけで `my-business.mdc` のターゲット設計セクションを完成させるコマンド。
全8問。答えたくない質問はスキップOK。

## 実行方法
```
/setup-target
```

---

## AIへの実行指示

このコマンドが呼ばれたら、以下の手順で必ず実行すること。

---

### 開幕メッセージ（必ず最初にこれを表示する）

```
ターゲット設計を始めます。

「誰に届けるか」が決まると、コンテンツの刺さり方が全然変わります。
全部で8問、1問ずつ聞いていきます。

答えたくない質問はスキップOK。
話し言葉でいいです。思ったままに答えてください。

では最初の質問です。
```

---

### Q1｜誰のことが頭に浮かぶか

```
Q1 / 8

今の発信やサービスで「一番助けてあげたい人」を思い浮かべてください。
どんな人が浮かびますか？

年齢・職業・状況など、思い浮かぶことを何でも教えてください。
（リアルに知っている人でもOKです）
```

**答えが薄かった時（例：「30代の人」「副業してる人」など）の深掘り：**
```
もう少し具体的に教えてもらえますか？

たとえば、以下のどれかに近いですか？
・会社員で副業を始めて少し売れたけど安定しない人
・すでに商品はあるが売上に波がある個人事業主
・SNSや発信はしているが収益に繋がっていない人

または「あの人」と顔が浮かぶ人がいれば、どんな人ですか？
```

---

### Q2｜その人が毎日感じている「理不尽な葛藤」

```
Q2 / 8

その人が日常で「なんかおかしい」「矛盾してる」と感じていることは何ですか？

たとえばこういう感覚です：
・自由になりたくて始めたのに、今が一番不自由
・学べば学ぶほど、逆に動けなくなる
・頑張っているのに、結果が出ない
・商品には自信がある、でも「なぜ私から買うべきか」が言えない

その人が感じている「矛盾・葛藤・理不尽さ」を教えてください。
```

**答えが薄かった時の深掘り：**
```
「努力はしているのに報われない」という感覚はありそうですか？

または、投稿・発信を「止めたいけど止められない」「休みたいけど売上が不安で休めない」
という状態はイメージに近いですか？

「この人が一人でいるときに感じていそうな本音」を教えてください。
```

---

### Q3｜繰り返してきたパターン

```
Q3 / 8

その人は今の悩みを解決しようとして、これまでに何を試してきましたか？

（例：他の人の発信を参考にした、ノウハウを学んだ、コンサルを受けた、
 SNSを頑張った、有料教材を買い続けた、など）

また、「学んだのに実践できなかった」「試したけど続かなかった」
という繰り返しパターンはありますか？
```

**答えが薄かった時の深掘り：**
```
こういうパターンはイメージに近いですか？

「ノウハウに出会う（希望）→学ぶ（満足）→いざ実践しようとすると止まる
→当て勘で出してみる→うまくいかない→また新しいノウハウを探す」

こういった「学んでいるのに同じ場所に戻ってくる」繰り返しはありそうですか？
```

---

### Q4｜本当に欲しいもの（表面と深層）

```
Q4 / 8

その人が「これが手に入ったら最高」と思っているものを教えてください。

2段階で考えてみてください：
① 口に出して言えること（例：安定した売上、発信の自動化、時間の自由）
② その奥にある本音（例：才能ないを証明されたくない、もう不安と闘いたくない）

どちらか一方でもOKです。
```

**答えが薄かった時の深掘り：**
```
「お金が増えた」「時間が増えた」の先に、何を求めていますか？

たとえば：
・「もう毎日怖くない状態になりたい」
・「自分のビジネスに確信を持ちたい」
・「誰かに証明したい気持ちがある」

その人の「本当はこれが欲しい」という本音はどこにありそうですか？
```

---

### Q5｜一番恐れていること

```
Q5 / 8

その人が一番怖いこと・避けたいことは何ですか？

表面的な怖さ（例：売上が下がる）でも、
深いところの怖さ（例：才能がないことが証明される・時間と人生を無駄にする）でも。

「これだけは絶対にそうなりたくない」という感覚を教えてください。
```

**答えが薄かった時の深掘り：**
```
たとえばこういう恐れはありますか？

・「結局、自分には才能がなかったということになること」
・「学んでいるのに結果が出ないまま、気づいたら何年も経っていること」
・「安売りすれば売れる。でもそれは"負け"だと感じる。でも値上げが怖い」

どれかに近いものがありますか？
```

---

### Q6｜なぜ今まで解決できていないか（3つの層）

```
Q6 / 8

その人はなぜ、今まで悩みを解決できなかったと思いますか？

3つの層で考えてみてください：
① やり方の問題（導線がない、計測していない、単発施策に頼っている）
② 設計の問題（商品設計・伝え方・オファーの組み方が弱い）
③ 内側の問題（完璧主義で出せない、自己否定、値上げ恐怖）

全部じゃなくていいです。いずれか1つでも思い当たるものがあれば。
```

**答えが薄かった時の深掘り：**
```
少し聞き方を変えます。

「ノウハウは持っているのに動けない」タイプですか？
それとも「動いているのに再現できない」タイプですか？
または「そもそも何が問題かわからない」タイプですか？

どれかに近いものがあれば教えてください。
```

---

### Q7｜なぜあなたが届けられるか

```
Q7 / 8

あなたはなぜ、その人の悩みに寄り添えると思いますか？

「昔の自分がそうだった」でも、
「お客さんを通じて見てきた」でも、
「だからこそわかる感覚がある」でも。
```

**答えが薄かった時の深掘り：**
```
「自分がその人の立場だった時期」を思い出してもらえますか？

・その頃、何が一番しんどかったですか？
・誰かに助けてもらった体験、または自力で突破した体験はありますか？
・「あの時の自分に言ってあげたいこと」は何ですか？
```

---

### Q8｜誰ではないか・買える状況

```
Q8 / 8

最後の質問です。2つ聞かせてください。

① 「この人には届けたくない」「向かない」という人はいますか？
   （例：完全な初心者・結果だけを求める人・行動しない人 など）

② あなたの商品を「検討できる」のはどんな段階の人ですか？
   （例：副業で5〜10万の実績がある人、すでに個人事業主として動いている人 など）

どちらか答えにくい場合はスキップOKです。
```

---

### 生成フェーズ

全8問が終わったら（またはスキップが3問以上になったら）、以下を実行する。

**1. 以下のメッセージを表示してから処理を始める：**
```
ありがとうございます。回答をもとにターゲット設計を作ります。少々お待ちください。
```

**2. 以下の構成でターゲット設計を生成する：**

```markdown
## ターゲット設計

### 基本プロフィール
[Q1・Q8の回答をまとめて、具体的で読み返しやすい1〜2段落で書く]
[「誰か」が鮮明にイメージできるレベルの解像度で]

### この人が毎日感じている葛藤・矛盾
[Q2の回答をもとに、その人の「言葉にならない理不尽感」を書く]
[「〜なのに〜」という矛盾の形式で2〜4個書くと使いやすい]
[ここがコンテンツのフックになる]

### 繰り返してきたパターン
[Q3の回答をもとに、「なぜ同じ場所に戻ってくるか」の構造を書く]
[ノウハウジプシーのループがあれば明示する]

### 欲求の層
**表面的欲求（言えること）**：[Q4の表面欲求]
**深層の欲求（本当に欲しいもの）**：[Q4の深層欲求]
**一番恐れていること**：[Q5の回答]

### なぜ今まで解決できていなかったか
- やり方の問題：[Q6の①]
- 設計の問題：[Q6の②]
- 内側の問題：[Q6の③]
（該当しない層は省略してOK）

### なぜあなたが届けられるか
[Q7の回答をもとに、ターゲットとの共通点・寄り添える理由を書く]

### この人ではない（対象外）
[Q8の①がある場合のみ記載]
```

**3. 生成した内容をチャットに表示し、以下を聞く：**
```
これで my-business.mdc のターゲット設計を更新します。

変えたい部分があれば「〇〇の部分をこう変えて」と教えてください。
問題なければ「保存して」と言ってください。
```

**4. 「保存して」と言われたら：**
- `.cursor/rules/my-business.mdc` を開く
- `## ターゲット設計` セクションを生成した内容で置き換える
- 「✅ ターゲット設計を保存しました」と伝える
- 「次は `/setup-character` でキャラクター設計もできます」と案内する

---

## 注意事項

- 質問は必ず1問ずつ行う。複数の質問を一度に聞かない
- 前の回答のキーワードを次の質問に自然に織り込む
- 「わからない」「ない」「スキップ」はそのまま受け入れて次へ進む
- 絵文字・過剰な明るさは使わない。落ち着いたトーンで進める
- 「素晴らしい回答です！」等の過剰な褒め言葉は使わない
- 生成した「葛藤・矛盾」のセクションは特に丁寧に書く。ここがコンテンツの一番の燃料になる
