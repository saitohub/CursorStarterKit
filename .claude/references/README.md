# .cursor/references/ — AIが「育つ」につれて埋まっていく場所

このフォルダは、**最初は空でOK** です。

> **補足**: このフォルダ（`.cursor/references/`）は、**キット全体でAIに参照させたい資料**の置き場です。  
> 個別のスキルが使う資料は、そのスキルフォルダの中にある `references/`（例：`.cursor/skills/journal-crystallizer/references/`）に置かれています。混同しないでください。

---

## このフォルダの役割

AIに繰り返し参照させたい「厚めの参考資料」を置く場所です。

- ルール（`rules/*.mdc`）に書くには長すぎる
- でもコンテンツ（`03_Knowledge/`）ではない
- スキル（`skills/`）から参照して使いたい

そんな資料を置く場所です。

## 例

運用を続けていくと、こういうファイルが自然と生まれてきます。

- `persona-deep.md` ……人格の深掘り版（ルール本体には書ききれなかった背景・エピソード）
- `business-deep.md` ……ビジネス設計の深掘り版
- `writing-corrections-log.md` ……AIの出力に入れた修正ログ（差分分析の蓄積）
- `customer-cases.md` ……お客様の声・事例集

全部、運用しながらAIと一緒に作っていくものです。最初から埋めようとしなくて大丈夫です。

## どうやって作るのか

`/setup-character` や `/setup-target` でルールが大きくなりすぎた時、  
または差分分析ループの中で「これルールに入れると重いな」と感じた時に、  
AIに「この部分は `.cursor/references/` に分離してほしい」と頼めば、AIが勝手に切り出して作ります。

自分で作るものじゃなく、**AIが必要を感じたタイミングで育てていく場所**だと思ってください。
