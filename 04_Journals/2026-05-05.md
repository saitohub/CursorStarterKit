#### 今日のメモ

**5月4日の学び（ジャーナル・読書ベース）**

- 『超デザイン思考』1章を「自分ごと」で解きほぐした。**問い（どうしたい／お前はどうしたい）→ 小さな違和感 → ネガが出たら逆転（やらないから面倒）→ 最短で形にして検証 → 振り返ってループ**、という流れを自分の言葉でつかめた。
- **着手回避**に気づいたときの処方：**作業興奮の呼び水**（関連動画を短く複数、期限つき）、長い動画は **10分単位に分解**するのが自分仕様。
- **理想は味わう**（五感・身体・感情まで）。共振共鳴は「会いたくて震える」級の身体反応もヒント、というメタファで整理。
- 第2章：**アイデアを育てる読書**を夜の枠で自分ごとに落としたい。**「どうしよう」で引きこもるときは自分だけで抱えず、人・AI・他業種・調べる**で枠の外に出る。
- **理想が実現しない典型的パターン**（理想が高すぎる／他人の理想／理想がない）と、**きっかけ設計**（机・星マークなどで「どうしたい」を想起）をメモした。
- **Wi-Fi子機インストール**：公式ドライバ DL、ディスク非対応、SmartScreen で止まったら推奨事項で進めた——**詰まったら設定・別ルートを試す**の実物ログ。

**5月5日の学び（振り返り・設計として）**

- **ジャーナル・AI分身・Obsidian は「収益メーター」ではなく「前段のインフラ」**として積み上がっている、と切り分けると腑に落ちる。
- **収益化に必要な行動をしない → お金が増えない**は、人格ではなく **ポートフォリオの問題**。だから **収益レーンに触れる回数**を別メーターで見るのが有効。
- 着地：**収益化レーンは週に最低1回、カレンダーに固定（短時間でも可）**。

**メタファ（逆転の言葉・追記）**

- 「逆転の言葉」というニュアンスがしっくりくる。**イメージは2アウト満塁で一打つ感じ**。
- 「もうダメかも」が強い場面ほど頭がネガとプレッシャーで固まりやすい。そこで逆転の一文は、魔法より **バットを振れる状態に戻すための言語**（カウント・打球方向の調整みたいなもの）。
- 毎打席ホームランじゃなくても、**凡打でもランナーが返れば点が入る**のと同じで、一点でもいいから外向きの検証に繋げられればよい。
- note の見出しフック例：**「2アウト満塁の頭の中で、一打にする一言」**。

#### ビジネス・仕事で気になったこと

**収益化につながる抽出（優先度順イメージ）**

1. **「やってもお金にならない → やったらお金になるかも」逆転**  
   発信・商品化・オファー前のブレーキにそのまま使える。**検証が最短**というより「お金の話から逃げない一文」として機能させる。

2. **最短検証＝手数を打つ**  
   読書感想だけで終わらず、**下書き1段落／見出し3つ／誰か1人かAIに「これ有料ならいくら？」と聞く**など、消える前に**外向きの形**にする。

3. **違和感・障害のリアルタイムログはコンテンツの種**  
   「配達が気になる」「SmartScreenで止まった」などは、同じ詰まりを持つ層向けの**共感・手順ネタ**になりうる（自分の実績・体験の範囲で語れる）。

4. **AI画像・環境整備は「理想の具体化」＝制作プロセスのデモ**  
   教えるビジネスなら、**理想→プロンプト→画像／快適な作業環境**は**見せられる成果物**になりやすい。

5. **枠の外（他者・市場）**  
   収益は一人の頭の中だけでは決まらない。**他者のやり方・反応**を見に行くのは、そのまま**ニーズ確認・競合・価格感**の調査になる。

#### 今日エネルギーが上がった瞬間／下がった瞬間

上がった：

- 読みながら **自分の弱点（Amazon・集中時間）を攻略本として読めている**実感。
- **逆転の言葉（やらないから面倒）**でブレーキが言語化できたとき。
- **Wi-Fi が進んだ**（詰まりを突破した）とき。
- （5月5日の整理）**インフラは積み上がっている／収益は別レーン**と切り分けられたとき——モヤモヤが「設計の話」に落ちた感じ。

下がった：

- **読みたくない潜在意識**と配達気になって **ループしそうなとき**。
- **長時間コンテンツに対する集中の不安**（だから分解が処方になった）。
- **収益にまだ結びついていない感じ**——ここは「やってないから」で説明がつくぶん、認めると次の一手だけ決めやすい。
