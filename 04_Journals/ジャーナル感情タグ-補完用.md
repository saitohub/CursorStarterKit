## 書くとき・読み返すとき（これだけ）

1. **編集できる画面にする**  
   読み返すときも、タグを足すなら **編集モード**（ソースモード or ライブプレビューでカーソルが置ける方）。読み取り専用のままだと追記できません。

2. **感情が動いたところにカーソルを置いて `#` と打つ**  
   候補に `#💡` などが出たら選ぶ。一文の末尾でも、行の途中でも、**好きな位置に何回でも**足してよいです。

3. **候補が出ない・迷子になったら**  
   `ジャーナル感情タグ-補完用` を **別タブで常時開いておき**、表の `#💡` などを **コピペ**する（一番確実）。

4. **迷ったら**  
   絵文字だけ貼って終わりにしないで、**必ず `#` 付き**（例: `#💡`）にする。週次ジャーナル側は「タグ」としてこの形を拾います。

## 「# しか出ない」のはなぜ？

**Cursor や VS Code で `04_Journals` のメモを開いて書いているとき**  
ここは **Obsidian ではない**ので、Vault に登録された「感情タグ」の一覧を `#` から引く機能はありません。`#` はただの文字なので、補完に **シャープそのもの**や Markdown 用の候補だけが出て、**#💡 が並ぶことは基本的にない**です。

**Obsidian で同じフォルダを Vault にして書いているとき**  
`#` のあとにタグ候補が出ることもありますが、バージョンや設定、絵文字タグの相性で **薄い／出ない**こともあります。

**どちらでも確実**なのは、このノートの表から `#💡` などを **コピペ**するか、Mac の **テキスト置換**で略から一発で出すことです。
