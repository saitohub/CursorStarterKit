# 07_Swipe — 他人の実例・参考事例ライブラリ

> **重要：このフォルダの中身は全て「他人の」実績・文章・事例です。**  
> **自分のストーリー・実績として使うことは絶対にできません。**

## このフォルダの目的

「この人のセールスレター上手いな」  
「このメルマガの構成、真似したい」  
「このSNSの切り口、参考になる」

こういう「いいな」と思った他人の事例を、ここに貯めていく場所です。

コンテンツを作るときに「構造の参考」として使います。  
中身の文章やストーリーをコピーするのではなく、  
**「この構成パターンを、自分の素材で再現する」** という使い方。

## フォルダ構成

```
07_Swipe/
├── Sales Page/    ← 他人のセールスページ・LP
├── Email/         ← 他人のメルマガ・ステップメール
├── SNS/           ← 他人のSNS投稿（X・Instagram等）
└── Copy/          ← 広告コピー・見出し・キャッチフレーズ
```

## ファイル名のルール

```
Swipe - {誰の / 何のコンテンツか}.md

例：
Swipe - ○○さんのセールスレター（商品名）.md
Swipe - ○○さんのメルマガ1通目.md
Swipe - ○○さんのX投稿（数字で見せる切り口）.md
```

## 保存するときのコツ

ファイルの冒頭に以下を書いておくと後から使いやすくなります。

```markdown
---
source: 誰の・どこで見つけたか
url: あればURL
date: 保存した日付
memo: なぜ「いいな」と思ったかを一言で
---
```

**「なぜいいと思ったか」を一言メモするだけで、後から参照する価値が10倍になります。**

## AIへの指示例

```
「@07_Swipe/Sales Page/Swipe - ○○.md の構成を参考にして、
 自分の03_Knowledgeの素材でセールスレターを書いて」

「@07_Swipe/Email/ のメルマガの構成パターンを分析して、
 共通する構造を教えて」
```

## やってはいけないこと

- Swipeの文章をそのまま自分のコンテンツにコピーする
- Swipeの中にある他人のストーリー・実績を自分のものとして使う
- Swipeの事例を「自分の顧客事例」として引用する
