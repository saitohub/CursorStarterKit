## 1. やる気がなくても動く仕組み

### 最初の着火は、外部の力を借りてよい

行動開始時に使える方法は次の5つ。

1. 作業後の小さなご褒美、または軽いペナルティを決める
2. 大きな期限ではなく、分解した短い期限を複数置く
3. 進捗を他人へ宣言し、見られる状態を作る
4. スマホを別室へ置くなど、作業するしかない環境へ移る
5. 少し先にいる人を比較対象にし、競争心を着火へ使う

これは一時的な着火方法。ご褒美や競争だけで長く走ると、燃え尽きる場合がある。動き始めた後は、内側から続く理由へ移す。

### 続けられる仕事の5要素

行動中に、次の感覚があるかを観察する。

1. 自律性：自分で選び、やり方を調整できる
2. 成長感：少しずつ上達していることが分かる
3. 好奇心：一部分でも、もっと知りたいと思える
4. フロー：簡単すぎず、少し頑張れば届く難度になっている
5. 貢献感：誰かの役に立っている実感がある

一日の終わりに「少し気持ちが乗った作業」を一行だけ記録する。数週間分を見ると、自分が続けやすい条件が見つかる。

### 行動を、快楽とやりがいで点検する

本文で紹介されていた行動活性化を、安全な自己観察へ一般化すると次の3ステップになる。

1. 一日の行動と、その時の「快楽」「やりがい」を各10点で記録する
2. 週に一度、点数が高い行動・低い行動の共通点を探す
3. 低い行動を中止・委任・縮小し、その分だけ高い行動を増やす

自分を責める評価表ではなく、行動と気分の関係を調べる記録として使う。強い抑うつや生活への支障がある場合は、自己流で処理せず専門家へ相談する。

### 習慣は「実行後の心地よさ」まで設計する

習慣化では、いつ・どこで行うかだけでなく、実行後に得られる小さな心地よさも決める。

- 実行の合図：既存の習慣や時間と結びつける
- 邪魔の除去：スマホ、疲労、準備不足を先に処理する
- 小さな報酬：終了後に休憩、飲み物、記録などを置く
- 再開手順：一日抜けた時に、翌日どう戻るか決める

連続日数を守るより、止まった後に戻れる設計を重視する。

## 2. AIを使う時の判断基準

### AIは答えを出す人ではなく、考える補助役にする

AIと会話を続ければ、いつか完全な答えへ到達するとは限らない。先に人間側で決める。

- 何を決めたいのか
- 正解を何で判定するのか
- 変えてよい条件と、変えてはいけない条件
- 事実確認が必要な部分

AIには、選択肢、抜け漏れ、反対意見、文章の叩き台を出させる。最終判断と責任は人間が持つ。

### 良いプロンプトは、AIに逆質問させて作る

自分の指示不足は、自分では気づきにくい。最初から完璧な依頼文を書こうとせず、AIへ次の役割を渡す。

1. 依頼文の目的を確認する
2. 足りない条件を一問ずつ質問する
3. 回答を反映した依頼文へ書き直す
4. 曖昧な言葉と矛盾を指摘する
5. 最終版を実行する前に確認する

「初心者向け」のような抽象語だけでなく、読者、文字数、前提知識、使う場面、避けたい表現まで具体化する。

### AIへ任せやすい仕事・任せにくい仕事

任せやすい仕事：

- アイデアの発散
- 要約、分類、形式変換
- 文章の初稿と複数案
- 観点や質問の洗い出し

慎重に扱う仕事：

- 一つのミスが全体を壊す計算
- 厳密な条件分岐や論理証明
- 社内事情・契約・法令を含む判断
- 医療、法律、投資など高リスクの助言

タスクを細かく分け、AIが作った部分を検証できる工程だけ任せる。「AIの回答は何％が嘘」などの数字は、元論文を確認できない限り引用しない。

### AIを使うほど、一次情報へ戻る

- AIの答えに出典を付けさせるだけで信用しない
- 出典ページを実際に開き、主張が書かれているか確認する
- 日付、対象者、サンプル数、比較条件を見る
- 複数の一次情報が一致するか確かめる
- 確認できない時は「不明」と書く

AIは調査の入口を速くする道具であって、証拠そのものではない。

## 3. 起業と商品づくり

### 資格は入口であり、商品ではない

資格を仕事へ変える流れは次の3段階。

1. 試験は過去問を中心に、合格に必要な範囲を学ぶ
2. 現場で技術、見積もり、顧客対応、トラブル対応を経験する
3. 集客と営業を学び、自分で仕事を得られるようにする

資格の知識だけで支援範囲を広げない。資格が必要な領域では、法令、実務経験、保険、責任範囲も確認する。

### 商品は顧客と一緒に作る

一人で完成品を作ってから売るより、仮説段階で顧客と話す。

1. すでにお金が動いている市場を探す
2. 解決されていない強い悩みを仮置きする
3. 属性や状況が異なる複数人へ聞く
4. 小さな試作品を見せ、使い方と反応を確認する
5. 有料で提供し、実行結果から修正する

「顧客と一緒に作る」は、相手の要望を全部入れることではない。誰のどの問題を解く商品かを守りながら、理解しづらい点や不足する支援を直す。

### 顧客の言葉は、発言・行動・購入を分けて見る

顧客本人も、本当に欲しいものを正確に言語化できるとは限らない。アンケートの回答だけで商品を決めず、次を組み合わせる。

- 発言：何に困っていると言ったか
- 行動：何を検索し、何を試したか
- 購入：何へ実際にお金や時間を払ったか
- 継続：何を使い続け、何をやめたか
- 背景：購入直前に何が起きたか

誘導尋問を避け、過去の具体的な行動を聞く。顧客が使った言葉は、商品名や販売文の素材にする。

### 強い悩みだけで高額化しない

本文では「まだ解決されていない深い悩み」が高単価商品に向くとされていた。しかし、悩みの強さを利用して価格を上げるだけでは危険。

価格を決める時は次を見る。

- 得られる変化と、その根拠
- 必要な期間と提供時間
- 個別支援、添削、質問対応の範囲
- 実行できない場合のリスク
- 代替手段との違い

医療・心理・法律・投資などは、悩みが強くても安易に商品化せず、資格と安全性を優先する。

## 4. マーケティングと顧客理解

### ペルソナは仮説であり、排除条件ではない

細かい人物像を作っても、その属性以外の人が買うことはある。年齢・性別だけで対象を固定せず、実際の購入データを見る。

- 誰が見たか
- 誰が相談したか
- 誰が買ったか
- 何が購入理由だったか
- 誰が継続したか

ペルソナは文章を書く時の仮の相手として使い、販売対象を狭める絶対条件にしない。

### 最初はコア層、反応が取れた後に周辺層へ広げる

1. 問題意識が強く、すでに情報や商品を探している人へ売る
2. その人たちの質問・購入理由・実行結果を集める
3. 商品と説明を改善する
4. 問題意識が弱い周辺層へ、入口の言葉を広げる

最初から全員向けにすると、誰のどの問題を解くかが薄くなる。一方、コア層の属性だけに閉じると市場を狭める。問題の強さと購入行動で段階を分ける。

### 他社を真似る時は、表現でなく仕組みを分解する

ロゴ、文章、商品名、体験談をコピーしない。見るのは次の構造。

- 誰の何を解決しているか
- 入口商品から本商品までの流れ
- 顧客が信用する根拠
- 実行を助ける支援
- 継続・紹介につながる理由

構造を自分の顧客・経験・提供範囲へ置き換え、小さく検証する。

### 無料ツール・特典は、本商品と同じ問題を扱う

無料配布は人数を集めるためだけに作らない。

- 本商品の対象者が使いたい内容か
- 小さな変化を体験できるか
- 提供者の判断基準が伝わるか
- 次の相談が必要な条件が分かるか

「無料で渡し、一部が有料相談へ進む」という導線は使える。ただし、個人情報の取得目的、配信同意、解除方法を明示する。

## 5. セールスを倫理的に使う

### 本音を聞く前に、安全な質問環境を作る

第三者の事例を出すと、話しづらいテーマを考えやすくなる。ただし、心理術で個人情報を聞き出す使い方はしない。

1. なぜ質問するか説明する
2. 答えたくない質問は飛ばせると伝える
3. 第三者の事例は、選択肢を見せるために使う
4. 推測で決めつけず、本人へ確認する
5. 得た情報を提案以外へ流用しない

相手の不安を先回りして解消することと、不安を作って購入させることは別。購入しない選択肢も残す。

### 即決より、判断材料をそろえる

- 今の問題
- 望む変化
- 商品でできること・できないこと
- 必要な時間と本人の作業
- 価格、解約、返金、サポート条件
- 他の選択肢

これらを提示し、相手自身が判断できる状態にする。「黒すぎる心理術」のような強い表現は件名の注意喚起として使われているが、操作的な技法は転用しない。

## 6. 感情整理・ジャーナリング

### 考えを、事実として扱う前に検証する

本文で紹介されていた認知行動療法を、日常の軽い振り返りへ一般化すると次の流れになる。

1. 強い感情が出た時、頭の中の言葉を書く
2. その考えを支持する事実と、反する事実を分ける
3. 他人ならどう見るか、別の説明を作る
4. 安全な小さい行動で確かめる
5. 結果を記録し、考えを修正する

一回で劇的に変わるとは考えない。診断や治療の代わりに使わず、症状が強い場合は医療・心理の専門家へ相談する。

### 感謝・感情の書き出しは、万能薬にしない

感謝できることを3つ書く、感情を自由に書く、という方法が紹介されていた。使う場合は次に注意する。

- 無理に前向きな意味を作らない
- 書いた後に苦痛が強まるなら中止する
- 事実、感情、望む状態、次の小さな行動を分ける
- 効果期間やIQ向上など、出典のない数字は信じない

### 愛着障害・アダルトチルドレンを自己診断しない

メールには、親との距離、手本となる人の行動観察、安全な人間関係での練習などが登場した。一般的な判断基準として使えるのは次の部分。

- 自尊心を継続的に傷つける関係から距離を取る
- 安全な関係で、境界線や頼り方を少しずつ練習する
- 信頼できる人の行動を観察し、自分に合う範囲で試す
- 一人で悪化する場合は専門家へ相談する

「愛着障害」「アダルトチルドレン」などのラベルをメールのチェックリストだけで確定しない。家族との断絶を一律に勧めない。

## 7. そのまま信じず、検証が必要なもの

- 医療、認知症、ホルモン、IQ、寿命に関する効果と数値
- 愛着障害、アダルトチルドレン、メンタル疾患の自己診断
- 円相場、失業率、年利、資格収入など将来予測
- AIの誤答率、生産性、失業への影響を示す割合
- 企業の売上や失敗原因を一つに絞ったケース分析
- 政党、選挙、国際情勢についての断定
- 「誰でも」「確実に」「一瞬で」など再現条件のない表現

外部へ使う場合は、一次情報、論文、公的資料、企業の公式情報を確認する。

## 8. メール構成として使えるもの

### 連続講座型

1. 前回の要点を一行で復習
2. 今回の位置を「3ステップの2番目」のように示す
3. 失敗例または身近なたとえを置く
4. 3〜5個の手順へ分ける
5. 今日一つだけ試す行動を示す
6. 次回の未解決部分を予告する

### 企業事例型

1. 誰でも知る企業・商品への疑問
2. 一般に信じられている説明
3. 数字や行動から見える矛盾
4. 本当の原因についての仮説
5. 個人の商品へ転用する問い

企業分析は断定せず、「公開情報からの仮説」と明示する。

### 強い件名の作り方

- 常識の否定：「〇〇するほど失敗する」
- 数字付き手順：「3ステップ」「5つの方法」
- 身近な対比：「歯磨きは続くのに〇〇は続かない」
- 有名事例：「大谷翔平」「Microsoft」
- 損失回避：「AIに任せてはいけない仕事」

件名を強くしても、本文では根拠・条件・例外を置く。恐怖だけで開封を迫らない。
