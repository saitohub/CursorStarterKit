# 全体構造マップ

```
① 結論一行先出し
   「人は見たいようにしか世界を見ない。見てる世界を変えよう。」

② 数字フックで引き込む
   「4時間で書いた販売ページ1枚で1600万」
   → 自分で計算：「時給400万超え？？」

③ 興奮を友人にぶつける→冷たいリアクション（共感の崩し）
   「どうせ情弱狩りでしょ？エビデンスは？？」
   → 友人の現状（300記事・先月4000円）を明かす

④ 「友人の頭の中」を解剖
   友人が見えている世界（SEO・量産・デザイン）を言語化
   → その世界観では「4時間で1600万」が認識できないと説明

⑤ 友人に見えていない世界を列挙
   ・SNS一切使わずブログ＋メルマガで月500万
   ・ヤフオクとメルマガを組み合わせて月300万
   → 「これ私が直接会って話した人たちです」

⑥ 心理ブロックの先回り解説
   「短期成功者を見ると、自分のがんばりを否定された感覚になる」
   → 見えない理由を心理から説明することで読者の防衛心を解除

⑦ 全く別軸の事例で「あるだろうな」を補強（気功師研究）
   東工大×気功師の研究→一般人でも脳波の乱れを起こせた
   → 「目に見えないものも"あるだろうな"という世界観」

⑧ 自分のビジネスの簡素さを示す
   「月1万以内でスタート・資金不要・脳みそが商品」
   → MBA400万や資金1000万と対比

⑨ 二つ目の体験談（スタバ・バー）
   スタバで午前中だけ5万売上
   バーで知り合った人にメール1本送ったら購入

⑩ キーワードで着地
   「まずは"あるだろうな"から始めてみましょう」
```

# テクニック別分析

## 1. 「自分で計算式を出して驚く」フック

**原文：**
> 時給400万超え？？、、みたいな状態。

**構造：**
```
数字の事実を提示（4時間・1600万）
→ 自分で計算（÷4h）
→ 計算結果に自分が驚く「？？」
→ 「みたいな状態」と少し引いた言い方
```

**なぜ効くか：**
- 読者が自分で計算する前に、書き手が先に計算してくれる
- 「？？」「みたいな状態」という引いた表現で押しつけ感をなくす
- 数字の組み合わせ（時間×金額）で衝撃が2段階になる

---

## 2. 「友人との対比」で成功を間接的に語る技法

**構造：**
```
自分の発見を友人に話す（興奮状態で）
→ 友人のリアクションが冷たい
→ 友人の現状を明かす（300記事・4000円）
→ 友人の頭の中（思考パターン）を言語化
→ 友人に見えていない世界を列挙
→ 「私のことも疑った目で見てた」と一言
```

**なぜ効くか：**
- 自分の成功を直接語らず「友人が見えていないもの」として語る
- 読者は「自分も友人と同じかも」と焦る
- 友人の思考パターンの言語化が「自分ごと化」のトリガーになる

---

## 3. 心理ブロックの先回り解説

**原文：**
> 裏ルートや近道で稼いでる人を見てしまうと、自分のがんばりを否定された感覚になります。

**構造：**
```
「なぜ人は信じられないのか？」を読者より先に言語化
→ 心理的な理由（努力を否定された感覚）を説明
→ 「だからこそ見える世界を変える必要がある」へ展開
```

**なぜ効くか：**
- 読者の「疑い」を先に言葉にすることで、読者は「わかってくれてる」と感じる
- 「見えない理由」を解説することで「見える側に移れる」可能性が生まれる
- 批判を防衛しつつ共感を生む

---

## 4. 「全く別軸の事例」で核心概念を補強

**気功師研究のエピソードの役割：**

```
ビジネスの話をしていて…
→ 突然「気功師と東工大の研究」の話に飛ぶ
→ 「目に見えないものが存在する」実例を示す
→ 「だからビジネスの世界でも"あるだろうな"は成立する」へ帰着
```

**なぜ効くか：**
- ビジネスの外側の事例を使うことで「普遍的な原則」に格上げされる
- 読者の「ビジネスへの疑い」が薄れる（ビジネスに限った話ではないから）
- 意外性が高く、話を読み続けさせる力がある

---

## 5. 「あるだろうな」というキーワードの設計

**キーワードの特徴：**
- 「信じる」ではなく「あるだろうな」という曖昧さが受け入れやすい
- 完全に信じなくていい、ただ「可能性を排除しない」だけで足りる
- 3回繰り返し使用して定着させる（気功師→1600万→着地）

**使用箇所：**
1. 「1600万も稼ぐとかって言っても"あるだろうな"と思えるわけです」
2. 「気功も"あるだろうな"って世界観」
3. 「まずは"あるだろうな"から始めてみましょう」（着地）

---

## 6. 体験談の2段重ね

**1本目（遠い事例）：** 知人が4時間で1600万
**2本目（自分の事例①）：** スタバで午前中5万
**3本目（自分の事例②）：** バーで知り合いにメール1本→購入

**なぜ3段階か：**
- 遠い事例→「すごすぎて自分ごとにならない」
- 自分の日常事例→「これが私の普通です」の証明
- バーの話→「こんな偶発的なことでも売れる」という意外性
