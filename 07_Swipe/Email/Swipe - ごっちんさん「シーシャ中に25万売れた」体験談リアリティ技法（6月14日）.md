# 「シーシャ中に25万売れた」体験談リアリティ技法

## 原文（6/14 19:30）

> 先日、サラリーマン時代の後輩とシーシャに行ったのですが、
> シーシャでリラックスしてた３時間ぐらいの間に、
> 5万円の商品と20万円の商品が売れた通知がピコーンと鳴りまして、
> 彼の月収とほぼ同じぐらいの金額を稼いでしまいました。
>
> つい「あ、2本売れた」って言ってしまったら、
> いくらですかいくらですか！？ってしつこく聞くので、
> 言いたくなかったのですが言ってしまったら・・・
>
> マジで働く気無くします・・・
> となってしまって申し訳なくなりました。
>
> 知識を得たら、信じざるを得ないよ、
> ということで企画の案内を置いておきます。

---

## 構造分析

```
[場所・状況の具体化]「サラリーマン時代の後輩とシーシャに行った」
  → 「シーシャ」という特定の場所で、「後輩と一緒に」という状況が絵として浮かぶ

[時間の具体化]「3時間ぐらいの間に」
  → 「3時間何もしてない間に」ということが伝わる

[金額の具体化]「5万円の商品と20万円の商品」
  → 合計25万円、内訳まで言うことでリアリティが増す

[通知音の描写]「ピコーンと鳴りまして」
  → 擬音が情景をリアルにする

[比較で衝撃を出す]「彼の月収とほぼ同じぐらいの金額を稼いでしまいました」
  → 「彼の月収」という身近な基準で金額の大きさを感じさせる

[つい漏れた感の演出]「つい"あ、2本売れた"って言ってしまったら」
  → 自慢ではなく「うっかり言ってしまった」という謙虚さを演出

[後輩のリアクション]「いくらですかいくらですか！？ってしつこく聞くので」
  → 第三者の反応を入れることで、すごさが「客観的な事実」になる

[オチ]「マジで働く気無くします…となってしまって申し訳なくなりました」
  → 後輩の言葉をそのまま引用。「申し訳ない」という謙虚な締め

[教訓への着地]「知識を得たら、信じざるを得ないよ」
  → 体験談を「知識の話」に着地させてCTAへ自然につなぐ
```

---

## なぜ効くか

| 要素 | 効果 |
|------|------|
| 「シーシャ」という場所 | リラックス中＝何もしていない、が一言で伝わる |
| 金額の内訳を言う | 5万＋20万、合計25万。内訳があると嘘っぽくならない |
| 「彼の月収と同じ」 | 読者が自分の月収に置き換えやすい。インパクトが個人的になる |
| 第三者のリアクション | 「後輩が驚いた」は自己申告より信頼性が高い |
| 「申し訳なくなった」 | 謙虚な着地が自慢話に見えない |
| 「信じざるを得ない」 | 読者に「あなたも体験してみれば信じる」というメッセージ |

---

## 体験談リアリティの5要素

1. **場所の具体性**（シーシャ、カフェ、散歩中）→ 情景が浮かぶ
2. **時間の具体性**（3時間、昨日の朝）→ スケールが伝わる
3. **金額の内訳**（5万+20万）→ 丸めた数字より信頼性が高い
4. **第三者のリアクション**（後輩が驚いた）→ 客観的な証言になる
5. **謙虚な着地**（申し訳なくなった）→ 自慢話に見えない
