# Swipe - Threads個人投稿ルール（ChatGPT用プロンプト）

## 直した理由（3点）

1. **語尾のバリエーション** — 一文ごとに違う語尾を使うことで、読み手に「人間が話してる」感覚を与える
2. **口語の揺らぎ** — 「いや」「正直」「マジで」といった言い淀みが、親密度を上げる
3. **短い一言の挟み込み** — 長文の緊張をほぐし、独り言っぽい「間」を作る

## ChatGPT に貼るプロンプト

```
次のテキストを「個人的なThreads投稿」として書き直してください。
以下の5つのルールを厳密に守ってください：

1. 一文ごとに語尾を変える
   - 「何々してた」「何々ないよねー」「何々だわ」「何々ちゃん」を混ぜる

2. 口語の揺らぎを最低1つ入れる
   - 「いや」「正直」「マジで」みたいな言い淀みを使う

3. 長い文の後に5字以内の短い一言を必ず挟む
   - 例：「AIが処理してる間に何もしてない感覚があった。でも」「それが答えだった」

4. 大言止めの連発とデスマスぞろえは禁止
   - 説明調を避ける
   - 〜です。〜ます。の連続を避ける

5. 優等生っぽい説明トーンを消して、独り言に寄せる
   - 「ということがわかりました」→ 削除
   - 「〜なのだ」→ 「〜なんだ」
   - 相手に説明する感覚を消す

【ここに投稿テキストを貼る】
```

## 適用ガイド

このルールは「AIっぽさを消して、サイジムの素の声」を作るため。

- AIに一度書かせたものをこのルールで「人間化」する
- 毎回 ChatGPT に貼って、機械的な文体を修正させる
- 修正されたテキストをさらに自分で読み直して、違和感を消す

## 重要

「AIっぽいのはプロンプトのせい」という気づきが本質。
プロンプトがダメなら、結果もダメ。

だから、AIに指示を与える前に「このプロンプトで人間っぽい文章が出るか」を考える。

## 実例

### Before（整理された感じ）

ノウハウで上級者と戦っても勝てない。感情的価値なら、始めたばかりでも最初から持っている。20年の営業で学んだことは自分にしか話せない。「いつも来るから頼めばいい」という一言はAIには書けない一次情報。昨日つまずいたことは、明日つまずく誰かの宝物になる。

### After（Threads個人投稿版）

ノウハウで上級者と戦っても勝てないんよね。感情的価値なら、始めたばかりでも最初から持ってた。正直、20年の営業で学んだことは自分にしか話せないし。「いつも来るから頼めばいいや」っていう一言は、AIには絶対書けない。それが一次情報。昨日つまずいたことが、明日つまずく誰かの宝物になるじゃん。

#### 直した理由（3点）

1. **語尾のバリエーション** — 一文ごとに違う語尾（なんよね、てた、し、ない、じゃん）を混ぜることで、読み手に「人間が話してる」感覚を与える
2. **口語の揺らぎ** — 「正直」という言い淀みを入れることで、親密度を上げる
3. **短い一言の挟み込み** — 「それが一次情報」という5字の短い一言を長文の後に挟んで、独り言っぽい「間」を作る
