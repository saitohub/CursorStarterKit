## 1. 元記事の構成（目次＝骨格）

1. **導入（リード）**  
   現場の痛み（概要欄が地味に時間を食う）→ 原因仮説（毎回ゼロから／テンプレの温度感が合わない）→ 今夜の一手（素材を投げて型通りに5本）→ 狙い（人間の作業を「素材を埋める」に圧縮）。

2. **こういう困りごと、ありませんか**  
   SEO・維持・誘導の重要性と手間のギャップ／テンプレがスケルトン止まり／複数本でトーンが疲労で崩れる／情報は手元にあるのに重い、の積み上げ。

3. **試したこと**  
   概要欄を5ブロックに分解、文字数・トーン固定、5本分の素材を一括投入。素材側もテンプレ化（項目列挙）。

4. **使ったプロンプト**  
   ロール指定 → 【出力ルール】（順序・字数・トーン統一・禁止・動画番号・空行）→ 【素材情報】プレースホルダ → 【出力】前置きなしで本体のみ。コピペ運用の一言。

5. **戻ってきたもの**  
   構造が守られた出力の説明＋仮置きの抜粋例（動画1ブロック）。

6. **効いた指示・工夫したポイント**  
   順序固定／字数は幅指定／禁止表現／URLプレースホルダ／絵文字禁止、など箇条書きで根拠化。

7. **カスタマイズ・他用途への応用**  
   トーン差し替え、ブロック増減、SNS抽出、メタディスクリプション、外注下地。

8. **使い心地・気づき**  
   作業の集中先の変化／本数まとめての効き／詰まり（要点の絞り）／URL運用のコツ／品質の体感。

9. **所要時間のまとめ**  
   内訳表（素材・生成・差し替え）と手作業との対比。

10. **結びに**  
    短く数が多い文章は型＋一括が効く／ショート・サムネ等への接続／締めの一言。

11. **末尾**  
    ハッシュタグ・クリエイター情報・おすすめ記事リスト（noteらしい回遊ブロック）。

## 2. 記事内コンテンツの「型」（構造だけ抜き出し）

### 概要欄5ブロック（順序固定）

1. 冒頭フック：1文（字数レンジ指定）。視聴者の悩み・状況を一言で。
2. 動画内容の要約：3〜4文（合計字数レンジ）。淡々と何が分かるか。
3. タイムスタンプ：`00:00 章タイトル` 形式・1行ずつ。
4. 関連動画3本：`・タイトル → URL`（URLはプレースホルダ可）。
5. チャンネル誘導：2文（合計字数レンジ）。登録・通知を自然に。

### 素材情報テンプレ（1動画あたり）

- タイトル／想定視聴者／要点3〜5／章（タイトル＋開始位置）／関連動画3本のタイトル／チャンネル一言説明（全体で1〜2文）

### プロンプト側の設計パターン（再現用メモ）

- ロール（概要欄ライター）→ 出力順・必須ブロックを番号で固定。
- 全体トーン（例：落ち着いた敬体）と、5本通しの統一指示。
- 禁止（煽り・過度な強調・絵文字・装飾記号など）を明示。
- 動画番号ラベル・ブロック間の空行など「貼り付け後の見た目」まで指定。
- 前置き・説明文を出さない締め。

※ **プロンプト全文は元記事に委ねる**（ここでは設計の骨だけ。必要なら元URLから自分用に再取得）。

## 3. 自分用メモ：厳し目振り返り（会話より・参考）

他人の実績ではなく、**記事を読んだあとの評価メモ**。発信や推敲のチェックリストとして使う。

### 良い点

- 困り → 型 → プロンプト → 出力例 → 学び → 時間、の動線が読みやすい。
- プロンプト設計の勘（順序・字数幅・禁止・プレースホルダ）が具体的。
- 「1本だけなら自分で書いた方が早いかも」など、条件付きの正直さがある。

### 突っ込みどころ（厳し目）

1. **「Claude Code」の必然性が薄い**  
   中身は長文プロンプト一括生成に近く、ブラウザ版でも再現しうる。**Code 固有の利点**（ファイル化、バッチ、履歴など）が本文でほぼ立っていないと、タイトルとのズレを突かれやすい。

2. **時間数字の検証可能性**  
   「8分」内訳は強いが、**計測の開始・終了条件・初回／慣れ**が書かれていないと、厳しい読者にはマーケ数字に見えうる。

3. **再現のボトルネック**  
   分秒合わせやリンク差し替えは現場によっては重い。**ばらつきの幅**を一文でも書くと楽観バイアスが減る。

4. **独自性・記事の寿命**  
   ブロック構成自体は定番に近い。全文公開は読者価値は高いが、**コピペで希薄化**しやすいタイプでもある。

5. **コンプライアンス／品質の一文**  
   フックで「悩みを言い当てる」系はチャンネルによっては誇大・誤認に寄りうる。**トーンと法的・倫理の境界**を一文添えるとプロ感が出る。

### 自分の発信に転用するときの型

- 他人の数字・体験を自分のものにしない。
- **「構成パターン」だけ借りる**：導入の痛みの畳みかけ → 一手の宣言 → ルール列挙 → 抜粋例 → 効いた条件 → 応用 → 時間の内訳 → 短い結び。
