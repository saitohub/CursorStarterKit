## 分析対象

- 発信プラットフォーム：Threads
- 実績標榜：「noteで38万稼いだ」
- 使用ツール：UTAGE（ウタゲ）
- 対象商材：AIを活用した副収入スクール

## 導線フロー

```
Threads投稿
  ↓

UTAGE ボタン（クローズド ページ）

  ↓
```

## 各ステップの役割・工夫

### ステップ1：Threads での興味喚起
- **タイトル：** 「noteで38万稼いだ」という具体的な数字
- **工夫：** Threads には note へのリンクを一切置かない
- **目的：** Threads だけでは情報を完結させず、先に進まざるを得ない状況を作る

### ステップ2：UTAGE フォーム（メール取得）
- **形式：** ボタン一つのシンプルな仕掛け
- **工夫：** Threads 上では「宴システム」と表記（UTAGE という正式名を隠す）
- **目的：** メールリストの取得、リード化

### ステップ3：LINE登録への誘導（ダブルオプトイン）
- **トリガー：** メール登録完了画面
- **メッセージ：** 「メールでは届かない可能性があるため、到達率100%のLINE で送ります」
- **工夫：** メールより LINE が「確実」という信頼感を作る
- **目的：** より確実な到達率を確保（メールの開封率より LINE の読了率）
- **時間制限：** 「1分以内に登録してください」という緊急性

### ステップ4：アンケート（セグメント化）
- **質問内容：** 「副業の悩みは何か」という4択
- **工夫：** 閉じられた選択肢で、顧客の課題を分類
- **目的：** その後のメッセージを「その人の悩みに特化させる」準備
- **効果：** 顧客自身が「自分の課題は何か」を言語化する手助け

### ステップ5：スクール勧誘
- **トリガー：** LINE 登録 + アンケート完了後
- **内容：** 「AI を活用した副収入スクール のモニター生募集」
- **工夫：** 「限定的（モニター枠）」という希少性

## テクニック・構造の学び

| テクニック | 効果 | ポイント |
|-----------|------|---------|
| ダブルオプトイン（メール→LINE） | 到達率の二重確保 | LINE が「緊急」「確実」に見える理由づけ |
| 時間制限（1分以内） | 緊急性・決断促進 | 迷う時間を与えない |
| 4択アンケート | 顧客セグメント化 | 閉じられた選択肢で課題を限定 |
| 数字の提示（38万） | 信頼性・動機喚起 | ただし note へのリンクはない（達成方法は不明） |
| UTAGE 使用 | リード自動化 | メール→LINE の流れを自動化できる |

## 疑問点・改善の余地

- Threads には note へのリンクがない
  - 実績の「見える化」がない
  - 信頼性の検証ができない
- アンケート後の「成約率」が不明
  - セグメント化したアンケートをどう活かすか
- スクール価格が明示されていない
  - どの段階で金額を提示するか

## 🤔 分析者の所感

**矛盾点に気づく**

Threads では「noteで月+22万達成した保育士」として実績を歌ってるのに、UTAGE に飛ばして待ってるのは「AI を活用した副収入スクール」。

つまり、note の方法論を売ってるわけじゃなく、スクールを売ってる。

なのに Threads の投稿でもスクールについては一切触れていない。

**疑問：**
- noteで成功した方法を学べるのか、それとも別のAI系の方法なのか、不明確
- 「月+22万」の実績と「AIスクール」の接続点が見えない
- 読者は「保育士でも稼げたnote方法論」を期待して流入している可能性が高い

**推測：**
- もしかして、noteの成功法則を教えるのではなく「AIツールを使った別の副業法」を教えるのか
- それなら、Threads の投稿で「note以外の新しい方法」というヒントを入れた方が信頼獲得につながるのでは

## 📌 改善案

**期待値マッチングを完璧にするなら**

Threads での実績が「noteで月+22万達成した保育士」ならば、ファネルの最終地点も「note での収入アップ方法を教えるプログラム」であるべき。

**現在の期待値ズレ：**
```
見込み客の期待：「noteで月+22万稼ぐ方法を知りたい」
  ↓（ファネルを通る）
実際の提供：「AIを活用したスクール（内容不明）」
```

**改善後のマッチング：**
```
見込み客の期待：「noteで月+22万稼ぐ方法を知りたい」
  ↓（ファネルを通る）
実際の提供：「保育士でも実現できたnote収入アッププログラム」
```

**効果：**
- 期待値と提供内容が完全に一致
- クローズ率が大幅に上昇する可能性
- 顧客満足度も高まる

**結論：**このファネル設計は優秀だが、「何を最終的に売るか」という終点設計で、期待値マッチングの有無が勝敗を分ける。

## Swipe として学べる点

1. **多段階ファネルの実装** ：メール → LINE → アンケート → 商品
2. **プラットフォーム間の橋渡し** ：Threads → UTAGE → LINE
3. **到達率の最大化** ：メール（開封率低）→ LINE（読了率高）への誘導
4. **顧客セグメント化の準備** ：アンケートで事前分類
5. **UTAGE の活用法** ：クローズド ページ + メール取得 + LINE 促進

**⚠️ 注意点：期待値と提供内容のズレ**
- 導線設計は優秀だが、見込み客の期待値と最終商品が合致するか確認が必要
