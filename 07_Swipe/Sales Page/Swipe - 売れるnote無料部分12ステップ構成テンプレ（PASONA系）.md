# 売れるnoteの無料部分 — 12ステップ構成テンプレ

> **Swipe ガード**：このテンプレは**他人が整理したマーケ構成の型**です。中のセリフ例・感情ラベルはそのままコピーしない。**構成の順序と各ブロックの役割**だけ参考にし、本文・実績・ストーリーは必ず `03_Knowledge/` と自分のルール（煽り禁止・根拠・健一さん向け等）で書き直す。

---

## このスワイプの価値（一言）

有料noteの**無料エリア**を、「期待 → 自分ごと → 共感 → 危機 → 希望 → 今やる理由 → 信頼 → 中身 → 不安解消 → 一押し」の**12ブロック**に分解したチェックリスト。画像付き教材でよく見る型を、執筆時に `@07_Swipe` から引き出せる形に固定したもの。

---

## Ⅰ. 12ステップ一覧（ステップ名・役割・読者感情）

| # | ステップ名 | 役割・説明 | 読者に与える感情・セリフ（参考ラベル） |
|---|------------|------------|----------------------------------------|
| 1 | これを読むとこうなります | このnoteを読むことで得られる理想の未来を明確に伝え、期待感を一気に高める | 「こんな未来が待っている！」というワクワク |
| 2 | こんな人のために書きました | ターゲットを具体的に示し、「自分ごと」にする | 「これは私のための内容だ！」 |
| 3 | こんな悩みないですか？ | 読者の悩み・不安を代弁し、共感で先を読ませる | 「わかる…！」— 共感が信頼の第一歩 |
| 4 | そのままだとこんな最悪な未来が待っています | 行動しなかった場合のリスク・損失を提示し、危機感を持たせる | 「このままだとヤバいかも…」 |
| 5 | これを手に入れたらこんな素敵な未来が待っています | 理想の未来を具体的に描き、行動へのモチベを引き出す | 「こんな未来が叶うならやってみたい！」 |
| 6 | 今のタイミングがチャンスな理由 | なぜ今がベストタイミングか。「今すぐ行動すべき理由」を明確に | 「今やらないと損！」という後押し |
| 7 | 自己紹介、わたしが主張できる理由 | 信頼できる人物であることを伝え、安心・信頼を築く | 「この人の話なら信じられる」 |
| 8 | 実績 | 実績・成果で信頼性と説得力を高める（数字・事例） | 「結果が出ている人なんだ」 |
| 9 | 悩みの原因と解決策 | 悩みの原因を明確にし、解決策で希望を与える | 原因がわかると納得、解決策に期待 |
| 10 | コンテンツ内容 | 学べる内容・得られる価値を具体化し、購入後のイメージを明確に | 「こんなに学べる価値がある！」 |
| 11 | Q&A | よくある質問・不安を先回りして解消し、購入ハードルを下げる | 不安や疑問が解消され安心 |
| 12 | 最後のひと押し | 迷っている背中を押し、行動を促す。締めは熱いメッセージ | 「今すぐ行動しよう！」 |

### 配布元キャラクターからのアドバイス（要約）

- **流れに沿って書くだけ**で、心をつかみ最後まで読まれ、「行動したい」と思わせやすい。
- 理想の未来を叶える読者を増やす、というゴール設定。

## Ⅱ. PASONA／新PASONAとの対応（構造の教科書用）

| 12ステップ | 古典PASONA寄りの読み | 新PASONA寄りの読み |
|------------|---------------------|-------------------|
| 1 これを読むと… | （前置きのベネフィット／約束） | Problemの前に「得られる未来」を先に見せる型にも使える |
| 2 こんな人のために | Audienceの明示 | 同左 |
| 3 こんな悩みないですか | Problem | 共感・代弁 |
| 4 最悪な未来 | Agitation | Solutionの「ない場合」の損失 |
| 5 素敵な未来 | （Solutionのビジョン） | Offerの前の理想像 |
| 6 今がチャンス | Narrow down / 緊急性 | タイミング・限定の論拠 |
| 7 主張できる理由 | — | 信頼・Authority |
| 8 実績 | Proof | 数字・事例（※他人の数字は使わない） |
| 9 原因と解決策 | Solution | 納得 → 希望 |
| 10 コンテンツ内容 | Offerの中身チラ見せ | カリキュラム・目次・得られるもの |
| 11 Q&A | 反論処理 | 不安の先回り |
| 12 最後のひと押し | Action | CTA・今すぐの理由 |

**使い方のコツ**：ステップ4（最悪）と5（理想）の**往復**、3（共感）の直後に4を置くと、読了率・購入意欲の設計としてよく言われる型に沿う。

## Ⅲ. 再利用できる執筆チェックリスト（コピペ用）

```markdown
## 無料部分ドラフト用チェックリスト

- [ ] 1. これを読むとこうなります（理想の未来・約束）
- [ ] 2. こんな人のために書きました（ペルソナ・自分ごと）
- [ ] 3. こんな悩みないですか？（代弁・共感）
- [ ] 4. そのままだと最悪な未来（放置リスク・損失）
- [ ] 5. 手に入れたら素敵な未来（具体シーン）
- [ ] 6. 今がチャンスな理由（タイミング・今やる根拠）
- [ ] 7. 自己紹介・主張できる理由（なぜ自分が書けるか）
- [ ] 8. 実績（※自分の03_Knowledgeの事実のみ）
- [ ] 9. 悩みの原因と解決策（納得→希望）
- [ ] 10. コンテンツ内容（章立て・ワーク・得られるもの）
- [ ] 11. Q&A（価格・時間・向き不向き・ツール不安など）
- [ ] 12. 最後のひと押し（CTA・次の一行）
```

**短縮版（健一さん向け・夜30分で書くとき）**  
1→2→3は必須。4は**事実ベースで軽く**（煽り過剰にしない）。7–8は**店長・note執筆時間など自分の根拠**だけ。12は「次の一行」で着地してもよい（毎回「今すぐ！」で締めなくてよい）。

## Ⅳ. サイジム向けに転用するときのレンズ

### 健一さん（メイン有料note）向け

| ステップ | 転用のヒント |
|----------|----------------|
| 1 | 「週1回、続きから書ける」「学びが蒸発しない」— 約束は2週間レベルまで |
| 2 | 40代後半・多忙・ChatGPTは使うがCursor/Obsidianは後回し |
| 3 | ワンナイトAI、名言が一日で薄れる、一行メモで文脈消失 |
| 4 | 根拠のある放置コスト（時間の浪費、同じ説明の繰り返し）— **恐怖煽りは避ける** |
| 5 | 帰宅前に一言→翌日背景なしで続き、Vaultに迷子にならない入口 |
| 6 | 「また今度」が積み上がった今、AI伴走の設計を一度だけ整える理由 |
| 7–8 | 店長・社長賞・note執筆100時間等 **自分の事実**（Swipeの他人数字は不可） |
| 9 | 原因＝置き場とループがない／解決＝Vault＋伴走AIの渡し方 |
| 10 | チェックリスト・テンプレ・失敗ログ・音声の有無を具体列挙 |
| 11 | 開発者向けではない、夜30分、無料ChatGPTだけでも始められるか、等 |
| 12 | 有料の直前：「ここから先は〜」＋**次の一行**（my-business 着地点） |

### 美咲さん（一人の不安ライン）向け

- 4・6は**弱め**（不安の夜に追い込みすぎない）
- 9は「原因＝仕分けの習慣がない」／解決＝3行整理・鏡・橋
- ツール名は主役にしない（my-business 境界）

### 禁止事項との整合（必読）

- ステップ4・6・12の**セリフ例**（「ヤバい」「今やらないと損」「今すぐ！」）は**感情ラベルの参考**であり、そのまま見出しにしない
- ステップ8に **Swipeや他人の売上・再現数字** を入れない
- 不安を過剰刺激して行動を迫る書き方はしない
