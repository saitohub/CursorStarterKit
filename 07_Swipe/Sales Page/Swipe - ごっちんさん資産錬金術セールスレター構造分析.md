# テクニック別深掘り

## 1. 「才能ではない」の先取り否定

**原文：**
> 私に何か特別な才能があったとかではありません。
> 寝る時間を削って努力した、、、という話でもありません。
> てゆーかサラリーマン課長時代のコロナ禍の激務と比べたら努力などしてないに等しいレベル。
> いまの状況とかは割と関係なくて、メルマガを効率よく作るノウハウを知ってれば、低労力で稼ぐことが目指せます。

**構造：**
```
「才能じゃない」→「努力でもない」→「あの激務より楽」→「ノウハウを知れば誰でも」
```

**なぜ効くか：**
- 読者の「自分には才能がない」という言い訳を、書き手が先に言う
- 「激務と比べたら楽」という基準の置き換えで一気にハードルが下がる
- 「低労力」という言葉が多忙な会社員の琴線に触れる

## 2. 後悔の個人的エピソード（購買動機の感情的根拠）

**原文：**
> もし仮に、ビジネスを始めた当初からメルマガビジネスを本気で学べていたら、、、
>
> 第一子の娘が生まれた月から単身赴任することもなかった。
>
> 第二子の息子をコロナ禍で忙殺されてろくに抱っこもしてあげられなかった。
>
> 一生引きずり続ける後悔しなくて済んだなって思います。

**構造：**
```
「もし早く学べていたら」という仮定
→ 子供との具体的なエピソード（娘・単身赴任）（息子・抱っこできなかった）
→ 「一生引きずり続ける後悔」という重い言葉で感情を着地
```

**なぜ効くか：**
- 数字や実績の話から突然、家族の話に転換することで感情を揺らす
- 「抱っこできなかった」という具体的な行動で情景が浮かぶ
- 読者（多忙な会社員）が「自分も今このままでいいのか」と自問する
- 商品を「お金を稼ぐもの」ではなく「家族との時間を守るもの」に意味転換

## 3. 「仕掛ける側の目が手に入る」という変容体験の描写

**原文：**
> 仕掛ける側が何を狙って文章を書いてるか、全部見えるようになった
> → そしてそれを自分もやればいいだけ、ということに気づいたのです。
>
> これができようになったら、たとえば
> 1、追いかけてる発信者のXをリストに入れる
> 2、1〜2分のスキマ時間があったらリストをバーっとチェック
> 3、気になる投稿をブックマーク
> 4、「裏の狙い」をメモ
> 5、200文字のベースをサクッと作る
> 6、1000〜1500文字の記事をサクッと作る
> → 30分で超良質な記事が作れます

**なぜ効くか：**
- 「見える世界が変わる」という体験は抽象的→具体的な6ステップで「できそう感」を作る
- スキマ時間1〜2分、20分という細かい時間設定が多忙な読者に刺さる
- 「追いかけてる発信者の投稿が全部教材になる」という逆転発想

> ◆売れるメルマガを書く人とメルマガオワコン論者の明確な違いとは？


## 8. クロージングの構造

**原文：**
> 人生に残された限りある時間は、自分と大切な人だけに使ってほしい。
> 人生のうちのほんの短時間だけ真剣に学べば、いろんな不安・不満・不足・不平から逃れられる。
> でも、その短時間の学びですら投げ出して、人生つまらなく老いていく人ばかりです。
>
> ただの「覚悟の問題」です。
> やると決めて、やる。ただこれだけです。
> 超シンプル。

**構造：**
```
感情的な訴え（時間・家族）
→ 否定的な未来（学びを投げ出して老いる）
→ 「覚悟の問題」という断言
→ 「超シンプル」で複雑さを消す
→ 「一緒にやりましょう」で寄り添い
```

**なぜ効くか：**
- 「超シンプル」という言葉が最後の言い訳（複雑すぎる）を消す
- 「やると決めてやる」は読者が今この瞬間にできること
- 「一緒にやりましょう」という伴走の表明で孤独感を解消
