# note 最速初収益テスト戦略

**作成日：2026-06-19**  
**目標：6月中に初収益（1円でも）達成**  
**戦略：37本の既存記事から「売れそうな3-5本」をピックアップし、即有料化してテスト販売**

---

## 背景と問題

**現状：**
- note 37本執筆・100時間投入 → 収益ゼロ（2026年5月時点）
- 5月後半までは軸（健一さんストーリー「ミッション分解の迷子」）があった
- 6月に入り、反応ゼロのため「何を書くべき？」という迷いが発生 → 記事のブレが増加

**本質的な問題：**
- 一貫性やクオリティの問題ではなく、**「ポジショニング（何を売るか）」が定まっていない**
- 実データなしに、仮説だけで37本全てをリライトするのは時間的に非効率

**解決策：**
- 最初に「売れるポジショニング」を小さい範囲（3-5本）でテストする
- 実際の売上とコメント反応から、本当に求められているものを発見
- その軸で全体をリライト、もしくは拡大する（A案への移行）

---

## 戦略：4フェーズ

### Phase 1：候補記事選定（期限：2026-06-21）

**選定基準：**

1. **テーマ軸**：「健一さん（47歳・多忙な会社員）」に刺さる
   - ミッション設計・分解の迷子感
   - 手が止まる/完璧主義で動けない
   - 時間がない中で動き続けたい
   - 整理しようとするほど迷子になる

2. **コンテンツ質**：既に「体験or具体的な解決策」が書かれている
   - 抽象論だけでなく、実例や気づきがある
   - 「サイジムが実際にやってみた」という一次情報がある

3. **時系列優先**：5月後半までの記事優先
   - この時期は軸がまだ明確だった
   - ブレが少ない可能性が高い

**候補リスト（推定）：**
- 「Cursor AIをやめて後悔した話」（2026-05-29）
- 「有料note売れなかった話と収益化の現実」（2026-05-28）
- 「深く落ちれば落ちるほど這い上がる力がつきますからね」（2026-05-18）
- 「例え話を自分の体験とゴリ押しで結ぶ」（2026-05-15）
- 「Cursorでやったこと（AI分身ラボ整理とMOC）」（2026-05-14）

**選定方法：**
- 実際に3-5本を全文読む
- 「健一さんが読んで『あ、これ自分だ』と思うか」を基準に最終決定
- 今週末までに3本に絞る（最初は3本、反応見て増やす）

---

### Phase 2：有料化とセールス文作成（期限：2026-06-25）

**価格設定：**
- 初回テストなので **500-980円**（低めに設定）
- 「安すぎて相手にされない」より「試しに買ってみるか」を優先

**セールス文の構造（PASONA法則に基づく）：**

```
P（Problem）：健一さんの「夜中に検索しちゃう悩み」を言語化
  例：「整理しようとするほど、ミッションがバラバラになるんですよね」

A（Affinity）：責めず、隣に座って共感
  例：「その気持ち、すごくわかります。私も同じでした」

S（Solution）：具体的な解決策を伝える
  例：「〇〇な視点を持ったとき、初めて動き出せました」

O（Offer）：記事の価値を先に伝えてから価格を出す
  例：「この気づきを得るのに、私は数ヶ月かかりました。この一冊に凝縮しています」

N（Narrowing Down）：「今買う理由」を正直に作る
  例：「初回限定で500円です」

A（Action）：言い切る
  例：「下のボタンから、今すぐ受け取ってください」
```

**告知方法：**
- X（Threads）で淡々と「有料note出しました」と共有（煽らない）
- プロフィールに「有料noteへのリンク」は置かない（まずは小さくテスト）
- 既存フォロワーに向けた「特別な告知」もしない

**特典：**
- 初回テストなので**なし**（シンプル）

---

### Phase 3：テスト実行と反応観察（期限：2026-07-03）

**観察期間：2週間**

**観察対象：**

1. **売上数字**：何冊売れたか（目標：3冊以上）
2. **コメント反応**：「いいね」「感想」の質
3. **購入者の属性**：可能なら DM 来た人の属性（年代、職業など）
4. **読み返されているか**：note の「再読率」や「保存」の数字

**パターン別の判断基準：**

| 売上 | コメント反応 | 判定 | 次のステップ |
|------|----------|------|-----------|
| ✅ 売れた | ✅ いい反応 | **大成功** | その軸で10本に拡大 |
| ⚠️ 少し売れた | ✅ 深い反応 | **ポジショニング OK** | セールス文を改善して再テスト |
| ✅ 売れた | ❌ 反応薄い | **データ不足** | 別テーマでテスト |
| ❌ 売れなかった | ❌ 反応なし | **外れ** | テーマを変えて再テスト |

---

### Phase 4：フィードバック → 次フェーズへ（期限：2026-07-06）

**パターン A：売れたケース**
- その軸で「関連する 5-10本」をセット販売用にリライト
- シリーズ化（マガジン化）を検討
- 「この軸が本当に求められている」と確定 → A案へ移行（全体のリライト）

**パターン B：売れなかったケース**
- 別の候補記事で即座に再テスト
- テーマを変える、価格を変える、セールス文を変える のいずれかを試す
- 「実は健一さんはこっちが欲しいんだ」という発見を待つ

**パターン C：反応が曖昧なケース**
- コメント来た人に直接 DM で「実際どう思いました？」と聞く
- 購入者の声を拾う（少数でも濃い反応が価値）

## 重要な前提

1. **完璧さは不要**
   - セールス文は「80点」で出す
   - 完璧は売れてから直す

2. **データが真実**
   - 推測や感覚ではなく、実際の売上・反応から判断
   - 予想が外れても OK。その方が学習できる

3. **速度重視**
   - 合計 3 週間で一通りテスト完了を目指す
   - 「決めて、出して、見る」のループを回す

4. **ローカルテスト**
   - まずは 3 本でテスト
   - 売れたら 5-10 本に拡大
   - 全 37 本のリライトはその後
