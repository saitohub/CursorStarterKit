### 4. **← 後日談セクション（新規挿入）**

3週間後の振り返り。困ったことと、その後の変化を項目ごとに。

#### 4-1. 新しいものへの拒否感→理解で解決
「新しいツール＝困る」という心理的な拒否感があった。でも使い方を理解すれば解決する。

#### 4-2. ショートカットに慣れた
Windows ユーザーだったから Mac のショートカットに慣れてなかった。3週間で普通になった。

#### 4-3. 音声認識が向上した
かつては Aqua Voice で誤字脱字が多かった。今は精度が上がって、整形の手間が減った。これは「技術の進化」。

#### 4-4. 「続けていいですか」→理解と成長の機会に
煩わしいと思ってたが、実は：
- セキュリティ意識が高まった
- AI に全部任せず、自分で理解しながら使う習慣がついた
- AI の仕組みが勝手に身についた

#### 4-5. 英語の嫌悪感→学習の機会に
システムメッセージが英語で出てくるのが嫌だった。でも、その経験があったおかげで AI の仕組みを理解した。

#### 4-6. チャット入力不可→対処法で解決
Esc を押せば治ることを知った。最初は面倒だったが、今は慣れた。

#### 4-7. セキュリティと削除が怖い→**今も課題**
これだけは「解決した」ではなく「今も怖い」。API やパスワード設定は石橋を叩いてやってる。

**（重要ポイント：全部解決した、ではなく、現実的に「今も課題」として継続）**

#### 4-8. 自分でアプリを作成できた→達成感・励み
音声入力アプリを自作。これが大きな励みと達成感になった。

#### 4-9. Claude Code の本質：設計＋思考の学習機会
Cursor は編集に特化。Claude Code は：
- 全体の設計を示してくれる
- 目的・ゴールが明確なら、道のりを細かく示してくれる
- 「なぜそうしたのか」「どういう流れか」を振り返って分析する機会を与える
- それが「自分の考え方の勉強」になる
