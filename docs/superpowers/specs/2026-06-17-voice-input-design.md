# Voice Input App — Design Spec
Date: 2026-06-17

## 概要

Typeless の代替となる macOS 向け音声入力 Python スクリプト。ホットキーをトグルして録音し、OpenAI Whisper API でテキスト変換後、フォーカス中のアプリに自動ペーストする。月$2.59（Typeless $12 の約78%削減）。

---

## 全体の流れ

```
[ホットキー1回押す]
        ↓
録音スタート ＋ インジケーター表示（🎙 録音中...）
        ↓
（ユーザーが自由に喋る）
        ↓
[ホットキーをもう1回押す]
        ↓
録音ストップ ＋ インジケーター「⏳ 変換中...」に切り替わる
        ↓
音声ファイルを Whisper API に送信
        ↓
テキストをクリップボードにコピー ＋ Cmd+V で自動ペースト
        ↓
インジケーター消える
```

---

## ファイル構成

```
voice-input/
├── main.py          # メインスクリプト（これだけ起動すれば動く）
├── .env             # OPENAI_API_KEY を記載（Git管理外）
├── requirements.txt # 依存ライブラリ一覧
├── log.txt          # 変換成功したテキストの履歴（自動生成）
└── recordings/      # エラー時に音声ファイルを保存（自動生成）
```

### 設定（main.py 先頭）

```python
HOTKEY = "<cmd>+<shift>+space"  # ここを変えるだけでホットキー変更
```

## 使用ライブラリ

| ライブラリ | 用途 |
|-----------|------|
| `pynput` | グローバルホットキー監視 |
| `sounddevice` | マイク録音 |
| `scipy` | 音声ファイルの保存（WAV） |
| `openai` | Whisper API 呼び出し |
| `pyperclip` | クリップボード操作 |
| `pyautogui` | Cmd+V の自動実行 |
| `tkinter` | フローティングインジケーターウィンドウ |
| `python-dotenv` | .env ファイルの読み込み |

---

## インジケーターウィンドウ

- 表示位置：画面右下
- 常に最前面（他ウィンドウに隠れない）
- 半透明・角丸デザイン
- クリック不可（操作を邪魔しない）

| 状態 | 表示 |
|------|------|
| 録音中 | 🎙 録音中... |
| 変換中 | ⏳ 変換中... |
| 待機中 | （非表示） |

---

## 履歴・ログ

### テキストログ（log.txt）
変換成功のたびに日時とテキストを追記。

```
[2026-06-17 14:32:10] 今日の会議は3時からです。田中さんも参加します。
[2026-06-17 14:45:03] このメールを明日までに返信してください。
```

### 音声ファイル保存（recordings/）
Whisper API エラー時のみ、音声ファイルを保存。ファイル名は日時。

```
recordings/
└── 2026-06-17_14-32-10.wav
```

---

## エラー処理

| 状況 | 動作 |
|------|------|
| 録音が0秒（誤タップ） | 何もしない |
| Whisper API エラー | ターミナルにエラー表示 ＋ 音声を `recordings/` に保存 |
| APIキー未設定 | 起動時にエラーメッセージを出して終了 |
| マイクアクセス権限なし | 起動時にエラーメッセージを出して終了 |
